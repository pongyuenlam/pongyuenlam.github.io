uv Quickstart

A quick reference for uv, an extremely fast Python package and project manager, written in Rust.

Install and initialize a project

Install uv, then use it to install and pin a Python version and initialize a new project.

pip install uv
uv python install 3.12.10
uv python pin 3.12.10
uv init

Add a package

Add a package to the project and run your script with it.

uv add matplotlib
uv run main.py

Install from requirements.txt

Install dependencies from a requirements file and run the script.

uv add -r requirements.txt
uv run main.py
