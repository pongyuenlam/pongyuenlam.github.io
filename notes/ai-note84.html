How to make a web page listen to Chinese (Putonghua or Cantonese) and speak a reply (version 4)?

Howard Pong Yuen Lam · AI Notes · November 27, 2026 · 5 min read

English 繁體中文 简体中文

A web page can listen in Chinese and answer out loud. This one hears Putonghua or Cantonese, shows the words, and reads a short reply back. It is still one HTML file with one short script.

The page uses both halves of the Web Speech API: speech recognition to hear, and speech synthesis to answer. Chrome and Edge include both. Firefox includes neither.

The page needs the microphone. The first time you click 开始听, the browser asks whether the page may use it; choose Allow.

What you need before you start

  • Chrome or Edge. Firefox cannot run this page.
  • A microphone. Most laptops have one built in.
  • Speakers or headphones, with the sound on. The reply comes out of them.
  • A Chinese voice. Most computers have one. If the reply is silent, or sounds like English, add a Chinese voice in the computer's sound settings.
  • An internet connection. Chrome sends the recorded sound to its speech service, which sends back the words.
  • A text editor. Visual Studio Code if you have it. If not, start with How to install Visual Studio Code?.

Step 1: Create the file

Download the zip file and extract it. On a Mac, double-click the zip. On Windows, right-click it and choose Extract All. You get a folder named Folder-AI-Speech-04-Putonghua-Reply, holding index.html.

Step 2: Open the page

Option 1: this computer. Double-click index.html. It opens in your browser. No server is needed.

Option 2: your free website. Copy the HTML file into the folder for your free GitHub website, described in How to create a free website at your-username.github.io?, and upload the change. If the folder already holds a page called index.html, rename this file first, for example to chinese-reply.html, so the upload does not replace the home page of your website. Then open the page at its https:// address in Chrome.

Option 3: this website. Open the same page on this website and click 开始听. It runs straight away, with nothing to download.

The file does not have to be named index.html. Any name works, and the name becomes the end of the link: a file called chinese-reply.html is reached at https://your-username.github.io/chinese-reply.html.

A file called index.html is special. It is the page a visitor sees first. So a file with that name would replace the home page of your website.

Step 3: The whole file

This is everything, in index.html:

<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>Answer</title>
</head>
<body>
<h1>答案</h1>
<button onclick="startListening()">开始听</button>
<button onclick="stopListening()">停止</button>
<p>你说：<span id="heard">还没有</span></p>
<p>回答：<span id="reply">还没有</span></p>
<script>
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
const recognition = new SpeechRecognition();
recognition.lang = 'zh-CN';
recognition.onresult = function (event) {
  const heard = event.results[0][0].transcript;
  document.getElementById('heard').textContent = heard;
  const reply = '你说的是：' + heard;
  document.getElementById('reply').textContent = reply;
  speak(reply);
};
function startListening() {
  recognition.start();
}
function stopListening() {
  recognition.stop();
}
function speak(text) {
  speechSynthesis.cancel();
  const utterance = new SpeechSynthesisUtterance(text);
  utterance.lang = 'zh-CN';
  speechSynthesis.speak(utterance);
}
</script>
</body>
</html>

The top half is an ordinary page: a heading, two buttons, and two lines. The heading says answer in Chinese, the buttons say start listening and stop, and the two lines are where the words appear. Each button carries an onclick attribute naming the function to run when it is clicked.

Step 4: The names in the script

SpeechRecognition is the browser's listening engine. Chrome also offers it under an older name, webkitSpeechRecognition, so the first line takes whichever name the browser has. recognition.lang = 'zh-CN' tells the engine that the speaker is using Chinese. 'zh-CN' asks for the standard spoken Chinese of mainland China, and the recogniser also accepts Cantonese speech, returning it as written Chinese.

recognition.onresult names the function to run when words arrive. event.results[0][0].transcript is the sentence as plain text. The next two lines put that sentence on the page and build the reply, '你说的是：' + heard, which means what you said is and puts a short Chinese phrase in front of the words.

speak(text) is the talking half. speechSynthesis.cancel() stops any earlier reply, SpeechSynthesisUtterance prepares the new text for reading, and speechSynthesis.speak() hands it to the engine. The line utterance.lang = 'zh-CN' asks for a Putonghua voice, so the reply is read in Putonghua even when you spoke Cantonese. Without it, the computer may read the Chinese characters with an English voice, or say nothing at all. Finally, start() opens the microphone and stop() closes it.

Step 5: Try it

Open the page in Chrome. Click 开始听, choose Allow when the browser asks for the microphone, and say a sentence in Putonghua or Cantonese, such as 你好，世界！.

The words appear next to 你说：, and the computer then reads the reply out loud in Chinese. Click 停止 to close the microphone early. If you say nothing for a moment, the page stops by itself; click 开始听 again to say more.

Limitations

  • The microphone must be allowed. If the browser will not offer the microphone for a file on your computer, upload the page to your free website and open it there.
  • The reply is an echo, not a conversation. The page repeats your words with a phrase in front. It does not understand them and has no AI model inside.
  • It needs the internet for the listening half. Chrome sends the sound to its speech service. The talking half usually works offline, because the voices are installed on the computer.
  • One phrase at a time. The page stops listening after a short pause, then answers once.
  • It is not perfect. Background noise, a strong accent and unusual names come back as the wrong words, and the reply repeats the mistake.
  • Putonghua and Cantonese, nothing else. The listening language is fixed at 'zh-CN', which covers Putonghua and, in practice, Cantonese as well. Other languages are not recognised. The reply is read with a Chinese voice; if the computer has none, the reply may be silent, so add one in the sound settings.
