How to let the program search its own settings (Forecast, version 10)?

Howard Pong Yuen Lam · AI Notes · November 13, 2026 · 7 min read

English 繁體中文 简体中文

This is version 10 of the forecasting series. Version 9 compared three learning rates by hand. Version 10 lets the program do the comparison: it lists the choices for five settings, works out every combination, tries twenty of them at random, keeps the best model and saves the whole comparison as a spreadsheet. The training loop itself is unchanged; what changes is who chooses the settings.

Five settings and 243 combinations

SEARCH_SPACE = {
    "epochs":       [50, 100, 200],
    "learning_rate":[0.001, 0.01, 0.1],
    "optimizer":    ["Adam", "SGD", "RMSprop"],
    "hidden_size":  [10, 32, 64],
    "num_layers":   [1, 2, 3],
}

Each key is a setting and each list is the values worth trying. Three values in five lists give 3 × 3 × 3 × 3 × 3 = 243 possible combinations.

Trying all 243 would take hours for an improvement that would be hard to notice. Instead the program draws N_TRIALS = 20 combinations at random from the 243. That is enough to show which combinations perform badly, at a much lower cost.

How the search works

1. Make every combination, then draw twenty

keys   = list(SEARCH_SPACE.keys())
combos = list(itertools.product(*SEARCH_SPACE.values()))
sampled = random.sample(combos, min(N_TRIALS, len(combos)))

itertools.product builds all 243 combinations, taking one value from each list in turn. random.sample then picks 20 of them without repeating any. The seed is fixed at the top of the file, so the twenty chosen here are the same twenty on every run. 

# ── Reproducibility ──────────────────────────────────────────────────────────
SEED = 42
random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)

2. Turn one combination into a model

def build_model(hidden_size, num_layers):
    layers = []
    in_dim = input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers).to(device)

Version 7's network was spelled out layer by layer. This version builds it from two numbers instead. The loop adds one hidden layer per num_layers, each of width hidden_size, and the last line outside the loop adds the single output: layers.append(nn.Linear(in_dim, 1)). With hidden_size = 64 and num_layers = 3, the result is the three-layer network of the winning trial.

3. Train each trial and keep its validation score

for i, combo in enumerate(sampled):
    cfg = dict(zip(keys, combo))
    model, t_losses, v_losses, trial_val_loss = train_trial(cfg)

    row = {**cfg, "val_loss": trial_val_loss, "actual_epochs": len(t_losses)}
    results.append(row)

zip(keys, combo) pairs each setting name with its value, and dict makes that a labelled configuration such as {"epochs": 50, "learning_rate": 0.001, ...}. This dictionary is stored in cfg, short for configuration: one complete set of settings for a single trial. train_trial(cfg) then builds and trains a model using those settings. Unlike the website version, train_trial now returns four values: the model, its training and validation loss curves, and the single best validation loss seen during training. We only record that validation-loss score for each trial — we do not call evaluate on the test set inside the loop. Each trial is graded on validation data only, so the test set remains a hidden "holiday" that we visit once, after the winner is picked.

Training works as in version 9: a trial stops early if the validation error does not improve for 15 epochs (EARLY_STOP_PATIENCE = 15), and the weights that gave the lowest validation error are kept. A trial that stops improving therefore ends early instead of running to the maximum number of epochs.

4. Pick the winner by validation loss, then grade it honestly

if trial_val_loss < best_val_loss:
    best_val_loss = trial_val_loss
    best_trial = {"cfg": cfg, "model": model, ...}

# Evaluate once on the test set after the winner is chosen
r2, mae, rmse, preds, actuals = evaluate(best_trial["model"])

torch.save(best_trial["model"].state_dict(), "best_model.pt")
results_df.to_excel("search_results.xlsx", index_label="Rank")

best_val_loss starts at positive infinity, so the first trial always becomes the benchmark and later trials must lower it to replace it. The selection rule is < not >: we want the smallest validation loss, not the largest R². Only after that decision is final does the script call evaluate once on the test set — the same test set that no trial has looked at until now. At the end two files appear: the winning weights in best_model.pt, and every trial ranked by validation loss in search_results.xlsx. The spreadsheet is the useful part, because it shows every trial, not only the winner.

Writing the Excel file needs one extra package, openpyxl, which is why it is listed in pyproject.toml.

Your numbers will differ, but the pattern is what matters.

Every very poor result uses a learning rate of 0.1. They appear at the bottom of the spreadsheet because they give much higher validation loss than every other setting. A trial with LR = 0.1 that ends early (say, 13 epochs) almost always means the optimizer could not make progress. This is the same story version 9 told with just three runs; twenty trials make it unavoidable.

The Epochs column shows the maximum allowed, not the number actually used. Early stopping may have finished long before, and the spreadsheet keeps a column, actual_epochs, with the real number. A trial that uses all 200 epochs is one where validation loss was still improving — or one where it never improved enough that the patience counter was reset.

The winner is only a little better than version 9. Version 9's best validation loss was already in the high 38s. Twenty trials found the same neighbourhood, not a new one. The honest lesson is that tuning helps a little, and no amount of tuning made this model a good one. That is a fact about the model and the data, not about the search.

One small change from the website version: every trial is ranked by validation loss (sort_values("val_loss"), ascending), not by R². This means trial 1 in the spreadsheet is always the best model by validation score, and the bar chart below puts it on the left. The spreadsheet also shows val_loss instead of R² because that is what we used to choose. R² still matters — we evaluate the winner on the test set once the selection is done — we just do not let it influence the choice.

The whole program

The pieces above, put back together. This is the complete file: 

import os
os.environ["KMP_DUPLICATE_LIB_OK"] = "TRUE"

import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import random
import itertools

# ── Reproducibility ──────────────────────────────────────────────────────────
SEED = 42
random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)

# ── Search space ─────────────────────────────────────────────────────────────
SEARCH_SPACE = {
    "epochs":       [50, 100, 200],
    "learning_rate":[0.001, 0.01, 0.1],
    "optimizer":    ["Adam", "SGD", "RMSprop"],
    "hidden_size":  [10, 32, 64],
    "num_layers":   [1, 2, 3],
}
N_TRIALS      = 20
EARLY_STOP_PATIENCE = 15   # stop if val loss doesn't improve for this many epochs
WINDOW_SIZE   = 30
BATCH_SIZE    = 32

# ── Data ─────────────────────────────────────────────────────────────────────
df = pd.read_csv("time_series.csv")
series = df["series"].values
series_tensor = torch.tensor(series, dtype=torch.float32)

def create_sliding_windows(data, window_size):
    windows  = data.unfold(0, window_size, 1)
    features = windows[:, :-1]
    targets  = windows[:, -1:]
    return features, targets

features, targets = create_sliding_windows(series_tensor, WINDOW_SIZE)
full_dataset = TensorDataset(features, targets)

total   = len(full_dataset)
tr_end  = int(total * 0.70)
val_end = int(total * 0.85)

train_loader = DataLoader(Subset(full_dataset, range(tr_end)),          batch_size=BATCH_SIZE, shuffle=True)
val_loader   = DataLoader(Subset(full_dataset, range(tr_end, val_end)), batch_size=BATCH_SIZE, shuffle=False)
test_loader  = DataLoader(Subset(full_dataset, range(val_end, total)),  batch_size=BATCH_SIZE, shuffle=False)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# ── Model factory ─────────────────────────────────────────────────────────────
def build_model(hidden_size, num_layers):
    input_size = WINDOW_SIZE - 1
    layers = []
    in_dim = input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers).to(device)

def get_optimizer(name, params, lr):
    return {"Adam": optim.Adam, "SGD": optim.SGD, "RMSprop": optim.RMSprop}[name](params, lr=lr)

# ── Train one trial ───────────────────────────────────────────────────────────
def train_trial(cfg):
    model     = build_model(cfg["hidden_size"], cfg["num_layers"])
    criterion = nn.MSELoss()
    optimizer = get_optimizer(cfg["optimizer"], model.parameters(), cfg["learning_rate"])

    best_val_loss = float("inf")
    best_state    = {k: v.clone() for k, v in model.state_dict().items()}
    patience_ctr  = 0
    train_losses, val_losses = [], []

    for epoch in range(cfg["epochs"]):
        # train
        model.train()
        t_loss = 0
        for xb, yb in train_loader:
            xb, yb = xb.to(device), yb.to(device)
            optimizer.zero_grad()
            loss = criterion(model(xb), yb)
            loss.backward()
            optimizer.step()
            t_loss += loss.item()
        t_loss /= len(train_loader)

        # validate
        model.eval()
        v_loss = 0
        with torch.no_grad():
            for xb, yb in val_loader:
                v_loss += criterion(model(xb.to(device)), yb.to(device)).item()
        v_loss /= len(val_loader)

        train_losses.append(t_loss)
        val_losses.append(v_loss)

        # early stopping
        if v_loss < best_val_loss:
            best_val_loss = v_loss
            best_state    = {k: v.clone() for k, v in model.state_dict().items()}
            patience_ctr  = 0
        else:
            patience_ctr += 1
            if patience_ctr >= EARLY_STOP_PATIENCE:
                break

    model.load_state_dict(best_state)
    return model, train_losses, val_losses, best_val_loss

# ── Evaluate on test set ──────────────────────────────────────────────────────
def evaluate(model):
    model.eval()
    preds, actuals = [], []
    with torch.no_grad():
        for xb, yb in test_loader:
            preds.extend(model(xb.to(device)).cpu().numpy())
            actuals.extend(yb.numpy())
    p = torch.tensor(np.array(preds))
    a = torch.tensor(np.array(actuals))
    mae  = torch.mean(torch.abs(p - a)).item()
    rmse = torch.sqrt(torch.mean((p - a) ** 2)).item()
    ss_res = torch.sum((a - p) ** 2)
    ss_tot = torch.sum((a - torch.mean(a)) ** 2)
    r2 = (1 - ss_res / ss_tot).item()
    return r2, mae, rmse, preds, actuals

# ── Random search; select by validation loss ──────────────────────────────────
keys   = list(SEARCH_SPACE.keys())
combos = list(itertools.product(*SEARCH_SPACE.values()))
sampled = random.sample(combos, min(N_TRIALS, len(combos)))

results = []
best_val_loss = float("inf")
best_trial = None

print(f"Running {N_TRIALS} random trials...\n")
print(f"{'Trial':>5}  {'Epochs':>6}  {'LR':>6}  {'Opt':>7}  {'Hidden':>6}  {'Layers':>6}  {'Val Loss':>12}")
print("-" * 70)

for i, combo in enumerate(sampled):
    cfg = dict(zip(keys, combo))
    model, t_losses, v_losses, trial_val_loss = train_trial(cfg)

    row = {**cfg, "val_loss": trial_val_loss, "actual_epochs": len(t_losses)}
    results.append(row)

    print(f"{i+1:>5}  {cfg['epochs']:>6}  {cfg['learning_rate']:>6}  "
          f"{cfg['optimizer']:>7}  {cfg['hidden_size']:>6}  {cfg['num_layers']:>6}  "
          f"{trial_val_loss:>12.4f}")

    if trial_val_loss < best_val_loss:
        best_val_loss = trial_val_loss
        best_trial = {"cfg": cfg, "model": model, "t_losses": t_losses,
                      "v_losses": v_losses, "val_loss": trial_val_loss}

# ── Evaluate the selected model on the test set once ─────────────────────────
r2, mae, rmse, preds, actuals = evaluate(best_trial["model"])
best_trial.update({"r2": r2, "mae": mae, "rmse": rmse,
                   "preds": preds, "actuals": actuals})

# ── Save best model ───────────────────────────────────────────────────────────
torch.save(best_trial["model"].state_dict(), "best_model.pt")
print(f"\nBest model saved → best_model.pt")
print(f"Best config : {best_trial['cfg']}")
print(f"Best validation MSE: {best_val_loss:.4f}")
print(f"Test R²: {r2:.4f}  |  MAE: {mae:.4f}  |  RMSE: {rmse:.4f}")

# ── Save results table ranked by validation loss ─────────────────────────────
results_df = pd.DataFrame(results).sort_values("val_loss").reset_index(drop=True)
results_df.index += 1
results_df.to_excel("search_results.xlsx", index_label="Rank")
print("Results table saved → search_results.xlsx")

# ── Plots for best model only ─────────────────────────────────────────────────
# 1. Loss curves
plt.figure(figsize=(10, 5))
plt.plot(best_trial["t_losses"], label="Train Loss")
plt.plot(best_trial["v_losses"], label="Val Loss")
plt.title(f"Best Model — Loss Curves\n{best_trial['cfg']}", fontsize=11)
plt.xlabel("Epoch"); plt.ylabel("MSE Loss")
plt.legend(); plt.grid(True)
plt.tight_layout()
plt.savefig("best_model_loss.png", dpi=150)
plt.show()

# 2. Predictions vs actual
plt.figure(figsize=(12, 5))
plt.plot(best_trial["actuals"], label="Actual",    color="lightgrey", linewidth=1.5)
plt.plot(best_trial["preds"],   label="Predicted", color="red",       linewidth=1.5)
plt.title(f"Best Model — Predictions vs Actual (Test Set)\nR²={best_trial['r2']:.4f}  RMSE={best_trial['rmse']:.4f}", fontsize=11)
plt.xlabel("Time"); plt.ylabel("Value")
plt.legend(); plt.grid(True)
plt.tight_layout()
plt.savefig("best_model_predictions.png", dpi=150)
plt.show()

# 3. Validation-loss bar chart across all trials
plt.figure(figsize=(12, 4))
colors = ["#70AD47" if rank == 1 else "#4472C4" for rank in results_df.index]
plt.bar(results_df.index, results_df["val_loss"], color=colors)
plt.axhline(best_val_loss, color="red", linestyle="--", linewidth=1,
            label=f"Best Val Loss={best_val_loss:.4f}")
plt.title("Validation Loss Across All Trials (green = best)")
plt.xlabel("Rank"); plt.ylabel("Validation MSE Loss")
plt.legend(); plt.grid(axis="y", alpha=0.4)
plt.tight_layout()
plt.savefig("trial_val_loss_chart.png", dpi=150)
plt.show()

Running it on your own computer

Download the zip file and unzip it to a folder. The zip holds the programs in this series so far, the time_series.csv data file, and pyproject.toml. This note uses time_10.py. Open the folder in Visual Studio Code, then type these three lines in the terminal: 

uv python pin 3.12.10
uv sync
uv run time_10.py

The first line records which Python version this folder uses, and the second installs every package that pyproject.toml lists. The third line runs the twenty trials, which takes noticeably longer than earlier versions, and then opens the charts; close each window to continue. Two files are left behind: best_model.pt and search_results.xlsx.

Those three lines are needed only once. The next time you want to run the program again, type just uv run time_10.py.

If you have not set up uv yet, start with How to install Visual Studio Code? and then the uv note for Windows or Mac.

What comes next

The window length has stayed at 30 throughout, even though version 2 already showed how much it changes the shape of the examples. The next version adds it to the search space, so the program decides how far back to look as well.
