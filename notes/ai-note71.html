How to let the program search its own settings (Forecast, version 10)?

Howard Pong Yuen Lam · AI Notes · November 13, 2026 · 7 min read

English 繁體中文 简体中文

This is version 10 of the forecasting series. Version 9 compared three learning rates by hand. Version 10 hands the job to the program: it lists the choices for five settings, works out every combination, tries twenty of them at random, keeps the best model and saves the whole comparison as a spreadsheet. The training loop itself is untouched — what changes is who decides the settings.

Five dials and 243 combinations

SEARCH_SPACE = {
    "epochs":       [50, 100, 200],
    "learning_rate":[0.001, 0.01, 0.1],
    "optimizer":    ["Adam", "SGD", "RMSprop"],
    "hidden_size":  [10, 32, 64],
    "num_layers":   [1, 2, 3],
}

Each key is a setting and each list is the values worth trying. Three values in five lists give 3 × 3 × 3 × 3 × 3 = 243 possible combinations.

Trying all 243 would take hours for a gain nobody would notice. Instead the program draws N_TRIALS = 20 combinations at random from the 243. That is enough to see which corners of the space are hopeless, at a fraction of the cost.

How the search works

1. Make every combination, then draw twenty

keys   = list(SEARCH_SPACE.keys())
combos = list(itertools.product(*SEARCH_SPACE.values()))
sampled = random.sample(combos, min(N_TRIALS, len(combos)))

itertools.product builds all 243 combinations, taking one value from each list in turn. random.sample then picks 20 of them without repeating any. The seed is fixed at the top of the file, so the twenty chosen here are the same twenty on every run — which is why the table below can be reproduced.

2. Turn one combination into a model

def build_model(hidden_size, num_layers):
    layers = []
    in_dim = input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers).to(device)

Version 7's network was spelled out layer by layer. This version builds it from two numbers instead. The loop adds one hidden layer per num_layers, each of width hidden_size, and the last line outside the loop adds the single output. With hidden_size = 64 and num_layers = 3, the result is the three-layer network of the winning trial.

3. Train and grade each trial

for i, combo in enumerate(sampled):
    cfg = dict(zip(keys, combo))
    model, t_losses, v_losses = train_trial(cfg)
    r2, mae, rmse, preds, actuals = evaluate(model)

zip(keys, combo) pairs each setting name with its value, and dict makes that a labelled configuration such as {"epochs": 50, "learning_rate": 0.001, ...}. Training is version 9's, with early stopping and best-weight restoring, so a hopeless trial gives up rather than running to the end.

4. Remember the winner and write everything out

if r2 > best_r2:
    best_r2    = r2
    best_trial = {"cfg": cfg, "model": model, ...}

torch.save(best_trial["model"].state_dict(), "best_model.pt")
results_df.to_excel("search_results.xlsx", index_label="Rank")

best_r2 starts at negative infinity, so the first trial always becomes the benchmark and later trials must beat it to replace it. At the end two files appear: the winning weights in best_model.pt, and every trial ranked by R² in search_results.xlsx. The spreadsheet is the useful part — it shows not only what won but what lost.

Writing the Excel file needs one extra package, openpyxl, which is why it is listed in pyproject.toml. Without it pandas prints the table happily and then fails at the moment of saving.

Three things in that table are worth more than the winning number.

The disasters all involve a learning rate of 0.1. Trials 5, 6, 11, 12, 13 and 15 report negative R² values in the hundreds, and RMSE in the seventies and hundreds instead of around 5. A negative R² means the model is worse than always replying with the average. That is what a step too large looks like: the weights jump about and never settle. Version 9 saw the mild version of this; here it is unmistakable.

The Epochs column is a ceiling, not a record. It shows the maximum allowed. Early stopping may have finished long before, and the spreadsheet keeps a column, actual_epochs, with the truth.

The winner is only a little better than version 9. R² of 0.4511 against 0.4394. Twenty trials of searching bought a small gain on top of the early stopping, which is the honest lesson: tuning helps at the margin, and no amount of tuning turned this model into a good one. That is a fact about the model, not about the search.

The whole program

The pieces above, put back together. This is the complete file: 

import os
os.environ["KMP_DUPLICATE_LIB_OK"] = "TRUE"

import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import random
import itertools

# ── Reproducibility ──────────────────────────────────────────────────────────
SEED = 42
random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)

# ── Search space ─────────────────────────────────────────────────────────────
SEARCH_SPACE = {
    "epochs":       [50, 100, 200],
    "learning_rate":[0.001, 0.01, 0.1],
    "optimizer":    ["Adam", "SGD", "RMSprop"],
    "hidden_size":  [10, 32, 64],
    "num_layers":   [1, 2, 3],
}
N_TRIALS      = 20
EARLY_STOP_PATIENCE = 15   # stop if val loss doesn't improve for this many epochs
WINDOW_SIZE   = 30
BATCH_SIZE    = 32

# ── Data ─────────────────────────────────────────────────────────────────────
df = pd.read_csv("time_series.csv")
series = df["series"].values
series_tensor = torch.tensor(series, dtype=torch.float32)

def create_sliding_windows(data, window_size):
    windows  = data.unfold(0, window_size, 1)
    features = windows[:, :-1]
    targets  = windows[:, -1:]
    return features, targets

features, targets = create_sliding_windows(series_tensor, WINDOW_SIZE)
full_dataset = TensorDataset(features, targets)

total   = len(full_dataset)
tr_end  = int(total * 0.70)
val_end = int(total * 0.85)

train_loader = DataLoader(Subset(full_dataset, range(tr_end)),          batch_size=BATCH_SIZE, shuffle=True)
val_loader   = DataLoader(Subset(full_dataset, range(tr_end, val_end)), batch_size=BATCH_SIZE, shuffle=False)
test_loader  = DataLoader(Subset(full_dataset, range(val_end, total)),  batch_size=BATCH_SIZE, shuffle=False)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# ── Model factory ─────────────────────────────────────────────────────────────
def build_model(hidden_size, num_layers):
    input_size = WINDOW_SIZE - 1
    layers = []
    in_dim = input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers).to(device)

def get_optimizer(name, params, lr):
    return {"Adam": optim.Adam, "SGD": optim.SGD, "RMSprop": optim.RMSprop}[name](params, lr=lr)

# ── Train one trial ───────────────────────────────────────────────────────────
def train_trial(cfg):
    model     = build_model(cfg["hidden_size"], cfg["num_layers"])
    criterion = nn.MSELoss()
    optimizer = get_optimizer(cfg["optimizer"], model.parameters(), cfg["learning_rate"])

    best_val_loss = float("inf")
    best_state    = {k: v.clone() for k, v in model.state_dict().items()}
    patience_ctr  = 0
    train_losses, val_losses = [], []

    for epoch in range(cfg["epochs"]):
        # train
        model.train()
        t_loss = 0
        for xb, yb in train_loader:
            xb, yb = xb.to(device), yb.to(device)
            optimizer.zero_grad()
            loss = criterion(model(xb), yb)
            loss.backward()
            optimizer.step()
            t_loss += loss.item()
        t_loss /= len(train_loader)

        # validate
        model.eval()
        v_loss = 0
        with torch.no_grad():
            for xb, yb in val_loader:
                v_loss += criterion(model(xb.to(device)), yb.to(device)).item()
        v_loss /= len(val_loader)

        train_losses.append(t_loss)
        val_losses.append(v_loss)

        # early stopping
        if v_loss < best_val_loss:
            best_val_loss = v_loss
            best_state    = {k: v.clone() for k, v in model.state_dict().items()}
            patience_ctr  = 0
        else:
            patience_ctr += 1
            if patience_ctr >= EARLY_STOP_PATIENCE:
                break

    model.load_state_dict(best_state)
    return model, train_losses, val_losses

# ── Evaluate on test set ──────────────────────────────────────────────────────
def evaluate(model):
    model.eval()
    preds, actuals = [], []
    with torch.no_grad():
        for xb, yb in test_loader:
            preds.extend(model(xb.to(device)).cpu().numpy())
            actuals.extend(yb.numpy())
    p = torch.tensor(np.array(preds))
    a = torch.tensor(np.array(actuals))
    mae  = torch.mean(torch.abs(p - a)).item()
    rmse = torch.sqrt(torch.mean((p - a) ** 2)).item()
    ss_res = torch.sum((a - p) ** 2)
    ss_tot = torch.sum((a - torch.mean(a)) ** 2)
    r2 = (1 - ss_res / ss_tot).item()
    return r2, mae, rmse, preds, actuals

# ── Random search ─────────────────────────────────────────────────────────────
keys   = list(SEARCH_SPACE.keys())
combos = list(itertools.product(*SEARCH_SPACE.values()))
sampled = random.sample(combos, min(N_TRIALS, len(combos)))

results = []
best_r2    = -float("inf")
best_trial = None

print(f"Running {N_TRIALS} random trials...\n")
print(f"{'Trial':>5}  {'Epochs':>6}  {'LR':>6}  {'Opt':>7}  {'Hidden':>6}  {'Layers':>6}  {'R2':>8}  {'RMSE':>10}")
print("-" * 70)

for i, combo in enumerate(sampled):
    cfg = dict(zip(keys, combo))
    model, t_losses, v_losses = train_trial(cfg)
    r2, mae, rmse, preds, actuals = evaluate(model)

    row = {**cfg, "r2": round(r2, 4), "mae": round(mae, 4), "rmse": round(rmse, 4),
           "actual_epochs": len(t_losses)}
    results.append(row)

    print(f"{i+1:>5}  {cfg['epochs']:>6}  {cfg['learning_rate']:>6}  "
          f"{cfg['optimizer']:>7}  {cfg['hidden_size']:>6}  {cfg['num_layers']:>6}  "
          f"{r2:>8.4f}  {rmse:>10.4f}")

    if r2 > best_r2:
        best_r2    = r2
        best_trial = {"cfg": cfg, "model": model, "t_losses": t_losses,
                      "v_losses": v_losses, "preds": preds, "actuals": actuals,
                      "r2": r2, "mae": mae, "rmse": rmse}

# ── Save best model ───────────────────────────────────────────────────────────
torch.save(best_trial["model"].state_dict(), "best_model.pt")
print(f"\nBest model saved → best_model.pt")
print(f"Best config : {best_trial['cfg']}")
print(f"Best R²     : {best_trial['r2']:.4f}  |  MAE: {best_trial['mae']:.4f}  |  RMSE: {best_trial['rmse']:.4f}")

# ── Save results table ────────────────────────────────────────────────────────
results_df = pd.DataFrame(results).sort_values("r2", ascending=False).reset_index(drop=True)
results_df.index += 1
results_df.to_excel("search_results.xlsx", index_label="Rank")
print("Results table saved → search_results.xlsx")

# ── Plots for best model only ─────────────────────────────────────────────────
# 1. Loss curves
plt.figure(figsize=(10, 5))
plt.plot(best_trial["t_losses"], label="Train Loss")
plt.plot(best_trial["v_losses"], label="Val Loss")
plt.title(f"Best Model — Loss Curves\n{best_trial['cfg']}", fontsize=11)
plt.xlabel("Epoch"); plt.ylabel("MSE Loss")
plt.legend(); plt.grid(True)
plt.tight_layout()
plt.savefig("best_model_loss.png", dpi=150)
plt.show()

# 2. Predictions vs actual
plt.figure(figsize=(12, 5))
plt.plot(best_trial["actuals"], label="Actual",    color="lightgrey", linewidth=1.5)
plt.plot(best_trial["preds"],   label="Predicted", color="red",       linewidth=1.5)
plt.title(f"Best Model — Predictions vs Actual (Test Set)\nR²={best_trial['r2']:.4f}  RMSE={best_trial['rmse']:.4f}", fontsize=11)
plt.xlabel("Time"); plt.ylabel("Value")
plt.legend(); plt.grid(True)
plt.tight_layout()
plt.savefig("best_model_predictions.png", dpi=150)
plt.show()

# 3. R² bar chart across all trials
plt.figure(figsize=(12, 4))
colors = ["#4472C4" if r < best_r2 else "#70AD47" for r in results_df["r2"]]
plt.bar(results_df.index, results_df["r2"], color=colors)
plt.axhline(best_r2, color="red", linestyle="--", linewidth=1, label=f"Best R²={best_r2:.4f}")
plt.title("R² Across All Trials (green = best)")
plt.xlabel("Rank"); plt.ylabel("R²")
plt.legend(); plt.grid(axis="y", alpha=0.4)
plt.tight_layout()
plt.savefig("trial_r2_chart.png", dpi=150)
plt.show()

Running it on your own computer

Download the zip file and unzip it to a folder. The zip holds the programs in this series so far, the time_series.csv data file, and pyproject.toml. This note uses time_10.py. Open the folder in Visual Studio Code, then type these three lines in the terminal: 

uv python pin 3.12.10
uv sync
uv run time_10.py

The first line records which Python version this folder uses, and the second installs every package that pyproject.toml lists. The third line runs the twenty trials, which takes noticeably longer than earlier versions, and then opens the charts; close each window to continue. Two files are left behind: best_model.pt and search_results.xlsx.

Those three lines are needed only once. The next time you want to run the program again, type just uv run time_10.py.

If you have not set up uv yet, start with How to install Visual Studio Code? and then the uv note for Windows or Mac.

What comes next

The window length has stayed at 30 throughout, even though version 2 already showed how much it changes the shape of the examples. The next version adds it to the search space, so the program decides how far back to look as well.
