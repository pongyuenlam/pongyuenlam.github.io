How to make a web page listen to speech with speech recognition (version 2)?

Howard Pong Yuen Lam · AI Notes · November 27, 2026 · 5 min read

English 繁體中文 简体中文

A web page can listen. This one turns your voice into text on the screen: one HTML file with a short script, and no Python program of your own.

The page uses speech recognition, the other half of the Web Speech API. Chrome and Edge include it. Firefox does not.

There is one extra requirement. The page needs the microphone. The first time you click Start listening, the browser asks whether the page may use it; choose Allow.

What you need before you start

  • Chrome or Edge. Safari can also listen. Firefox cannot run this page.
  • A microphone. Most laptops have one built in.
  • An internet connection. Chrome sends the recorded sound to its speech service, which sends back the words.
  • A text editor. Visual Studio Code if you have it. If not, start with How to install Visual Studio Code?.

Step 1: Create the file

Download the zip file and extract it. On a Mac, double-click the zip. On Windows, right-click it and choose Extract All. You get a folder named Folder-AI-Speech-02-Speech-Recognition, holding index.html.

Step 2: Open the page

Option 1: this computer. Double-click index.html. It opens in your browser. No server is needed.

Option 2: your free website. Copy the HTML file into the folder for your free GitHub website, described in How to create a free website at your-username.github.io?, and upload the change. Then open the page at its https:// address in Chrome.

The file does not have to be named index.html. Any name works, and the name becomes the end of the link: a file called listen.html is reached at https://your-username.github.io/listen.html.

A file called index.html is special. It is the page a visitor sees first. So a file with that name would replace the home page of your website.

Step 3: The whole file

This is everything, in index.html:

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Listen</title>
</head>
<body>
<h1>Listen</h1>
<button onclick="startListening()">Start listening</button>
<button onclick="stopListening()">Stop</button>
<p>You said: <span id="result">nothing yet</span></p>
<script>
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
const recognition = new SpeechRecognition();
recognition.lang = 'en-US';
recognition.onresult = function (event) {
  document.getElementById('result').textContent = event.results[0][0].transcript;
};
function startListening() {
  recognition.start();
}
function stopListening() {
  recognition.stop();
}
</script>
</body>
</html>

The top half is an ordinary page: a heading, two buttons, and a line that shows the words. The words appear inside a span named result. Each button carries an onclick attribute naming the function to run when it is clicked.

Step 4: The names in the script

SpeechRecognition is the browser's listening engine. Chrome also offers it under an older name, webkitSpeechRecognition, so the first line takes whichever name the browser has. recognition.lang = 'en-US' tells the engine which language is being spoken.

recognition.onresult names the function to run when words arrive. event.results[0][0].transcript is the sentence as plain text, and textContent puts it on the page. Finally, start() opens the microphone and stop() closes it; those are what the two buttons call.

Step 5: Try it

Open the page in Chrome. Click Start listening. The browser asks for the microphone the first time; choose Allow. Say an English sentence, such as Hello, World!, and the words appear next to You said:.

Click Stop to finish early. If you say nothing for a moment, the page stops by itself; click Start listening again to say more.

Limitations

  • The microphone must be allowed. If the browser will not offer the microphone for a file on your computer, upload the page to your free website and open it there.
  • It needs the internet. Chrome sends the sound to its speech service and waits for the words to come back, so recognition does not work offline.
  • One phrase at a time. The page stops listening after a short pause. It does not keep listening in the background.
  • It is not perfect. Background noise, a strong accent and unusual names come back as the wrong words.
  • English only, in this version. The language is fixed at 'en-US', so Chinese speech is usually written down as unrelated English words.
