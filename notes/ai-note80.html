How to make a web page read text aloud with speech synthesis (version 1)?

Howard Pong Yuen Lam · AI Notes · November 26, 2026 · 4 min read

English 繁體中文 简体中文

Most browsers can already speak. A page does not need a server, a Python program or anything installed: one HTML file, opened by double-clicking, can read out whatever you type.

The page uses speech synthesis, one half of the Web Speech API that every modern browser includes.

What you need before you start

  • A browser. Chrome, Edge, Safari and Firefox all read text aloud.
  • A text editor. Visual Studio Code if you have it. If not, start with How to install Visual Studio Code?.
  • Sound turned on. The reading comes out of the computer's speakers.

Step 1: Create the file

Download the zip file and extract it. On a Mac, double-click the zip. On Windows, right-click it and choose Extract All. You get a folder named Folder-AI-Speech-01-Read-Aloud, holding index.html. Double-click index.html and it opens in your browser. There is no terminal to use and no server to start.

Step 2: The whole file

This is everything, in index.html:

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Read aloud</title>
</head>
<body>
<h1>Read aloud</h1>
<label for="text">Text:</label>
<textarea id="text" rows="3">Hello, World!</textarea>
<button onclick="speak()">Speak</button>
<button onclick="stopSpeaking()">Stop</button>
<script>
function speak() {
  speechSynthesis.cancel();
  const text = document.getElementById('text').value;
  const utterance = new SpeechSynthesisUtterance(text);
  speechSynthesis.speak(utterance);
}
function stopSpeaking() {
  speechSynthesis.cancel();
}
</script>
</body>
</html>

The top half is an ordinary page: a heading, a label, a textarea holding Hello, World!, and two buttons. A textarea is a box that accepts several lines, so a whole paragraph fits. Each button carries an onclick attribute naming the function to run when it is clicked.

Step 3: The three names in the script

Only three names matter. speechSynthesis is the browser's speech engine. SpeechSynthesisUtterance is one piece of text prepared for reading; a new one is created each time, because each carries its own words. speak() hands it to the engine.

speechSynthesis.cancel() stops anything still being read. It appears twice: once at the start of speak(), so a second click does not talk over the first, and once in stopSpeaking(), which is what the Stop button calls.

Step 4: Try it

Type an English sentence or a paragraph, click Speak, and the computer reads it. Click Stop to cut it short.

A Chinese sentence usually produces no sound. The page never tells the browser which language to speak, so the browser falls back to its default voice, which is usually English. How to name the language is explained under Limitations.

Limitations

  • The voice is chosen by the computer. The page does not say which language to speak, so the browser uses its default voice, usually English. Chinese text given to an English voice is normally skipped in silence. Naming the language for the text, for example with utterance.lang = 'zh-CN', is a separate topic.
  • Reading starts only after a click. Browsers keep pages silent until the visitor interacts with them; the Speak button provides that interaction.
  • Voices come from the device. Most systems read while offline because the voices are installed locally, but a few browsers use an online voice instead.
