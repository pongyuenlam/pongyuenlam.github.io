How to build a local website with Python and Flask (version 2)?

Howard Pong Yuen Lam · AI Notes · November 25, 2026 · 5 min read

English 繁體中文 简体中文

One quick way to make a website respond to a visitor is to add a text box and a button. Type a name, select Say Hello, and the page shows a greeting such as Hello Howard.

A small Python program receives the name and sends back the greeting. The page and the program are in two files: templates/index.html and app.py.

What you need before you start

  • Visual Studio Code, with a terminal. If it is not installed, start with How to install Visual Studio Code?.
  • uv, the tool that installs Flask: Windows or Mac.
  • A browser. You will open the address yourself.

Step 1: Get the project folder

Download the zip file and extract it to a folder. It contains app.py, templates/index.html, and pyproject.toml. Open the folder in Visual Studio Code.

In the terminal, record which Python version this folder uses. This line is needed only once: 

uv python pin 3.12.10

Then install Flask, also once:

uv sync

Step 2: Look at the Python program

This is the whole program, in app.py:

from flask import Flask, render_template, request, jsonify
app = Flask(__name__)
@app.route("/")
def index():
    return render_template("index.html")
@app.route("/greet", methods=["POST"])
def greet():
    data = request.get_json()
    user_name = data.get("user_name", "")
    return jsonify({"greeting": f"Hello {user_name}"})

The first route sends the page to the browser. The second route receives the name, adds it to Hello, and sends the greeting back. Each @app.route line connects an address to the function below it.

Step 3: Look at the page

This is templates/index.html:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Hello User</title>
</head>
<body>
    <h1>Hello User</h1>
    <input type="text" id="userName" placeholder="Your name">
    <button onclick="greetUser()">Say Hello</button>
    <p id="greeting"></p>
    <script>
        function greetUser() {
            const userName = document.getElementById("userName").value;
            fetch("/greet", {
                method: "POST",
                headers: {"Content-Type": "application/json"},
                body: JSON.stringify({user_name: userName})
            })
            .then(response => response.json())
            .then(data => {
                document.getElementById("greeting").textContent = data.greeting;
            });
        }
    </script>
</body>
</html>

The text box holds the name, and the button runs greetUser(). The script sends the name to /greet, receives the answer, and places it in the paragraph below the button.

Step 4: Run it

In the terminal:

uv run flask run

Flask finds app.py automatically and normally uses port 5000 each time. The terminal shows where the page is available: 

 * Debug mode: off
WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit

Copy and paste http://127.0.0.1:5000 into your browser’s address bar, or type it directly into the address bar. Enter a name and select Say Hello. The greeting appears below the button.

To stop the server, click the terminal and press two keys, Ctrl and C, at the same time. Next time, just type uv run flask run in the terminal.

Limitations

  • What user has entered, the name, is not saved. The program uses it to make one greeting and then forgets it.
  • An empty text box gives an incomplete greeting. The program does not check whether a name was entered.
  • It is a development server. Flask's own warning says not to use it in production. It is for building and trying the application on your computer.
