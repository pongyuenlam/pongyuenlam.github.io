How to install Homebrew Package Manager for macOS?

Howard Pong Yuen Lam · AI Notes · November 4, 2026 · 5 min read

Homebrew calls itself “The Package Manager for Everywhere”: it supports macOS (Sequoia 15 and newer), Linux, and Windows Subsystem for Linux (WSL). A package manager is a single command that downloads and installs other programs for you, so you do not have to hunt down websites and drag files into the Applications folder. With Homebrew, installing a tool like git or apps like Firefox, Chrome, etc. is one short line in the Terminal. This note covers macOS only.

What you need

  • A Mac running macOS Sequoia (15) or newer — these are the versions Homebrew officially supports. Older macOS versions may still work but are not guaranteed.
  • An internet connection.
  • Your Mac's administrator password — the installer needs permission to create its own folder. If you are the only user of your own Mac, then the administrator password is simply your password to enter when your Mac is locked.
  • The Terminal app, in Applications → Utilities (or type “Terminal” into Spotlight).

The install command

Open Terminal and paste this line from the official Homebrew page (as of the time of writing this AI Note): 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Press Return. The script explains what it will do, then pauses and asks for your password. Type your Mac's login password — you will not see the letters appear — and press Return again. The install can take several minutes; wait until the script finishes and prints “Installation successful!”.

Add Homebrew to your PATH

Right after the install, the script prints a few lines at the end that let your Mac find the brew command. This step is easy to overlook — but if you do, the Terminal will say command not found. Before you close the Terminal, scroll up to the last few lines the installer printed, copy them, and run them exactly as shown. You can view how to copy these few lines at the 1:20 mark in the video above. They already contain the right folder for your Mac's chip, so you do not have to guess between Apple Silicon and Intel.

Check it works

Close Terminal and open it again, then type:

brew --version

It prints a version number, something like Homebrew 4.4.0. If you see command not found: brew, the PATH step did not take effect — go back to the lines the installer printed, run them again, then restart Terminal.

Try it: install a tool and an app

One command installs everything, whether it is a command-line tool or a desktop app. To install a command-line tool such as wget: 

brew install wget

To install a desktop app such as the Firefox browser (it appears in your Applications folder): 

brew install firefox

To see what Homebrew can install, type brew search and then a name such as google. Homebrew then lists every tool and app whose name contains “google” — for example (as of the time of writing this AI Note): 

brew search google

To list the installed packages, type brew list: 

brew list

To update Homebrew itself: 

brew update

To upgrade a specific package, such as google-chrome: 

brew upgrade google-chrome

How to uninstall Homebrew?

To remove Homebrew, run the official uninstall script from the Homebrew/install repository (as of the time of writing this AI Note): 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/uninstall.sh)"

This removes the Homebrew folder and the brew command. It also uninstalls the command-line tools you installed with brew install. Desktop apps you installed (such as Firefox) may remain in your Applications folder and can be dragged to the Trash separately. If you are unsure, check the official FAQ.

Limitations

  • The PATH step is the one people miss. Without it, brew is not found even though it installed fine.
  • Apple Silicon and Intel use different folders. Always use the lines the installer printed, because they already match your Mac.
  • Requires internet every time you install or update a package. Speed or access may be limited in some countries/regions.
