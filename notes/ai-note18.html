How to install Homebrew Package Manager for macOS?

Howard Pong Yuen Lam · AI Notes · November 4, 2026 · 5 min read

Homebrew is a package manager for macOS. A package manager is a single command that downloads and installs other programs for you, so you do not have to hunt down websites and drag files into the Applications folder. With Homebrew, installing a tool like git or an app like Firefox is one short line in the Terminal. This note covers macOS only.

What you need

  • A Mac running macOS Sequoia (15) or newer — these are the versions Homebrew officially supports. Older macOS versions may still work but are not guaranteed.
  • An internet connection.
  • Your Mac's administrator password — the installer needs permission to create its own folder.
  • The Terminal app, in Applications → Utilities (or type “Terminal” into Spotlight).

The install command

Open Terminal and paste this line from the official Homebrew page: 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

Press Return. The script explains what it will do, then pauses and asks for your password. Type your Mac's login password — you will not see the letters appear — and press Return again. The install can take several minutes; wait until the script finishes and prints “Installation successful!”.

Add Homebrew to your PATH

Right after the install, the script prints a few lines that let your Mac find the brew command. This step is easy to skip — but if you do, the Terminal will say command not found. Copy the lines the installer shows you; it already prints the correct ones for your Mac's chip:

Apple Silicon (M1, M2, M3, M4) — Homebrew lives in /opt/homebrew: 

echo >> ~/.zprofile
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"

Intel — Homebrew lives in /usr/local: 

echo >> ~/.zprofile
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/usr/local/bin/brew shellenv)"

If you are unsure which chip you have, click the Apple menu → About This Mac. Apple Silicon Macs say “Chip”; Intel Macs say “Processor”.

Check it works

Close Terminal and open it again, then type:

brew --version

It prints a version number, something like Homebrew 4.4.0. If you see command not found: brew, the PATH step did not take effect — run the three lines for your chip again, then restart Terminal.

Try it: install a tool and an app

Homebrew has two kinds of packages. Formulae are command-line tools and libraries; casks are full desktop apps. To install a command-line tool: 

brew install wget

To install a desktop app (here, the Firefox browser) and have it appear in your Applications folder: 

brew install --cask firefox

To update Homebrew itself and upgrade everything you installed with it: 

brew update
brew upgrade

Limitations

  • Needs your admin password to create its folder and set up system links.
  • The PATH step is the one people miss. Without it, brew is not found even though it installed fine.
  • Apple Silicon and Intel use different folders. Always use the lines the installer printed, because they already match your Mac.
  • Requires internet every time you install or update a package.
