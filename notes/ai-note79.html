How to build a local website with Python and Flask (version 1)?

Howard Pong Yuen Lam · AI Notes · November 26, 2026 · 4 min read

English 繁體中文 简体中文

One quick way to see a web server in action is to create a single page that says “Hello, World!” A small Python program can respond to a browser request with those words.

This note follows the Flask Quickstart. The application has one file and five lines.

What you need before you start

  • Visual Studio Code, with a terminal. If it is not installed, start with How to install Visual Studio Code?.
  • uv, the tool that installs Flask: Windows or Mac.
  • A browser. You will open the address yourself.

Step 1: Get the project folder

Download the zip file and extract it to a folder. It contains app.py and pyproject.toml. Open the folder in Visual Studio Code.

In the terminal, record which Python version this folder uses. This line is needed only once: 

uv python pin 3.12.10

Then install Flask, also once:

uv sync

Step 2: Look at the five lines

This is the whole application, in app.py:

from flask import Flask
app = Flask(__name__)
@app.route("/")
def hello_world():
    return "<p>Hello, World!</p>"

The first line brings in Flask. The next line creates the application; __name__ tells Flask where this file is, so it can find related files. There are two underscores before and after name. The last three lines say what to do when someone opens the front page: run hello_world and send back Hello, World!. The <p> tags simply make it a paragraph.

Step 3: Run it

In the terminal:

uv run flask run

Flask finds app.py automatically. The terminal shows where the page is available: 

 * Debug mode: off
WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit

Copy and paste http://127.0.0.1:5000 into your browser’s address bar, or type it directly into the address bar. You should see Hello, World!.

To stop the server, click the terminal and press two keys, Ctrl and C, at the same time. Next time, just type uv run flask run in the terminal.

Limitations

  • The page is just text. This application does not allow user to enter anything and get response.
  • It is a development server. Flask's own warning says not to use it in production. It is for building and trying the application on your computer.
