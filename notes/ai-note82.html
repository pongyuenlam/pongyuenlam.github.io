How to make a web page speak a reply after it hears you (version 3)?

Howard Pong Yuen Lam · AI Notes · November 26, 2026 · 5 min read

English 繁體中文 简体中文

A web page can listen and talk on the same page. This one hears what you say, shows the words, and answers out loud. It is still one HTML file with one short script.

The page uses both halves of the Web Speech API: speech recognition to hear, and speech synthesis to answer. Chrome and Edge include both. Firefox includes neither.

The page needs the microphone, and browsers only lend the microphone to a page opened at a web address or at localhost. A file opened by double-clicking gets no microphone, so this page is opened from a website or from a local preview instead.

What you need before you start

  • Chrome or Edge. Firefox cannot run this page.
  • A microphone. Most laptops have one built in.
  • Speakers or headphones, with the sound on. The reply comes out of them.
  • An internet connection. Chrome sends the recorded sound to its speech service, which sends back the words.
  • A web address for the file. Either your free GitHub website, described in How to create a free website at your-username.github.io?, or a local preview, described in Step 2.
  • A text editor. Visual Studio Code if you have it. If not, start with How to install Visual Studio Code?.

Step 1: Create the file

Download the zip file and double-click it. A folder named Folder-AI-Speech-03-Speak-Reply is created, holding index.html.

Step 2: Open the page at a web address

Option 1: your free website. Copy index.html into the folder for your free GitHub website and upload the change. Then open the page at its https:// address in Chrome.

Option 2: a local preview. Open a terminal in the folder that holds index.html and start a small web server. On a Mac, type this line: 

python3 -m http.server 8000

On Windows, type this line instead:

py -m http.server 8000

Then open http://localhost:8000 in Chrome. Leave the terminal open while you use the page; it is what serves the file.

Step 3: The whole file

This is everything, in index.html:

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Answer</title>
</head>
<body>
<h1>Answer</h1>
<button onclick="startListening()">Start listening</button>
<button onclick="stopListening()">Stop</button>
<p>You said: <span id="heard">nothing yet</span></p>
<p>Reply: <span id="reply">nothing yet</span></p>
<script>
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
const recognition = new SpeechRecognition();
recognition.lang = 'en-US';
recognition.onresult = function (event) {
  const heard = event.results[0][0].transcript;
  document.getElementById('heard').textContent = heard;
  const reply = 'I heard you say: ' + heard;
  document.getElementById('reply').textContent = reply;
  speak(reply);
};
function startListening() {
  recognition.start();
}
function stopListening() {
  recognition.stop();
}
function speak(text) {
  speechSynthesis.cancel();
  const utterance = new SpeechSynthesisUtterance(text);
  speechSynthesis.speak(utterance);
}
</script>
</body>
</html>

The top half is an ordinary page: a heading, two buttons, and two lines. One line shows what the page heard; the other shows what it is about to say. Each button carries an onclick attribute naming the function to run when it is clicked.

Step 4: The names in the script

SpeechRecognition is the browser's listening engine. Chrome also offers it under an older name, webkitSpeechRecognition, so the first line takes whichever name the browser has. recognition.lang = 'en-US' tells the engine which language is being spoken.

recognition.onresult names the function to run when words arrive. event.results[0][0].transcript is the sentence as plain text. The next two lines put that sentence on the page and build the reply, 'I heard you say: ' + heard, which is the sentence with a short phrase in front.

speak(text) is the talking half. speechSynthesis.cancel() stops any earlier reply, SpeechSynthesisUtterance prepares the new text for reading, and speechSynthesis.speak() hands it to the engine. Finally, start() opens the microphone and stop() closes it.

Step 5: Try it

Open the page at its https:// address or at http://localhost:8000 in Chrome. Click Start listening, choose Allow when the browser asks for the microphone, and say an English sentence, such as Hello, World!.

The words appear next to You said:, and the computer then reads the reply out loud. Click Stop to close the microphone early. If you say nothing for a moment, the page stops by itself; click Start listening again to say more.

Limitations

  • A double-clicked file does not work. The microphone stays closed, so the page never hears anything. It must be opened from https:// or localhost.
  • The microphone must be allowed. If the answer was Block, the page hears nothing. Allow the microphone in the browser's site settings and reload.
  • The reply is an echo, not a conversation. The page repeats your words with a phrase in front. It does not understand them and has no AI model inside.
  • It needs the internet for the listening half. Chrome sends the sound to its speech service. The talking half usually works offline, because the voices are installed on the computer.
  • One phrase at a time. The page stops listening after a short pause, then answers once.
  • It is not perfect. Background noise, a strong accent and unusual names come back as the wrong words, and the reply repeats the mistake.
  • English only, in this version. The listening language is fixed at 'en-US', and the voice is the computer's default, which is usually English.
