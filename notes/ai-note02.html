How to unzip a file in Windows?

Howard Pong Yuen Lam · AI Notes · November 1, 2026 · 3 min read

Windows can open a .zip file on its own. Here are the steps.

Watch the demonstration

If the video does not load, open it in Google Drive (no account needed).

Unzip a .zip file

  1. Find the file in File Explorer. It shows a zipper icon on the folder.
  2. Right-click the file and choose Extract All…
  3. Pick a destination folder, then click Extract.
  4. Open the folder when Windows offers to show the extracted files.

“Extract All” creates a folder and puts the files inside it, so your original download stays tidy.

Two habits worth keeping

First, extract before editing. If you double-click an Office file inside a zipped folder, Windows opens a temporary copy and your edits can disappear when the file closes.

Second, keep the extracted folder separate from the original. That way you can delete the .zip later, or start over if an edit goes wrong, without losing anything you have already changed.
