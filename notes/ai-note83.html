How to get a link for a website with Tencent WorkBuddy?

Howard Pong Yuen Lam · AI Notes · November 26, 2026 · 3 min read

An HTML file on your computer has no web address that you can send to somebody else. To get one, the file must be hosted: a computer connected to the internet keeps the page and shows it to visitors.

The international version of Tencent WorkBuddy can do this from a conversation. Attach one HTML file, ask WorkBuddy to host it, and it returns a link. There is no terminal to open and no server to set up.

The example in this note is the listening page from How to make a web page listen to speech with speech recognition (version 2)?. You can open the hosted example to see the result.

What you need before you start

  • One HTML file. It should work when opened in a browser. The example file is named index.html.
  • Tencent WorkBuddy, international version. Open it at www.workbuddy.ai and sign in if the site asks.
  • An internet connection. WorkBuddy reads the file and puts the page online.

Step 1: Prepare the HTML file

Use your own file, or download index.html from the listening page note. Keep the file somewhere easy to find, such as the Desktop or Downloads folder.

This example is one self-contained file: its page and script are both inside index.html. There are no other files to upload.

Step 2: Attach the file in WorkBuddy

Start a new conversation in the international version of WorkBuddy. Use the attachment control to add index.html, just as you would attach a document or a picture.

Step 3: Ask WorkBuddy to host it

Send this message with the attached file:

read the attached html file, and let me know whether you can help host it online?

WorkBuddy reads the file and prepares an online copy. If its reply does not include a link, ask it to host the page and give you the web address.

Step 4: Copy and test the link

WorkBuddy returns a web address. For the example file, the address was: 

https://wbapp-p9pnbs1i3wmpuod8agncme.apps.workbuddy.host/?sharecode=ND6FKZWMKB

Open the whole address in a new browser tab. The page now comes from WorkBuddy's hosting service, not from a file on your computer. Test its buttons and other features before you send the link to anyone.

Copy the entire address, including the part after sharecode=. That complete address is the link to share. Visitors do not need you to send them the HTML file.

Limitations

  • WorkBuddy controls the address. It is not your own domain, and the hosting service can change. Keep the original HTML file so you can host it again if the link stops working.
  • Treat the shared page as public. Remove passwords, personal details and other private information from the file before uploading it.
  • This example is one HTML file. A site with separate images, style files or scripts needs those files as well. A Python website is different again because it needs a server that runs Python.
  • Hosting does not change what the page needs. The listening example still needs Chrome or Edge, microphone permission and an internet connection for speech recognition.
