How to install Visual Studio Code

Howard Pong Yuen Lam · AI Notes · November 1, 2026 · 4 min read

Visual Studio Code — VS Code for short — is a free Integrated Development Environment (IDE) from Microsoft. In plain terms, it is a single program that keeps your files together, lets you edit them, and shows AI help alongside the text. It is the editor I described in No-code, low-code, vibe coding, and coding. You install it once, and that takes only a few minutes on either Windows or Mac.

Watch the walkthrough

If the video does not load, open it in Google Drive: video (no account needed).

Download the installer

Go to code.visualstudio.com/download and pick the button for your computer. Microsoft publishes this page, and the download is free.

Install on Windows

Choose the Windows button on the download page and run the file that downloads. Accept the licence terms, then keep pressing Next until you reach Install and click it. The default options are fine.

Install on a Mac

Choose the Mac button on the download page — the chip named “Apple silicon” if you have a recent Mac, or “Intel” if you are unsure.

Double-click the downloaded file to unpack it, then drag Visual Studio Code into your Applications folder. Open it from Launchpad or Spotlight, the same way you open Word or Excel.

Check the install

Open Visual Studio Code. You should see a Welcome tab with a list of recent folders. That is all the setup you need; there is nothing else to configure yet.
