How to use LiveKit Voice Agent?

Howard Pong Yuen Lam · AI Notes · November 4, 2026 · 6 min read

A voice agent is an AI program that you can talk to in real time: you speak, it recognises your words (STT, speech-to-text), sends the text to a large language model (LLM), then turns the answer back into speech (TTS, text-to-speech). LiveKit is an open-source framework that ties these three pieces together over the internet, so your agent can run on a server and answer calls from a browser or a phone.

This note walks you through a minimal but complete voice agent in Python. The program greets you, tells you the weather (a demo tool), and can be deployed to LiveKit Cloud in minutes. You will need to type five commands in the Terminal.

What you need

  • A Mac (the same steps work on Windows and Linux too).
  • Homebrew installed and the uv package manager — if you do not have uv, run brew install uv.
  • A LiveKit Cloud account (the free Build plan is enough).
  • Your LiveKit Cloud credentials, which you copy into a file called .env — see below.

Set up LiveKit Cloud

Sign up at cloud.livekit.io. In the dashboard, click Projects → Create Project, then open the project and go to Keys. Copy the three values:

  • LIVEKIT_URL — looks like wss://your-project.livekit.cloud.
  • LIVEKIT_API_KEY — a short string like APIxxxxxxxxxxxxx.
  • LIVEKIT_API_SECRET — a longer string, shown only once.

In your project folder, create a file named .env with these three lines: 

LIVEKIT_URL=wss://your-project.livekit.cloud
LIVEKIT_API_KEY=APIxxxxxxxxxxxxx
LIVEKIT_API_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

Important: never put .env on GitHub or any public site — it contains your live credentials.

The five commands

Use Visual Studio Code or similar Integrated Development Environment (IDE) to open the folder, and run these five commands one by one. The first two tell uv to use Python 3.13. The third initialises a new project. The fourth installs the dependencies listed in requirements.txt. The fifth starts the agent. You only have to do these first four commands once and do not have to do them again the next time you want to run the agent in the fifth command. 

uv python install 3.13

Downloads Python 3.13. You only have to do it once and do not have to do it again the next time you want to run the LiveKit Voice Agent program.

uv python pin 3.13

Locks this project to Python 3.13 so team members get the same version. You also only have to do it once, and need not do it again the next time you want to run the LiveKit Voice Agent program.

uv init

Creates the pyproject.toml file that uv uses to manage your project.

uv add -r requirements.txt

Reads requirements.txt and installs every package listed there, including livekit-agents and python-dotenv. You do not have to run this command again unless you want to change the program and need to change the version of a package or need more packages.

uv run main.py console

Starts the agent in your Terminal so you can speak to it directly and listen to the agent's answer.

The Python files

Here are the two files you need before running the commands above. Paste them into your project folder first.

requirements.txt

livekit-agents>=1.8.4,<2
python-dotenv

main.py

from dotenv import load_dotenv
from livekit.agents import (
    Agent,
    AgentServer,
    AgentSession,
    JobContext,
    RunContext,
    cli,
    function_tool,
    inference,
)

load_dotenv()

@function_tool
async def lookup_weather(
    context: RunContext,
    location: str,
):
    """Used to look up weather information."""

    return {"weather": "sunny", "temperature": 70}


server = AgentServer()


@server.rtc_session()
async def entrypoint(ctx: JobContext):
    session = AgentSession(
        vad=inference.VAD(),
        stt=inference.STT("deepgram/nova-3", language="multi"),
        llm=inference.LLM("google/gemma-4-31b-it"),
        tts=inference.TTS("cartesia/sonic-3", voice="9626c31c-bec5-4cca-baa8-f8ba9e84c8bc"),
    )

    agent = Agent(
        instructions="You are a friendly voice assistant built by LiveKit.",
        tools=[lookup_weather],
    )

    await session.start(agent=agent, room=ctx.room)
    await session.generate_reply(instructions="greet the user and ask about their day")


if __name__ == "__main__":
    cli.run_app(server)

How main.py works, in plain words

STT, LLM, TTS. The AgentSession line wires three pieces together: speech is turned to text by Deepgram (deepgram/nova-3), text is answered by Google Gemma 4 (google/gemma-4-31b-it), and the answer is spoken by Cartesia (cartesia/sonic-3). All three run on LiveKit Cloud so you do not need separate API keys for each provider — a single LiveKit account covers them.

A tool function. The lookup_weather function is wrapped with @function_tool, which tells the LLM “you can call this function when the user asks about the weather.” Right now it returns a hard-coded answer ("sunny", 70°F); a real agent would call a weather API such as Open-Meteo.

A friendly greeting. After the session starts, generate_reply(instructions="greet the user and ask about their day") makes the agent speak the first thing, so callers hear a hello instead of silence.

Talk to your agent

With uv run main.py console running in your Terminal, the program will ask your Mac for microphone permission — click Allow. Then speak into your microphone: you should hear the agent greet you back, and you can continue the conversation freely. Press Ctrl+C when you want to stop.

If the Terminal does not print anything after you press play, or it shows an error about missing credentials, stop the server (Ctrl+C), check that .env is in the project folder, and run uv run main.py console again.

Limitations

  • You need a LiveKit Cloud account and real credentials in .env. The program will not start without them.
  • The free Build plan has limits: 1,000 session minutes per month, a $2.50 LiveKit Inference credit (about 50 minutes of calls), and cold starts — the first call after an idle period may take a few seconds to answer. Paid plans start at $50/month.
  • The demo weather tool is fake. It always returns sunny and 70°F. Replace it with a real API before using the agent for anything real.
