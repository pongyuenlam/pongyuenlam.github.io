How to use LiveKit and Synthesia Avatar (version 1)?

Howard Pong Yuen Lam · AI Notes · November 4, 2026 · 6 min read

A voice agent that answers only with text or a disembodied voice is useful — but an agent with a face feels much more like talking to a real person. Synthesia makes photorealistic AI avatars that speak and lip-sync in real time. LiveKit ties the avatar to the voice agent pipeline: microphone → speech recognition → LLM → text-to-speech → avatar.

This note shows you the smallest complete demo: a browser page with a video window, a single button, and an avatar called Lin who plays the host at a fictional restaurant and answers when it opens. It is version 1 — deliberately minimal so every line is easy to follow.

Watch the walkthrough

If the video does not load, open it in Google Drive: video (no account needed).

The pipeline

browser mic → VAD → STT → LLM → TTS → Synthesia avatar → browser video

Five pieces wired together over LiveKit's real-time transport. VAD (Voice Activity Detection) listens for when you start and stop talking, STT turns speech to text, LLM answers, TTS turns the answer in text back to speech, and Synthesia renders the face with lips that match the audio. All five run on LiveKit Cloud — no separate servers needed.

What you need

  • A Mac (the same steps work on Windows and Linux too).
  • Homebrew installed and the uv package manager — if you do not have uv, run brew install uv.
  • A LiveKit Cloud account (the free Build plan is enough).
  • A Synthesia account. You need at least one avatar created there (the free plan lets you try).
  • Your LiveKit and Synthesia credentials, which you copy into a file called .env — see below.

Set up LiveKit Cloud

Sign up at cloud.livekit.io. In the dashboard, click Projects → Create Project, then open the project and go to Keys. Copy the three values:

  • LIVEKIT_URL — looks like wss://your-project.livekit.cloud.
  • LIVEKIT_API_KEY — a short string like APIxxxxxxxxxxxxx.
  • LIVEKIT_API_SECRET — a longer string, shown only once.

Set up Synthesia

Sign in at app.synthesia.io. Go to Avatars and pick or create an avatar — each one has a UUID, shown in the URL when you open it (it looks like 3190429b-1eda-4151-bf24-96162e405840). Copy that as SYNTHESIA_AVATAR_ID.

Then go to API Keys and create a key — that is SYNTHESIA_API_KEY.

Create your .env

In your project folder, create a file named .env with these five lines: 

LIVEKIT_URL=wss://your-project.livekit.cloud
LIVEKIT_API_KEY=APIxxxxxxxxxxxxx
LIVEKIT_API_SECRET=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
SYNTHESIA_API_KEY=syn_xxxxxxxxxxxxxxxxxxxxxxxxxxxxx
SYNTHESIA_AVATAR_ID=3190429b-1eda-4151-bf24-96162e405840

Important: never put .env on GitHub or any public site — it contains your live credentials.

Running it on your own computer

Download the zip file and unzip it to a folder. The zip holds agent.py, server.py, index.html, and pyproject.toml. Add your own .env file with the keys, as shown above. Then open the folder in Visual Studio Code and run these two commands in two separate Terminal windows:

Terminal 1 — the voice agent + avatar engine: 

uv sync
uv run agent.py dev

Terminal 2 — the web server that serves the browser page: 

uv run server.py

uv sync only needs to run the first time — it installs Python 3.13 and every package. After that you just start the agent in one terminal and the server in the other.

Open the page in your browser

With both terminals running, open http://127.0.0.1:8080 in Chrome, Safari, or Edge. Click Start, allow microphone permission, and wait a few seconds while the agent and avatar join the room. You should see a video of Lin greeting you — click the microphone icon and ask a question, for example "When are you open?"

agent.py

import asyncio
import os
from pathlib import Path

from dotenv import load_dotenv
from livekit.agents import Agent, AgentSession, JobContext, WorkerOptions, cli, inference
from livekit.plugins import silero, synthesia

load_dotenv(dotenv_path=Path(__file__).parent / ".env")

AGENT_NAME = "avatar-demo"
AVATAR_ID = os.getenv("SYNTHESIA_AVATAR_ID") or "3190429b-1eda-4151-bf24-96162e405840"
VOICE_ID = "db6b0ed5-d5d3-463d-ae85-518a07d3c2b4"

INSTRUCTIONS = """\
You are Lin, the host at YouFantasy, a made-up restaurant. You are a real-time
avatar in a spoken conversation, so answer in one short sentence and never use
markdown, lists, or URLs.

YouFantasy is open every day from 9am to 10pm.

That is the only thing you know. If the guest asks about anything else, say
kindly that for now you can only help with our opening hours."""


def prewarm(proc) -> None:
    proc.userdata["vad"] = silero.VAD.load()


async def entrypoint(ctx: JobContext) -> None:
    await ctx.connect()

    session = AgentSession(
        vad=ctx.proc.userdata["vad"],
        stt=inference.STT(model="cartesia/ink-2"),
        llm=inference.LLM(model="openai/gpt-4.1-mini"),
        tts=inference.TTS(model="cartesia/sonic-3.6", voice=VOICE_ID),
        turn_handling={"turn_detection": "stt"},
    )

    avatar = synthesia.AvatarSession(
        synthesia.AvatarConfig(avatar_ids=[AVATAR_ID]),
        join_timeout=60.0,
    )
    for attempt in range(3):
        try:
            await avatar.start(session, room=ctx.room)
            break
        except synthesia.SynthesiaError as e:
            if not e.retryable or attempt == 2:
                raise
            await asyncio.sleep(2)

    await session.start(agent=Agent(instructions=INSTRUCTIONS), room=ctx.room)
    session.generate_reply(
        instructions="Welcome the guest to YouFantasy and invite them to ask about our opening hours, in one short sentence."
    )


if __name__ == "__main__":
    cli.run_app(WorkerOptions(entrypoint_fnc=entrypoint, prewarm_fnc=prewarm, agent_name=AGENT_NAME, port=8081))

server.py

import os
import uuid
from datetime import timedelta
from pathlib import Path

from aiohttp import web
from dotenv import load_dotenv
from livekit import api

load_dotenv(dotenv_path=Path(__file__).parent / ".env")

AGENT_NAME = "avatar-demo"


async def token(request: web.Request) -> web.Response:
    room = f"avatar-demo-{uuid.uuid4().hex[:8]}"
    jwt = (
        api.AccessToken()
        .with_identity(f"user-{uuid.uuid4().hex[:8]}")
        .with_ttl(timedelta(minutes=15))
        .with_grants(api.VideoGrants(room_join=True, room=room))
        .with_room_config(
            api.RoomConfiguration(
                sync_streams=True,
                agents=[api.RoomAgentDispatch(agent_name=AGENT_NAME)],
            )
        )
        .to_jwt()
    )
    return web.json_response({"url": os.environ["LIVEKIT_URL"], "token": jwt})


async def index(request: web.Request) -> web.FileResponse:
    return web.FileResponse(
        Path(__file__).parent / "index.html", headers={"Cache-Control": "no-store"}
    )


app = web.Application()
app.router.add_get("/", index)
app.router.add_get("/token", token)

if __name__ == "__main__":
    web.run_app(app, host="127.0.0.1", port=8080)

How it works, in plain words

Two programs, two terminals. agent.py is the voice + avatar engine — it joins a LiveKit room, listens to the microphone, answers, and drives the avatar. server.py is a tiny aiohttp web server that serves the page and, on each visit, mints a short-lived LiveKit access token (so you do not embed credentials in HTML). You start both separately because they each own their own port.

The browser knows nothing about avatars. index.html just joins a LiveKit room and plays every video track that arrives — it does not care whether the track comes from a real webcam or a Synthesia avatar. The avatar streams itself from inside the agent, and sync_streams=True in the room config keeps its lips aligned with the audio track.

Cold start retries. The Synthesia service occasionally takes a few seconds to spin up an avatar session, so the agent retries up to three times before giving up. That is why clicking Start can feel slow the first time — it is not broken, just warming up.

Limitations (version 1)

  • Lin only knows opening hours. The whole knowledge base is one paragraph in INSTRUCTIONS. That is on purpose — version 1 is about wiring the pieces, not knowledge. Later versions can add tools, a database, or RAG.
  • You need three accounts (LiveKit, Synthesia, Cartesia). LiveKit Cloud covers STT, LLM, and TTS, but Synthesia is a separate subscription. At time of writing Synthesia charges for avatar minutes.
  • Two-terminal workflow. You have to start agent.py and server.py separately. That is fine for demos, but a production deployment would bundle them behind a single supervisor or run them on LiveKit Cloud Agents alone.
  • The web server has no authentication. server.py generates a fresh room token for every visitor with no login. Fine for local testing; never deploy this as-is to the public internet.
