如何顯示資料夾裡的每一張人臉照片（人臉辨識，版本 1）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 4 分鐘閱讀

這是九篇系列的第一篇。這個系列一步一步搭出一個能認出鏡頭前是誰的程式。 版本 1 裡完全沒有 AI。它打開一個裝滿照片的資料夾，把照片一張一張顯示出來， 並印出照片裡那個人的名字。這樣安排是有原因的：電腦要認出人臉，先要能找到檔案、 打得開照片。

名字從哪裡來？

人臉辨識程式必須知道誰是誰。你可以另外打一份名單，但那等於多了一件要跟照片同步的事。 這個系列改用檔名。資料夾裡如果有 Howard.JPG、Mary.jpg 和 Paul.jpg，程式就已經知道三個名字，需要的時候直接從檔名讀出來就行。

這也是程式最後三行只印出 Howard 的原因——前面不帶 images/ 這個資料夾，後面不帶 .JPG 這個副檔名。這裡印出來的東西，就是後面幾個版本 貼在人臉旁邊的標籤。

程式怎麼運作

1. 載入三個函式庫

import cv2
import os
import glob

cv2 是 OpenCV，負責打開和顯示圖片。 os 負責電腦的檔案和資料夾，並且知道你的電腦在資料夾之間用的是 / 還是 \。glob 負責按規則找檔案——程式不用事先知道照片叫什麼名字， 就能把它們找出來。

2. 列出資料夾裡的每一個檔案

images_folder = "images"
images_path = glob.glob(os.path.join(images_folder, "*.*"))

第一行記下資料夾的名字。第二行用 os.path.join 組合出 images/*.* 這個規則——任何名字，一個點，任何副檔名。用 os.path.join 而不是自己打斜線，是為了在 Mac 和 Windows 上都正確。 然後 glob.glob 會回傳所有符合條件的路徑，例如 ["images/Howard.JPG", "images/Mary.jpg", "images/Paul.jpg"]。

*.* 很方便，但也不挑食：在 Mac 上它連 .DS_Store 這類雜物 都會抓進來。遇到這種情況，程式只是讀不到那一個檔案然後繼續，你也可以把這個雜物檔案刪掉。

3. 數一數有幾張照片

print("{} images in folder".format(len(images_path)))

len() 就是 length（長度），用來數清單裡有幾個路徑。{} 是佔位符，由 .format() 填進去，所以畫面會先顯示 3 images in folder。如果這個數字是 0，說明資料夾名字寫錯了，或者照片放在 別的地方——這時候先把它修好，再往下讀。

4. 每張照片顯示一秒

for img_path in images_path:
    img = cv2.imread(img_path)
    cv2.imshow("image", img)
    cv2.waitKey(1000)

for 那一行把路徑一個一個拿出來，下面縮排的部分每張照片執行一次。 cv2.imread 把檔案讀進 img，那是一格一格的像素值， 後面的版本就是在這個格子裡找出人臉。cv2.imshow 把它顯示在標題為 "image" 的視窗裡，cv2.waitKey(1000) 讓它停留 1000 毫秒， 也就是一秒，然後下一張照片才替換上來。

一秒夠你看清照片，也短到能一張張看完整個資料夾。把數字調大，幻燈片就慢下來。

5. 印出檔名裡的名字

    basename = os.path.basename(img_path)
    (filename, ext) = os.path.splitext(basename)
    print(filename)

os.path.basename 去掉資料夾，images/Howard.JPG 變成 Howard.JPG。os.path.splitext 把名字和副檔名拆成兩段， Howard 和 .JPG，分別存進 filename 和 ext。最後一行在他的照片還顯示著的時候，印出 Howard。

完整程式

把上面的片段拼回去，就是完整的檔案，一共 13 行： 

import cv2
import os
import glob
images_folder = "images"
images_path = glob.glob(os.path.join(images_folder, "*.*"))
print("{} images in folder".format(len(images_path)))
for img_path in images_path:
    img = cv2.imread(img_path)
    cv2.imshow("image", img)
    cv2.waitKey(1000)
    basename = os.path.basename(img_path)
    (filename, ext) = os.path.splitext(basename)
    print(filename)

在自己的電腦上執行

下載壓縮檔，解壓到一個 資料夾。壓縮檔裡是這個系列全部九個程式、裝著三張照片的 images 資料夾， 以及 pyproject.toml。這一篇用的是 face01.py。用 Visual Studio Code 打開這個資料夾，然後在終端輸入下面三行： 

uv python pin 3.12.10
uv sync
uv run face01.py

第一行記下這個資料夾使用的 Python 版本，第二行按 pyproject.toml 安裝所有 套件，第三行顯示第一張照片。想換成自己的照片，就把 images 裡的檔案替換掉， 並用那個人的名字當檔名，例如 Anna.jpg。

這三行只需要做一次。下次想再執行這個程式，只需輸入 uv run face01.py。

如果你還沒裝好 uv，請先讀如何安裝 Visual Studio Code？， 再看 uv 那一篇：Windows 或 Mac。
