如何用 Python 和 Flask 建立本機網站（版本 1）？

林邦源 · AI 筆記 · 2026年11月26日 · 閱讀時間約 4 分鐘

English 繁體中文简体中文

要快速看到網頁伺服器如何運作，可以建立一個只顯示「Hello, World!」的頁面。一個小型 Python 程式便能以這句話回應瀏覽器的請求。

本文跟隨 Flask Quickstart。 整個應用程式只有一個檔案、五行代碼。

開始前需要甚麼

  • Visual Studio Code，並可使用終端機。如尚未安裝，請先看 如何安裝 Visual Studio Code？
  • uv，用來安裝 Flask 的工具： Windows 或 Mac。
  • 瀏覽器。你需要自行開啟網址。

步驟 1：取得專案資料夾

下載 zip 檔案並解壓到一個資料夾。 內有 app.py 和 pyproject.toml。用 Visual Studio Code 開啟該資料夾。

在終端機記錄這個資料夾使用的 Python 版本。這行只需執行一次：

uv python pin 3.12.10

然後安裝 Flask，同樣只需一次：

uv sync

步驟 2：查看這五行

以下是 app.py 的全部程式：

from flask import Flask
app = Flask(__name__)
@app.route("/")
def hello_world():
    return "<p>Hello, World!</p>"

第一行匯入 Flask。下一行建立應用程式；__name__ 告訴 Flask 這個檔案的位置， 讓它找到相關檔案。name 前後各有兩條底線。最後三行指定有人開啟首頁時要做的事： 執行 hello_world，並回傳 Hello, World!。<p> 標籤只是把它放進一個段落。

步驟 3：執行程式

在終端機輸入：

uv run flask run

Flask 會自動尋找 app.py。終端機會顯示頁面網址：

 * Debug mode: off
WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit

把 http://127.0.0.1:5000 複製並貼到瀏覽器的網址列，或直接輸入網址列。你應會看到 Hello, World!。

要停止伺服器，請按一下終端機，然後同時按 Ctrl 和 C 兩個鍵。 下次只需在終端機輸入 uv run flask run。

限制

  • 頁面只有文字。這個應用程式不讓使用者輸入任何內容並取得回應。
  • 這是開發用伺服器。Flask 的警告訊息明確指出不要把它用於正式環境； 它是讓你在自己的電腦上建立及試用應用程式。
