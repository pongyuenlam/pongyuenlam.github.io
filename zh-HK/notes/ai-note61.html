人臉比對應有多嚴格（人臉辨識，版本 9）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 6 分鐘閱讀

版本 8 處理速度。最後一個版本處理一個更安靜的問題：版本 8 判斷兩張臉是不是同一個人， 用的數字不是任何人選的。函式庫的預設值是 0.6，那是一個合理的猜測，不是一個決定。 版本 9 把它變成一個決定：給這個數字起名，並把它搬到檔案頂部的一個地方。

從版本 8 改了兩行。就這樣。改動小，是因為這個旋鈕一直都在；它只是藏在函式庫的預設值裡。

一個數字，兩種錯誤

匹配一張臉會產生一個距離：這張臉離一個已知的臉有多遠，用 128 個數字來量。零就是完全相同。 容差是那條界線——任何高於它的距離都被當成另一個人。

轉動這個旋鈕，兩種錯誤會朝相反方向移動，沒有任何設定能讓兩者同時消失：

  • 太鬆 — 陌生人被安上最像的那個人的名字。螢幕自信地顯示錯誤的人。
  • 太嚴 — 對的人被拒絕，因為同一張臉從來不會兩次拍得一模一樣。 螢幕對一個它認識的人顯示 Unknown。

哪種錯誤更要緊，是關於用途的問題，不是關於程式碼的問題。一扇絕對不能讓錯的人打開的門， 要嚴的設定。一個應該找出朋友每一張相片的相片庫，鬆一點也無妨。

1. 把容差設一次

images_folder = "images"
my_tolerance = 0.5  # 函式庫預設值是 0.6

這個變數和其他設定放在一起，在資料夾搜尋上面，所以容易找到，也容易改。# 後面的文字是註解：Python 忽略它，它留在檔案裡，告訴下一個讀的人：沒有這一行時，數字會是多少。 把預設值這樣擺出來，比記住它便宜。

2. 把這個數字傳給 compare_faces

        matches = face_recognition.compare_faces(known_face_encodings, face_encoding, tolerance=my_tolerance)

那一行裡其他東西都是版本 7 的工作。加的是 tolerance=my_tolerance： 等號左邊的名字是 compare_faces 內部的設定，必須一字不差地寫成這樣； 等號右邊是上面設的變數。

注意下一行的 face_distance 沒有動。它沒有容差，因為它只報距離； 多遠的距離可以接受，這個決定屬於 compare_faces。所以兩行是一致的： 距離量一次，同一個界線套在它們上面。

距離大概是什麼樣子

編碼向量的長度大約是 1，所以實際上距離很少超過 1.2。典型的值：

  • 0 — 兩張完全相同的相片。
  • 大約 0.3–0.5 — 同一個人的兩張相片，拍攝時間不同。
  • 大約 0.7 以上 — 兩個不同的人。

所以有用的設定大致落在 0.4 到 0.7 之間：

  • 0.4–0.5 — 嚴格。錯誤的姓名更少，Unknown 更多。
  • 0.6 — 函式庫的預設值，也是函式庫自己的文件推薦的起點。
  • 0.7 以上 — 寬鬆。陌生人開始從資料夾裡借名字。
  • 1.0 以上 — 幾乎什麼都匹配，等於完全不檢查。

函式庫的建議和這張表一致：如果兩個不同的人被報成同一個人，就把數字調低。

容差和縮放會互相拉扯

版本 8 在編碼之前把畫面縮到一半，這要付出細節，也把距離推高一點。版本 9 又把界線收緊。 兩件都做，效果會疊加：一張在 0.6 預設值下以 0.57 通過的臉，現在可能坐在 0.62，在 0.5 下面失敗。

所以這兩個設定應該一起選。如果你收緊了容差，對的人卻一直顯示 Unknown， 先把 scale_ratio 調高靠近 1.0，再考慮放鬆容差。 靠保留更多像素來恢復準確率，通常比靠接受更弱的證據來恢復更好。

完整程式

版本 1 的下載裡已經有這個檔案。和版本 8 相比，多了一行，還有一行多了一個設定； 後面每一行的行號都往後挪了一位。 

import face_recognition
import cv2
import os
import glob
import numpy as np
images_folder = "images"
my_tolerance = 0.5 # 函式庫預設值 = 0.6
images_path = glob.glob(os.path.join(images_folder, "*.*"))

known_face_encodings=[]
known_face_names=[]
for img_path in images_path:
    img = cv2.imread(img_path)
    rgb_img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    basename = os.path.basename(img_path)
    (filename, ext) = os.path.splitext(basename)
    img_encoding = face_recognition.face_encodings(rgb_img)[0]
    known_face_encodings.append(img_encoding)
    known_face_names.append(filename)

cap = cv2.VideoCapture(0)
scale_ratio = 0.5
multiple = int(1 / scale_ratio)
ret, img = cap.read()
width=int(img.shape[1]*scale_ratio)
height=int(img.shape[0]*scale_ratio)
dim=(width,height)

while True:
    ret, img = cap.read()
    resized=cv2.resize(img,dim,interpolation=cv2.INTER_NEAREST)
    rgb_img = cv2.cvtColor(resized,cv2.COLOR_BGR2RGB)
    face_locations = face_recognition.face_locations(rgb_img)
    face_encodings = face_recognition.face_encodings(rgb_img, face_locations)

    face_names = []
    for face_encoding in face_encodings:
        matches = face_recognition.compare_faces(known_face_encodings, face_encoding, tolerance=my_tolerance)
        name = "Unknown"
        face_distances = face_recognition.face_distance(known_face_encodings, face_encoding)
        best_match_index = np.argmin(face_distances)
        if matches[best_match_index]:
            name = known_face_names[best_match_index]
        face_names.append(name)

    for face_loc, name in zip(face_locations, face_names):
        y1, x2, y2, x1 = face_loc[0], face_loc[1], face_loc[2], face_loc[3]
        y1=y1*multiple
        x2=x2*multiple
        y2=y2*multiple
        x1=x1*multiple
        cv2.putText(img, name, (x1, y1 - 10), cv2.FONT_HERSHEY_DUPLEX, 1, (0, 200, 0), 2)
        cv2.rectangle(img, (x1, y1), (x2, y2), (0, 200, 0), 4)

    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break

cap.release()
cv2.destroyAllWindows()

先加上你自己的相片

和之前一樣，只有當 images 資料夾裡有那個名字的檔案時，臉才會被叫出名字， 例如 Peter.jpg。沒有它，不管容差是多少，每張臉都是 Unknown。

在自己的電腦上執行

用和版本 1 相同的下載： 下載 zip 檔案，解壓， 在 Visual Studio Code 裡打開資料夾。這篇筆記用的是 face09.py。 在這個資料夾裡第一次執行時，三行都跑： 

uv python pin 3.12.10
uv sync
uv run face09.py

這三行只需要一次。下次想再執行程式，只打 uv run face09.py。

整個系列一眼看完

  • 版本 1 — 顯示資料夾裡的每一張相片。
  • 版本 2 — 把每張相片變成 128 個數字，把檔名留作標籤。
  • 版本 3 — 給一張相片裡的人臉命名。
  • 版本 4 — 在視窗裡顯示鏡頭。
  • 版本 5 — 顯示之前先改動一格影格。
  • 版本 6 — 在影格上畫一個框和一個標籤。
  • 版本 7 — 即時辨識並命名人臉。
  • 版本 8 — 只搜尋四分之一的像素，換取速度。
  • 版本 9 — 選擇匹配要多嚴格。

九個小程式，每一個都是能用一句話說清楚的一步。拼在一起，它們是一台能叫出面前是誰的鏡頭； 而同一個模式——列一串數字、比對、決定、把決定畫出來——也躺在遠大於它們的系統底下。
