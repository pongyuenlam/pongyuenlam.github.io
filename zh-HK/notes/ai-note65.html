如何把每個視窗拆成特徵與目標值（預測，版本 4）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 5 分鐘閱讀

這是預測系列的第 4 個版本，也是訓練開始之前的最後一個版本。版本 4 把每個視窗切成兩部分： 特徵，就是模型被允許看的日子；以及目標值，就是它必須猜的 那一天。

特徵與目標值

取一個 30 天的視窗。頭 29 天是模型會看到的；第 30 天是它必須預測的。這把每個視窗變成一個 訓練例子。這兩部分有值得記住的名字，因為之後每一個版本都會用到它們：

  • 特徵 — 29 個已知的日子。輸入。
  • 目標值 — 第 30 天。模型被評分對照的答案。

因為每個視窗裡最後一個銷售值被當作目標值，一個 30 天的視窗產生 29 個特徵，而不是 30 個。 這就是為什麼 29 在整個程式裡出現。

程式怎樣運作

1. 匯入 torch、它的資料工具，以及 pandas

import torch
from torch.utils.data import TensorDataset, DataLoader
import pandas as pd

TensorDataset 把特徵與目標值配對。DataLoader 把這些配對分批 送給模型。pandas 讀取 CSV 檔案。

2. 在一個函式裡切割並分拆

def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    row_n = windows.shape[0]
    col_n = windows.shape[1]
    features = windows[0:row_n, 0:col_n-1]  # All columns except the last
    targets = windows[0:row_n, col_n-1:col_n]   # Just the last column
    return features, targets

第一行是版本 3 的切割，沒有改動。windows.shape 接着報告結果的大小： row_n 是有多少個視窗，col_n 是每個視窗有多長。

接下來兩行做分拆。windows[0:row_n, 0:col_n-1] 意思是 每一列、由第 0 欄到但不包括最後一欄，那就是 29 個已知的日子。 windows[0:row_n, col_n-1:col_n] 意思是每一列、只有最後一欄， 那就是答案。每行上的註解用更少的字說同一件事，而最後一行把特徵和目標值交回。

3. 載入真實的銷售檔案

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30

頭兩行帶來 1,460 個每日銷售數字。第三行把它們由普通陣列轉成 PyTorch 張量，那只是 PyTorch 用來做計算的格式，而 dtype=torch.float32 讓每個數字變成十進位而不是整數 —— 這是必須的， 因為銷售數字有仙（小數）。

4. 建立例子的資料集

features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
dataset = TensorDataset(features, targets)
batch_size = 32
train_loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

第一行呼叫函式 create_sliding_windows_with_target，給我們兩個清單， features 和 targets。第一個清單裝着 29 天的輸入，第二個裝着 對應的答案。TensorDataset 把每個輸入與它自己的答案放在一起。 DataLoader 接着把例子以 32 個一組交給模型，而不是一次過給 1,431 個。 設定 shuffle=True 會在模型每次看到例子時改變它們的順序，所以它從銷售數值 學習，而不是記住它們的日期順序。

5. 印出建立了什麼

print(f"Series length: {len(series)}")
print(f"Number of windows: {len(features)}")
print(f"Feature shape: {features.shape}")
print(f"Target shape: {targets.shape}")

這四行是一個值得仿效的習慣：在訓練任何東西之前，先印出形狀。如果這裡的數字錯了，下面 每一個結果也都錯了，而現在發現這件事的代價是一次執行，而不是一個下午。

6. 偷看三個例子

for i in range(3):
    print(f"\nWindow {i+1}:")
    print(f"Features (previous {window_size-1} days): {[f'{x:.2f}' for x in features[i].numpy()]}")
    print(f"Target (next day): {targets[i].item():.2f}")

迴圈執行三次，頭三個例子各一次。在裡面，第一個 print 為例子加上標籤， 第二個印出四捨五入到兩位小數的 29 個特徵，第三個印出那一個目標值。大括號裡的 :.2f 意思是顯示兩位小數。

你應該會看到

Series length: 1460
Number of windows: 1431
Feature shape: torch.Size([1431, 29])
Target shape: torch.Size([1431, 1])

First few windows:

Window 1:
Features (previous 29 days): ['29.40', '33.41', '37.86', ... '27.24', '28.71']
Target (next day): 27.08

數列有 1,460 天，而每個視窗覆蓋其中 30 天。第一個視窗包含第 [1, 2, 3, ..., 30] 天，第二個包含第 [2, 3, 4, ..., 31] 天， 如此類推，每個視窗都比前一個遲一天開始。

你可以由一個視窗的結束日算出它的開始日： 開始日 = 結束日 − 30 + 1。第二個視窗在第 31 天結束，所以它在第 31 − 30 + 1 = 2 天開始。最後一個視窗在第 1,460 天結束，所以它在第 1,460 − 30 + 1 = 1,431 天開始。因此視窗由第 1 天、第 2 天開始， 一直增加到 1,431，總共 1,431 個視窗。

每個視窗變成一個訓練例子。它的頭 29 個值是輸入，最後一個值是目標值。這就是為什麼特徵形狀 是 [1431, 29]，而目標形狀是 [1431, 1]：有 1,431 個例子， 每個有 29 個輸入和 1 個答案。

完整程式

把上面的各部分放回一起。這就是完整的檔案，共 27 行： 

import torch
from torch.utils.data import TensorDataset, DataLoader
import pandas as pd
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    row_n = windows.shape[0]
    col_n = windows.shape[1]
    features = windows[0:row_n, 0:col_n-1]  # All columns except the last
    targets = windows[0:row_n, col_n-1:col_n]   # Just the last column
    return features, targets
df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
dataset = TensorDataset(features, targets)
batch_size = 32
train_loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)
print(f"Series length: {len(series)}")
print(f"Number of windows: {len(features)}")
print(f"Feature shape: {features.shape}")  # Should be (num_windows, window_size-1)
print(f"Target shape: {targets.shape}")    # Should be (num_windows, 1)
print("\nFirst few windows:")
for i in range(3):
    print(f"\nWindow {i+1}:")
    print(f"Features (previous {window_size-1} days): {[f'{x:.2f}' for x in features[i].numpy()]}")
    print(f"Target (next day): {targets[i].item():.2f}")

在自己的電腦上執行

下載 zip 檔案並解壓到 一個資料夾。zip 裡有這個系列到目前為止的程式、time_series.csv 資料檔， 以及 pyproject.toml。這篇筆記用的是 time_04.py。在 Visual Studio Code 裡打開資料夾，然後在終端機輸入這三行： 

uv python pin 3.12.10
uv sync
uv run time_04.py

第一行記錄這個資料夾用哪個 Python 版本，第二行安裝 pyproject.toml 列出的 每一個套件。第三行在終端機印出四個計數和三個例子視窗。

這三行只需要一次。下次想再執行程式，只打 uv run time_04.py。

如果你還沒有設定 uv，先看 如何安裝 Visual Studio Code？，然後看 uv 筆記的 Windows 或 Mac。

接下來是甚麼

資料集存在了，但還沒有任何東西從它學習。版本 5 把兩行切片的程式碼整理成更短的形式， 而版本 6 把例子分成訓練部分和驗證部分，好讓進度可以在模型未見過的日子上量度。
