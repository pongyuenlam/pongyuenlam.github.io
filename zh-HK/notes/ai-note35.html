如何為 AI 代理建立時間工具？

林邦源博士 · AI 筆記 · 2026 年 11 月 8 日 · 約 3 分鐘閱讀

AI 代理能夠規劃、起草和推理，卻不知道當下的時間和日期。它對「現在」的概念 來自訓練時讀過的文本，所以你問它今天是幾號，它可能會叫你自己去查。任何依賴 時間的事情，在代理得到一個「查看」的方法之前，都不可靠。

工具就是那個方法：一個代理獲准呼叫的普通函數。本篇筆記建立 一個最小的實用工具 — 一個回傳當前日期和時間的函數 — 並在牽涉任何 代理之前先測試它。整個工具只有九行 Python。

工具

這是 tool01_time.py 目前的內容：

from datetime import datetime
def get_current_time():
    """
    Returns the current date and time as a string.
    """
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")
result = get_current_time()
print(result)

每一部分的作用

  • datetime 是 Python 內建的，無需安裝任何東西。
  • get_current_time() 不接受任何參數。這是刻意的：沒有參數的 工具，是模型最容易正確呼叫的一種。
  • docstring 不是裝飾。當這個函數交給代理使用時，這句話就成為模型決定是否 呼叫它之前所讀到的描述。“Returns the current date and time as a string” 既說明會回傳甚麼，也說明甚麼時候值得呼叫這個工具。
  • strftime — string format time 的縮寫 — 把 datetime 轉成文字，而 strftime("%Y-%m-%d %H:%M:%S") 固定了格式，例如 2026-11-08 14:32:07。固定格式很重要，因為模型會把這個值引用 給使用者，也可能把它拆成日期和時間兩部分。
  • 最後兩行呼叫函數並印出結果，讓你在還未牽涉任何代理之前，就可以在終端機 檢查這個工具。

單獨測試

執行這個檔案：

python tool01_time.py

你應該會看到一行，例如 2026-11-08 14:32:07。這是執行腳本那台 電腦的時鐘。如果腳本放在其他地區的伺服器上，你得到的是伺服器的本地時間， 不是你的時間。

為甚麼這是好的第一個工具

  • 沒有參數，模型沒有出錯的空間。
  • 只讀：它不能改檔案、發訊息或花錢。
  • 容易核對：跟自己螢幕上的時鐘比較即可。
  • 即時有用：它修正了代理每一個與日期有關的答案。

延伸閱讀
