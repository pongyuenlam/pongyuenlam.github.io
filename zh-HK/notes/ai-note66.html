如何用冒號縮短切片（預測，版本 5）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 4 分鐘閱讀

這是預測系列的第 5 個版本。與版本 4 相比，唯一的改動是兩行：它們用簡寫產生同樣的特徵和目標值。

一個沒有改變任何看得見的東西的版本，仍然值得寫下來，因為這種簡寫幾乎會出現在你之後讀到的每個 Python 程式裡，也常常出現在其他開發者寫的 Python 程式裡。學會解讀它一次，之後就能省下很多次 困惑。

同一件事的兩種說法

版本 4 是這樣完整地寫的： 

row_n = windows.shape[0]
col_n = windows.shape[1]
features = windows[0:row_n, 0:col_n-1]
targets = windows[0:row_n, col_n-1:col_n]

版本 5 用簡寫說同一件事： 

features = windows[:, :-1]
targets = windows[:, -1:]

長寫法的每一部分都還在，只是變成隱含的。
0:row_n 的意思是每一行，所以變成單獨一個 :。
0:col_n-1 的意思是除最後一欄以外的所有欄，所以變成 :-1。
而 col_n-1:col_n 的意思是只有最後一欄，所以變成 -1:。

怎樣讀一個冒號和一個負一

1. 單獨一個冒號代表「全部」

windows[:, :-1]

方括號裡面有兩個位置，用逗號分開：先是行，後是欄。行那個位置上單獨的冒號說取每一行， 所以 1,431 個例子全部保留。

2. 負一由尾開始數

windows[:, :-1]
windows[:, -1:]

負數是倒着數的：-1 是最後一項，-2 是它前面那一項。所以 :-1 的意思是由開始直到最後一欄之前，但不包括最後一欄 — 那 29 個已知的日子。而 -1: 的意思是由最後一欄到最後 — 那個要被預測的日子。

3. 檔案其餘部分沒有改動

讀取 CSV、轉成 tensor、建立資料集和載入器、印出四個數目和三個例子 — 全部都和版本 4 一樣。 只有函式裡面那兩行切片改了。

你應該會看到甚麼

Series length: 1460
Number of windows: 1431
Feature shape: torch.Size([1431, 29])
Target shape: torch.Size([1431, 1])

和之前一樣的四個數目，後面跟着同樣的三個例子視窗。

完整程式

把上面的各部分放回一起： 

import torch
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    features = windows[:, :-1]  # All columns except the last
    targets = windows[:, -1:]   # Just the last column
    return features, targets

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
# Create PyTorch Dataset and DataLoader
dataset = TensorDataset(features, targets)
batch_size = 32
train_loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

# Print some information about the dataset
print(f"Series length: {len(series)}")
print(f"Number of windows: {len(features)}")
print(f"Feature shape: {features.shape}")  # Should be (num_windows, window_size-1)
print(f"Target shape: {targets.shape}")    # Should be (num_windows, 1)

# Show a few examples
print("\nFirst few windows:")
for i in range(3):
    print(f"\nWindow {i+1}:")
    print(f"Features (previous {window_size-1} days): {[f'{x:.2f}' for x in features[i].numpy()]}")
    print(f"Target (next day): {targets[i].item():.2f}")

在自己的電腦上執行

下載 zip 檔案並解壓到一個 資料夾。zip 裡有這個系列到目前為止的程式、time_series.csv 資料檔，以及 pyproject.toml。這篇筆記用的是 time_05.py。在 Visual Studio Code 裡打開資料夾，然後在終端機輸入這三行： 

uv python pin 3.12.10
uv sync
uv run time_05.py

第一行記錄這個資料夾用哪個 Python 版本，第二行安裝 pyproject.toml 列出的每一個 套件。第三行印出和版本 4 一樣的四個數目和三個例子。

這三行只需要一次。下次想再執行程式，只打 uv run time_05.py。

如果你還沒有設定 uv，先看 如何安裝 Visual Studio Code？，然後看 uv 筆記的 Windows 或 Mac。

接下來是甚麼

例子準備好了，程式碼也整齊了，但仍然沒有辦法分辨模型是在學習，還是只是在背誦。版本 6 把例子分成 訓練部分和驗證部分，這樣就可以在模型從未訓練過的日子上檢查進度。
