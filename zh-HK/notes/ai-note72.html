如何也讓程式選擇視窗長度（預測，版本 11）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 6 分鐘閱讀

這是預測系列的第 11 個版本。版本 10 搜尋五個設定：訓練多久、每步走多大、用哪個優化器、 隱藏層應該多寬，以及疊多少層。版本 11 加入第六個：視窗長度 — 每個例子由多長的一段 過去值建成，換句話說，模型在作出猜測之前往回看多遠。這個設定和其他不一樣。前五個改變模型； 第六個改變資料。

六個設定與 972 個組合

版本 11 的搜尋空間就是舊的那個，只加了一行。舊的五個設定仍然各提供三個值；新的那個提供 四個。 

SEARCH_SPACE = {
    "epochs":       [50, 100, 200],
    "learning_rate":[0.001, 0.01, 0.1],
    "optimizer":    ["Adam", "SGD", "RMSprop"],
    "hidden_size":  [10, 32, 64],
    "num_layers":   [1, 2, 3],
    "window_size":  [10, 20, 30, 50],
}

五個清單各有三個值，最後一個有四個，得出 3 × 3 × 3 × 3 × 3 × 4 = 972 個組合，比 243 多。預算不變，仍是 N_TRIALS = 20，所以同樣的二十次隨機抽樣，現在覆蓋的面積大了四倍。這就是加入 第六個設定的代價。

為甚麼視窗長度和其他設定不同

由版本 2 開始，視窗長度一直是檔案頂部附近的一行固定程式碼，WINDOW_SIZE = 30。 每個執行程式的人都在同樣的例子上訓練。在版本 11，那一行沒有了，window_size 作為其中一個設定送進來。

它帶來三個後果，而只有第一個是明顯的。改變視窗就改變有多少個例子：1,460 天切成長度為 w 的視窗，得到 1,460 − w + 1 個例子，當 w = 30 時是 1,431， 這個計算在 如何把每個視窗分成特徵與目標（版本 4） 中做過。它也改變每個輸入包含多少個數字：w − 1 個，所以視窗 30 時是 29 個， 最短的視窗 10 時是 9 個，最長的視窗 50 時是 49 個。而且因為輸入長度會餵給網路的第一層， 它也改變了模型本身的形狀。

搜尋怎樣運作

1. 在每個試驗裡重建資料

版本 10 在搜尋開始之前只建一次視窗。版本 11 把同樣的工作包進一個函式，這樣就可以為每個 視窗長度重複： 

def make_loaders(window_size):
    windows      = series_tensor.unfold(0, window_size, 1)
    features     = windows[:, :-1]
    targets      = windows[:, -1:]
    full_dataset = TensorDataset(features, targets)
    total        = len(full_dataset)
    tr_end       = int(total * 0.70)
    val_end      = int(total * 0.85)

unfold 把一個指定長度的框沿着數列滑動，每個框的最後一個數字成為答案，其餘 成為問題。分割點然後按新的總數重新計算，所以比例在每個視窗長度都成立。這個函式的第一個 呼叫者是訓練常式本身： train_loader, val_loader, test_loader = make_loaders(cfg["window_size"])。

2. 讓第一層改變大小

模型工廠現在把輸入大小當作引數，而不是讀取一個常數。在版本 10，它裡面的那一行是 input_size = WINDOW_SIZE - 1；在版本 11，這個數字是由外面送進來的： 

def build_model(input_size, hidden_size, num_layers):
    layers = []
    in_dim = input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers).to(device)

各層的建立方式與 如何讓程式自己搜尋它的設定（版本 10） 中解釋的完全一樣。唯一的改變是輸入值的數目現在由外面傳入，而不是從一個固定常數讀取，所以 第一層按視窗長度接收 9、19、29 或 49 個數字。

3. 訓練每個組合並保留它的驗證分數

for i, combo in enumerate(sampled):
    cfg = dict(zip(keys, combo))
    model, t_losses, v_losses, trial_val_loss, test_loader = train_trial(cfg)

    row = {**cfg, "val_loss": trial_val_loss, "actual_epochs": len(t_losses)}
    results.append(row)

組態現在帶着六個值，例如 {"epochs": 50, "learning_rate": 0.001, ..., "window_size": 10}。這個字典存放在 cfg，是 configuration（組態）的簡寫：一個試驗的一整套完整 設定。train_trial 現在回傳五樣東西：模型、它的訓練與驗證損失曲線、 訓練期間見過的最佳驗證損失，以及為那個試驗的視窗建立的測試載入器。我們把驗證分數記錄在 結果那一行，但不會在迴圈裡對測試集呼叫 evaluate。每個試驗只用驗證 資料評分，所以測試集一直隱藏到選出優勝者為止。

訓練的運作與版本 9 一樣：如果驗證誤差連續 15 個回合沒有改善 （EARLY_STOP_PATIENCE = 15），試驗就會提早停止，而帶來最低驗證誤差的權重會被 保留。因此，一個停止改善的試驗會提早結束，而不是跑到最大回合數。測試載入器之所以從 train_trial 帶回來，只是因為它是為那個試驗的視窗而建的；它還沒有被用到。

4. 按驗證損失選出優勝者，然後誠實地評分

if trial_val_loss < best_val_loss:
    best_val_loss = trial_val_loss
    best_trial = {"cfg": cfg, "model": model, ...}

# Evaluate once on the test set after the winner is chosen
r2, mae, rmse, preds, actuals = evaluate(best_trial["model"], best_trial["test_loader"])

torch.save(best_trial["model"].state_dict(), "best_model.pt")
results_df.to_excel("search_results.xlsx", index_label="Rank")

best_val_loss 由正無限大開始，所以第一個試驗一定成為基準，後面的試驗必須 降低它才能取代它。只有在這個決定確定之後，腳本才對測試集呼叫 evaluate 一次 — 同一個直到現在都沒有任何試驗看過的測試日。最後，資料夾裡會出現五個檔案。 best_model.pt 保存優勝的權重，search_results.xlsx 保存全部二十個 試驗按驗證損失排列的結果，並有一個版本 10 沒有的 window_size 欄，而三張圖表 分別存成 best_model_loss.png、best_model_predictions.png 和 trial_val_loss_chart.png。試算表仍然是有用的那一個，因為它保留每一個試驗， 不只是優勝者。

完整程式

把上面的各部分放回一起。這就是完整的檔案： 

import os
os.environ["KMP_DUPLICATE_LIB_OK"] = "TRUE"

import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import random
import itertools

# ── Reproducibility ──────────────────────────────────────────────────────────
SEED = 42
random.seed(SEED)
np.random.seed(SEED)
torch.manual_seed(SEED)

# ── Search space ─────────────────────────────────────────────────────────────
SEARCH_SPACE = {
    "epochs":       [50, 100, 200],
    "learning_rate":[0.001, 0.01, 0.1],
    "optimizer":    ["Adam", "SGD", "RMSprop"],
    "hidden_size":  [10, 32, 64],
    "num_layers":   [1, 2, 3],
    "window_size":  [10, 20, 30, 50],
}
N_TRIALS            = 20
EARLY_STOP_PATIENCE = 15
BATCH_SIZE          = 32

# ── Data ─────────────────────────────────────────────────────────────────────
df = pd.read_csv("time_series.csv")
series = df["series"].values
series_tensor = torch.tensor(series, dtype=torch.float32)

def make_loaders(window_size):
    windows      = series_tensor.unfold(0, window_size, 1)
    features     = windows[:, :-1]
    targets      = windows[:, -1:]
    full_dataset = TensorDataset(features, targets)
    total        = len(full_dataset)
    tr_end       = int(total * 0.70)
    val_end      = int(total * 0.85)
    train_loader = DataLoader(Subset(full_dataset, range(tr_end)),           batch_size=BATCH_SIZE, shuffle=True)
    val_loader   = DataLoader(Subset(full_dataset, range(tr_end, val_end)),  batch_size=BATCH_SIZE, shuffle=False)
    test_loader  = DataLoader(Subset(full_dataset, range(val_end, total)),   batch_size=BATCH_SIZE, shuffle=False)
    return train_loader, val_loader, test_loader

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# ── Model factory ─────────────────────────────────────────────────────────────
def build_model(input_size, hidden_size, num_layers):
    layers = []
    in_dim = input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers).to(device)

def get_optimizer(name, params, lr):
    return {"Adam": optim.Adam, "SGD": optim.SGD, "RMSprop": optim.RMSprop}[name](params, lr=lr)

# ── Train one trial ───────────────────────────────────────────────────────────
def train_trial(cfg):
    train_loader, val_loader, test_loader = make_loaders(cfg["window_size"])
    model     = build_model(cfg["window_size"] - 1, cfg["hidden_size"], cfg["num_layers"])
    criterion = nn.MSELoss()
    optimizer = get_optimizer(cfg["optimizer"], model.parameters(), cfg["learning_rate"])

    best_val_loss = float("inf")
    best_state    = {k: v.clone() for k, v in model.state_dict().items()}
    patience_ctr  = 0
    train_losses, val_losses = [], []

    for epoch in range(cfg["epochs"]):
        # train
        model.train()
        t_loss = 0
        for xb, yb in train_loader:
            xb, yb = xb.to(device), yb.to(device)
            optimizer.zero_grad()
            loss = criterion(model(xb), yb)
            loss.backward()
            optimizer.step()
            t_loss += loss.item()
        t_loss /= len(train_loader)

        # validate
        model.eval()
        v_loss = 0
        with torch.no_grad():
            for xb, yb in val_loader:
                v_loss += criterion(model(xb.to(device)), yb.to(device)).item()
        v_loss /= len(val_loader)

        train_losses.append(t_loss)
        val_losses.append(v_loss)

        # early stopping
        if v_loss < best_val_loss:
            best_val_loss = v_loss
            best_state    = {k: v.clone() for k, v in model.state_dict().items()}
            patience_ctr  = 0
        else:
            patience_ctr += 1
            if patience_ctr >= EARLY_STOP_PATIENCE:
                break

    model.load_state_dict(best_state)
    return model, train_losses, val_losses, best_val_loss, test_loader

# ── Evaluate on test set ──────────────────────────────────────────────────────
def evaluate(model, test_loader):
    model.eval()
    preds, actuals = [], []
    with torch.no_grad():
        for xb, yb in test_loader:
            preds.extend(model(xb.to(device)).cpu().numpy())
            actuals.extend(yb.numpy())
    p = torch.tensor(np.array(preds))
    a = torch.tensor(np.array(actuals))
    mae  = torch.mean(torch.abs(p - a)).item()
    rmse = torch.sqrt(torch.mean((p - a) ** 2)).item()
    ss_res = torch.sum((a - p) ** 2)
    ss_tot = torch.sum((a - torch.mean(a)) ** 2)
    r2 = (1 - ss_res / ss_tot).item()
    return r2, mae, rmse, preds, actuals

# ── Random search; select by validation loss ──────────────────────────────────
keys   = list(SEARCH_SPACE.keys())
combos = list(itertools.product(*SEARCH_SPACE.values()))
sampled = random.sample(combos, min(N_TRIALS, len(combos)))

results = []
best_val_loss = float("inf")
best_trial = None

print(f"Running {N_TRIALS} random trials...\n")
print(f"{'Trial':>5}  {'Win':>4}  {'Epochs':>6}  {'LR':>6}  {'Opt':>7}  {'Hidden':>6}  {'Layers':>6}  {'Val Loss':>12}")
print("-" * 78)

for i, combo in enumerate(sampled):
    cfg = dict(zip(keys, combo))
    model, t_losses, v_losses, trial_val_loss, test_loader = train_trial(cfg)

    row = {**cfg, "val_loss": trial_val_loss, "actual_epochs": len(t_losses)}
    results.append(row)

    print(f"{i+1:>5}  {cfg['window_size']:>4}  {cfg['epochs']:>6}  {cfg['learning_rate']:>6}  "
          f"{cfg['optimizer']:>7}  {cfg['hidden_size']:>6}  {cfg['num_layers']:>6}  "
          f"{trial_val_loss:>12.4f}")

    if trial_val_loss < best_val_loss:
        best_val_loss = trial_val_loss
        best_trial = {"cfg": cfg, "model": model, "t_losses": t_losses,
                      "v_losses": v_losses, "val_loss": trial_val_loss,
                      "test_loader": test_loader}

# ── Evaluate the selected model on the test set once ─────────────────────────
r2, mae, rmse, preds, actuals = evaluate(best_trial["model"], best_trial["test_loader"])
best_trial.update({"r2": r2, "mae": mae, "rmse": rmse,
                   "preds": preds, "actuals": actuals})

# ── Save best model ───────────────────────────────────────────────────────────
torch.save(best_trial["model"].state_dict(), "best_model.pt")
print(f"\nBest model saved → best_model.pt")
print(f"Best config : {best_trial['cfg']}")
print(f"Best validation MSE: {best_val_loss:.4f}")
print(f"Test R²: {r2:.4f}  |  MAE: {mae:.4f}  |  RMSE: {rmse:.4f}")

# ── Save results table ranked by validation loss ─────────────────────────────
results_df = pd.DataFrame(results).sort_values("val_loss").reset_index(drop=True)
results_df.index += 1
results_df.to_excel("search_results.xlsx", index_label="Rank")
print("Results table saved → search_results.xlsx")

# ── Plots for best model only ─────────────────────────────────────────────────
# 1. Loss curves
plt.figure(figsize=(10, 5))
plt.plot(best_trial["t_losses"], label="Train Loss")
plt.plot(best_trial["v_losses"], label="Val Loss")
plt.title(f"Best Model — Loss Curves\n{best_trial['cfg']}", fontsize=11)
plt.xlabel("Epoch"); plt.ylabel("MSE Loss")
plt.legend(); plt.grid(True)
plt.tight_layout()
plt.savefig("best_model_loss.png", dpi=150)
plt.show()

# 2. Predictions vs actual
plt.figure(figsize=(12, 5))
plt.plot(best_trial["actuals"], label="Actual",    color="lightgrey", linewidth=1.5)
plt.plot(best_trial["preds"],   label="Predicted", color="red",       linewidth=1.5)
plt.title(f"Best Model — Predictions vs Actual (Test Set)\nR²={best_trial['r2']:.4f}  RMSE={best_trial['rmse']:.4f}", fontsize=11)
plt.xlabel("Time"); plt.ylabel("Value")
plt.legend(); plt.grid(True)
plt.tight_layout()
plt.savefig("best_model_predictions.png", dpi=150)
plt.show()

# 3. Validation-loss bar chart across all trials
plt.figure(figsize=(12, 4))
colors = ["#70AD47" if rank == 1 else "#4472C4" for rank in results_df.index]
plt.bar(results_df.index, results_df["val_loss"], color=colors)
plt.axhline(best_val_loss, color="red", linestyle="--", linewidth=1,
            label=f"Best Val Loss={best_val_loss:.4f}")
plt.title("Validation Loss Across All Trials (green = best)")
plt.xlabel("Rank"); plt.ylabel("Validation MSE Loss")
plt.legend(); plt.grid(axis="y", alpha=0.4)
plt.tight_layout()
plt.savefig("trial_val_loss_chart.png", dpi=150)
plt.show()

在自己的電腦上執行

下載 zip 檔案並解壓到一個 資料夾。zip 裡有這個系列到目前為止的程式、time_series.csv 資料檔，以及 pyproject.toml。這篇筆記用的是 time_11.py。在 Visual Studio Code 裡打開資料夾，然後在終端機輸入這三行： 

uv python pin 3.12.10
uv sync
uv run time_11.py

第一行記錄這個資料夾用哪個 Python 版本，第二行安裝 pyproject.toml 列出的每一個 套件。第三行執行二十個試驗，每個視窗長度重建一次資料，然後在顯示之前把圖表存到磁碟；關閉 每個視窗以繼續。最後你會有 best_model.pt、search_results.xlsx 和 三個 PNG 檔案。

這三行只需要一次。下次想再執行程式，只打 uv run time_11.py。

如果你還沒有設定 uv，先看 如何安裝 Visual Studio Code？，然後看 uv 筆記的 Windows 或 Mac。

接下來是甚麼

這次搜尋仍然很小：幾十個試驗，一個短短的數值清單。版本 12 把每個範圍都擴大 — 更多 回合、更多學習率、更寬的隱藏層、更多層 — 並跑 200 個試驗而不是 20 個，所以表格會長 到足以讀成一個地貌，而不只是一個樣本。
