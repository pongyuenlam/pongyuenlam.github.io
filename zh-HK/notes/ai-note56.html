如何顯示鏡頭的即時畫面（人臉辨識，版本 4）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 4 分鐘閱讀

版本 1 到 3 處理的都是已經存在硬碟上的相片。要認出坐在電腦前的那個人，程式需要有 源源不絕的新相片，鏡頭就是這個來源：它每秒送出很多格靜止畫面。版本 4 建立這個來源。 它打開鏡頭並顯示影片，其他什麼都不做。不找出人臉，不印出名字。

這看起來像退了一步，但它把兩個問題分開了。如果版本 7 辨識失敗，這個程式能告訴你 鏡頭那部分究竟有沒有在工作。如果你讀過 如何從鏡頭取得即時影片？，這篇筆記的大部分內容你會覺得熟悉； 這裡把它放回系列裡，因為後面每一個版本都往這個迴圈裡加自己的工序。

鏡頭送來的是一格一格的畫面，不是一段影片

你的眼睛看到的是流暢的動作。程式收到的是一張張獨立的靜止畫面，每一張都在足夠短的時間裡 替換掉上一張，所以你看不出變化。這很有用：影格和相片檔案是同一種物件，所以你在相片上 量度人臉學到的一切，原樣適用於影格。

程式怎麼運作

1. 打開鏡頭

import cv2
cap = cv2.VideoCapture(0)

cv2.VideoCapture 連接一台鏡頭；cap 是 capture（擷取）的縮寫， 保存這個連接。這裡的 0 表示第一台鏡頭，通常是內建鏡頭；1 會是第二台，例如 USB 鏡頭。

在 Mac 上，第一次執行時系統會請求權限，你不允許它就什麼也不顯示。如果視窗一直黑著， 到「系統設定」裡檢查終端機或編輯器有沒有鏡頭權限，並確認沒有其他程式正在使用鏡頭。

2. 不停地重複

while True:
    ret, img = cap.read()
    cv2.imshow("Frame", img)

while True 開始一個自己永遠不會停的迴圈，因為 True 永遠為真。它下面縮排的所有內容每一格執行一次，只要程式還在執行就一直執行。

cap.read() 取一格，回傳兩樣東西。ret 是 return value（回傳值） 的縮寫，說明這次讀取有沒有成功。img 是 image（影像）的縮寫，就是這一格： 一個由像素值組成的格子，順序是 OpenCV 使用的藍-綠-紅。 cv2.imshow 把這一格放進標題為 "Frame" 的視窗，迴圈下一輪再把它 替換掉。每秒顯示的影格數足夠多，視窗看起來就像影片。

3. 按下 q 就停

    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break

cv2.waitKey(1) 等待按鍵一毫秒。它把按下的鍵作為數字回傳，沒有按鍵就回傳 -1。這一毫秒也是 OpenCV 用來畫視窗的時間；不呼叫 waitKey， 視窗會卡住或者空白。

ord() 把字母變成它的數字，ord('q') 是 113，這樣字母就能和 waitKey 回傳的數字比較。同時檢查 q 和 Q，開不開 Caps Lock 都一樣。break 離開迴圈。

只有影片視窗是作用中視窗時，按鍵才會送到程式。執行之後，編輯器的終端機通常還拿著焦點， 所以先在影片視窗上按一下，再按 q。忘了的話，在終端機裡按 Ctrl 和 C 也能停掉程式。

4. 放開鏡頭

cap.release()
cv2.destroyAllWindows()

這兩行沒有縮排，所以迴圈結束後執行一次。cap.release() 斷開與鏡頭的連接， 關掉它的指示燈，讓其他程式可以使用。cv2.destroyAllWindows() 關掉視窗。

完整程式

把上面的片段拼回去。這是完整的檔案，一共 10 行： 

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

為什麼是一毫秒

waitKey(0) 會一直等到有按鍵才回傳，畫面永遠不會更新。 waitKey(30) 大約每秒更新 33 次，看起來流暢，但會帶來延遲。一毫秒讓視窗 保持回應，並讓迴圈以鏡頭允許的最快速度執行。

在自己的電腦上執行

用和版本 1 相同的下載： 下載壓縮檔，解壓縮， 然後用 Visual Studio Code 打開這個資料夾。這一篇用的是 face04.py。 第一次在這個資料夾裡，執行全部三行： 

uv python pin 3.12.10
uv sync
uv run face04.py

這三行只需要做一次。下次想再執行這個程式，只需輸入 uv run face04.py。

會打開一個視窗，顯示你的鏡頭畫面。在它上面按一下，然後按 q 關掉。 鏡頭指示燈應該在同一時刻熄滅。

下一步

下兩個版本都留在這個迴圈裡。版本 5 把每一格變成灰色，版本 6 在格上畫一個框和標籤， 這樣版本 7 真正做辨識的時候，已經有地方可以放結果。
