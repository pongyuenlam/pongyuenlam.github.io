如何嘗試多個學習率並保留最好的一個（預測，版本 9）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 6 分鐘閱讀

這是預測系列的第 9 個版本。到目前為止，所有設定都是猜的：Adam 的預設學習率、一百個回合、 最後一個回合結束時剛好存在的那些權重。版本 9 把學習率當成一件可以比較的事：用不同的學習率 把同一段訓練跑三次，每次開始停止改善就停下來，並保留得分最好的那個模型。

學習率的作用

在版本 7，優化器在每個批次之後把每一個權重稍微調整一次。學習率控制那次調整的幅度。

  • 太小 — 權重每次改變得太少，所以模型學得慢，跑完 100 個回合之後 可能仍然有很大的誤差。
  • 太大 — 權重每次改變得太多，所以誤差可能一直上下起伏，而不是 穩定地變小。
  • 差不多剛好 — 權重的改變幅度合適，所以模型學得快，誤差也穩定在 低水平。

沒有任何公式可以告訴你某個資料集該用哪個值，所以實用的答案是試幾個，然後看。

提前停止的作用

版本 8 總是跑完 100 個回合，並使用最後一個回合的模型，即使驗證日的誤差早已經開始上升。 其中一個原因是訓練批次是隨機打亂的，所以有些權重的調整會令驗證日的預測變差。版本 9 在每個 回合之後都檢查那個誤差，每當它達到新的最低誤差，就把模型儲存起來。如果誤差連續 10 個回合 沒有改善，訓練就停下來。之後程式會還原已儲存、驗證誤差最低的那個模型，而不是使用最後一個 回合的模型。

這有兩個好處。當更多回合已經不能再改善模型時，訓練可以更早完成。程式保留的也是在驗證日 表現最好的模型，而不只是最後一個回合的模型。

程式怎樣運作

1. 把一次訓練包在一個函式裡

def train_one_model(lr):
    model     = TimeSeriesModel(window_size).to(device)
    criterion = nn.MSELoss()
    optimizer = optim.Adam(model.parameters(), lr=lr)

函式裡面重複的是版本 7 的訓練，只改了一件事：lr 是 learning rate（學習率）的簡寫，現在是一個參數，所以同一個函式可以用不同的 學習率呼叫。每次呼叫都會建立一個全新的模型，所以三次訓練各自從獨立的隨機權重開始，互不 污染。

2. 保留最好的權重

    best_val_loss = float('inf')
    best_state    = {k: v.clone() for k, v in model.state_dict().items()}
    patience_ctr  = 0

best_val_loss 由無限大開始，所以第一個回合一定算作一次改善。 best_state 保存那一刻權重的一份副本。.clone() 很重要：沒有它， 副本會隨着模型改變而繼續改變，就沒有東西可以回去了。patience_ctr 計算連續 多少個回合驗證誤差沒有改善。它由零開始，因為還沒有任何回合跑過。

3. 改善停了就停下來

        if v_loss < best_val_loss:
            best_val_loss = v_loss
            best_state    = {k: v.clone() for k, v in model.state_dict().items()}
            patience_ctr  = 0
        else:
            patience_ctr += 1
            if patience_ctr >= PATIENCE:
                break

出現新的最佳值時，計數器 patience_ctr 重設為零。一個更差的回合就把它加一。 當連續累積了十個更差的回合，break 就提早離開迴圈。之後 model.load_state_dict(best_state) 把最好的權重放回去，所以回傳的模型是在驗證日 得分最好的那一個，而不是剛好排在最後的那一個。

4. 跑這三個學習率

learning_rates = [0.001, 0.01, 0.1]

for lr in learning_rates:
    model, t_losses, v_losses, epochs, val_loss = train_one_model(lr)

迴圈的每一輪都訓練一個完整的模型。函式現在回傳五個值，而不是四個：模型、它的訓練損失曲線 與驗證損失曲線、實際跑了多少個回合，以及訓練期間見過的最佳驗證損失。我們只從每次訓練收集 那個驗證損失分數 — 測試日的 R² 只在選出優勝者之後評估一次。結果放進一個清單， 方便之後比較和排序。

5. 保留優勝者

best = min(results, key=lambda r: r["val_loss"])
torch.save(best["model"].state_dict(), "best_model.pt")

min 從 results 清單中選出一個結果。 key=lambda r: r["val_loss"] 這部分告訴 Python 按驗證損失分數來比較結果，所以 驗證損失最低的結果 — 也就是優勝者 — 會存進 best。我們用 驗證損失（來自模型從未訓練過的日子的資料），而不是用測試集，因為在選擇之前先看測試集， 等於用一些只應該留作最後誠實檢查的資料來「作弊」。然後 torch.save 把那個模型 學到的權重寫進一個叫 best_model.pt 的檔案。之後的程式可以載入這個檔案，重用 模型而不必再訓練一次。

你應該會看到甚麼

      lr   epochs      Val Loss
--------------------------------
   0.001       73       39.9478
    0.01       26       40.9754
     0.1       73     3136.5420

Best learning rate: 0.001  (Validation MSE = 39.9478)

Test Set Metrics:
  MAE:  4.3036
  RMSE: 5.3494
  R²:   0.4393
Best model saved → best_model.pt

你的數字會不同，但要看的是那個模式。兩個較小的學習率都達到差不多 40 左右的低驗證損失，而 0.01 用 26 個回合就達到，不是 73 個。兩者給出差不多的測試集 R²，大約 0.44，但 0.01 需要較少回合。0.1 這個大學習率的驗證損失高出三十倍，因為每次調整都太大，誤差無法穩定地 變小。

相比版本 8，有兩件事改善了。R² 由 0.24 升到約 0.44，而大部分改善來自提前停止，而不是 來自學習率：保留最好的權重而不是最後的權重，明顯提高了分數。訓練也由 100 個回合縮短到 26 個回合完成。

完整程式

把上面的各部分放回一起。這就是完整的檔案： 

import os
os.environ["KMP_DUPLICATE_LIB_OK"] = "TRUE"

import torch
import torch.nn as nn
import torch.optim as optim
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt

# ── Data preparation (same as time_08) ────────────────────────────────────────
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    features = windows[:, :-1]
    targets = windows[:, -1:]
    return features, targets

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
full_dataset = TensorDataset(features, targets)

total_windows = len(full_dataset)
train_size = int(total_windows * 0.7)
val_size = int(total_windows * 0.15)
test_size = total_windows - train_size - val_size

train_indices = list(range(train_size))
val_indices = list(range(train_size, train_size + val_size))
test_indices = list(range(train_size + val_size, total_windows))

train_loader = DataLoader(Subset(full_dataset, train_indices),
                         batch_size=32, shuffle=True)
val_loader   = DataLoader(Subset(full_dataset, val_indices),
                         batch_size=32, shuffle=False)
test_loader  = DataLoader(Subset(full_dataset, test_indices),
                         batch_size=32, shuffle=False)

device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')

# ── Visualize train/val/test split (same as time_08) ─────────────────────────
val_start = train_size
test_start = train_size + val_size
plt.figure(figsize=(12, 4))
plt.plot(range(val_start), series[:val_start], 'b-', label='Training Data')
plt.plot(range(val_start, test_start), series[val_start:test_start], 'r-', label='Validation Data')
plt.plot(range(test_start, len(series)), series[test_start:], 'g-', label='Test Data')
plt.axvline(x=val_start, color='k', linestyle='--', label='Train/Val Split')
plt.axvline(x=test_start, color='purple', linestyle='--', label='Val/Test Split')
plt.title('Time Series Train/Validation/Test Split')
plt.xlabel('Time'); plt.ylabel('Value')
plt.legend(); plt.grid(True); plt.show()

# ── Model (same as time_07/08) ────────────────────────────────────────────────
class TimeSeriesModel(nn.Module):
    def __init__(self, window_size):
        super(TimeSeriesModel, self).__init__()
        self.network = nn.Sequential(
            nn.Linear(window_size - 1, 10),
            nn.ReLU(),
            nn.Linear(10, 10),
            nn.ReLU(),
            nn.Linear(10, 1)
        )

    def forward(self, x):
        return self.network(x)

# ── NEW: training with early stopping ────────────────────────────────────────
# Early stopping: if val loss does not improve for PATIENCE consecutive epochs,
# stop training early and restore the best weights seen so far.
PATIENCE   = 10
MAX_EPOCHS = 100

def train_one_model(lr):
    model     = TimeSeriesModel(window_size).to(device)
    criterion = nn.MSELoss()
    optimizer = optim.Adam(model.parameters(), lr=lr)

    best_val_loss = float('inf')
    best_state    = {k: v.clone() for k, v in model.state_dict().items()}
    patience_ctr  = 0
    train_losses, val_losses = [], []

    for epoch in range(MAX_EPOCHS):
        # ── train ──
        model.train()
        t_loss = 0
        for batch_features, batch_targets in train_loader:
            batch_features = batch_features.to(device)
            batch_targets  = batch_targets.to(device)
            optimizer.zero_grad()
            loss = criterion(model(batch_features), batch_targets)
            loss.backward()
            optimizer.step()
            t_loss += loss.item()
        t_loss /= len(train_loader)

        # ── validate ──
        model.eval()
        v_loss = 0
        with torch.no_grad():
            for batch_features, batch_targets in val_loader:
                batch_features = batch_features.to(device)
                batch_targets  = batch_targets.to(device)
                v_loss += criterion(model(batch_features), batch_targets).item()
        v_loss /= len(val_loader)

        train_losses.append(t_loss)
        val_losses.append(v_loss)

        # ── early stopping check ──
        if v_loss < best_val_loss:
            best_val_loss = v_loss
            best_state    = {k: v.clone() for k, v in model.state_dict().items()}
            patience_ctr  = 0
        else:
            patience_ctr += 1
            if patience_ctr >= PATIENCE:
                break

    # restore the best weights
    model.load_state_dict(best_state)
    actual_epochs = len(train_losses)
    return model, train_losses, val_losses, actual_epochs, best_val_loss

# ── NEW: evaluate on test set (returns R², RMSE, MAE) ────────────────────────
def evaluate_on_test(model):
    model.eval()
    preds, actuals = [], []
    with torch.no_grad():
        for batch_features, batch_targets in test_loader:
            preds.extend(model(batch_features.to(device)).cpu().numpy())
            actuals.extend(batch_targets.numpy())

    p = torch.tensor(np.array(preds))
    a = torch.tensor(np.array(actuals))

    mae  = torch.mean(torch.abs(p - a)).item()
    rmse = torch.sqrt(torch.mean((p - a) ** 2)).item()
    ss_res = torch.sum((a - p) ** 2)
    ss_tot = torch.sum((a - torch.mean(a)) ** 2)
    r2 = (1 - ss_res / ss_tot).item()
    return r2, rmse, mae, preds, actuals

# ── Manually try 3 learning rates; select by validation loss ─────────────────
learning_rates = [0.001, 0.01, 0.1]
results = []

print(f"{'lr':>8}  {'epochs':>7}  {'Val Loss':>12}")
print("-" * 32)

for lr in learning_rates:
    model, t_losses, v_losses, epochs, val_loss = train_one_model(lr)
    results.append({
        "lr": lr, "epochs": epochs, "val_loss": val_loss,
        "model": model, "t_losses": t_losses, "v_losses": v_losses,
    })
    print(f"{lr:>8}  {epochs:>7}  {val_loss:>12.4f}")

# ── Select on validation data, then evaluate the test set once ───────────────
best = min(results, key=lambda r: r["val_loss"])
print(f"\nBest learning rate: {best['lr']}  (Validation MSE = {best['val_loss']:.4f})")

r2, rmse, mae, preds, actuals = evaluate_on_test(best["model"])
best.update({"r2": r2, "rmse": rmse, "mae": mae, "preds": preds, "actuals": actuals})

print(f"\nTest Set Metrics:")
print(f"  MAE:  {mae:.4f}")
print(f"  RMSE: {rmse:.4f}")
print(f"  R²:   {r2:.4f}")

torch.save(best["model"].state_dict(), "best_model.pt")
print("Best model saved → best_model.pt")

# ── Plots ──────────────────────────────────────────────────────────────────────
# 1. Loss curves for the best trial
plt.figure(figsize=(10, 5))
plt.plot(best["t_losses"], label="Train Loss")
plt.plot(best["v_losses"], label="Val Loss")
plt.title(f"Best Model — Loss Curves\nlr={best['lr']}  (stopped at epoch {best['epochs']})")
plt.xlabel("Epoch"); plt.ylabel("MSE Loss")
plt.legend(); plt.grid(True); plt.tight_layout(); plt.show()

# 2. Predictions vs actual on test set (best trial)
plt.figure(figsize=(12, 5))
plt.plot(best["actuals"], label="Actual",    color="lightgrey", linewidth=1.5)
plt.plot(best["preds"],   label="Predicted", color="red",       linewidth=1.5)
plt.title(f"Best Model — Predictions vs Actual (Test Set)\nR²={best['r2']:.4f}  RMSE={best['rmse']:.4f}")
plt.xlabel("Time"); plt.ylabel("Value")
plt.legend(); plt.grid(True); plt.tight_layout(); plt.show()

# 3. Validation-loss bar chart comparing all 3 trials
plt.figure(figsize=(8, 4))
lrs = [str(r["lr"]) for r in results]
val_losses = [r["val_loss"] for r in results]
colors = ["#4472C4" if r["lr"] != best["lr"] else "#70AD47" for r in results]
plt.bar(lrs, val_losses, color=colors)
plt.axhline(best["val_loss"], color="red", linestyle="--", linewidth=1,
            label=f"Best Val Loss={best['val_loss']:.4f}")
plt.title("Validation Loss Across 3 Learning Rates (green = best)")
plt.xlabel("Learning Rate"); plt.ylabel("Validation MSE Loss")
plt.legend(); plt.grid(axis="y", alpha=0.4); plt.tight_layout(); plt.show()

在自己的電腦上執行

下載 zip 檔案並解壓到一個 資料夾。zip 裡有這個系列到目前為止的程式、time_series.csv 資料檔，以及 pyproject.toml。這篇筆記用的是 time_09.py。在 Visual Studio Code 裡打開資料夾，然後在終端機輸入這三行： 

uv python pin 3.12.10
uv sync
uv run time_09.py

第一行記錄這個資料夾用哪個 Python 版本，第二行安裝 pyproject.toml 列出的每一個 套件。第三行依次訓練三個模型，印出比較表，然後打開圖表；關閉每個視窗以繼續。

這三行只需要一次。下次想再執行程式，只打 uv run time_09.py。

如果你還沒有設定 uv，先看 如何安裝 Visual Studio Code？，然後看 uv 筆記的 Windows 或 Mac。

接下來是甚麼

手動試三個值已經夠重複了。學習率只是眾多設定中的一個 — 隱藏層的數目、它們的寬度、 優化器和視窗長度都是選擇。下一個版本讓程式自己嘗試許多組合，並保留最好的。
