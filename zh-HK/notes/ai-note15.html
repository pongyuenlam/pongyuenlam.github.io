Python 程式如何用 DeepSeek API？

林邦源 · AI 筆記 · 2026年11月3日 · 閱讀時間約 5 分鐘

English 繁體中文 简体中文

與 AI 模型對話，不一定要透過瀏覽器。程式可以透過互聯網向 DeepSeek 發出訊息，然後收到一段文字回覆，隨即可印出、儲存，或交給更大程式的下一步處理。 程式就是這樣取得 AI 答案，而無需人手從聊天視窗複製貼上。

本文的程式向 DeepSeek 提出 「What is the traditional Chinese for Hong Kong?」這個問題，並印出回覆，全程只用 21 行。

先取得金鑰

DeepSeek 需要知道誰在發問，所以程式要出示一條 API 金鑰：一串像密碼 一樣的保密字元。API 是 Application Programming Interface（應用 程式介面）的縮寫，即程式之間透過互聯網溝通的方式。要取得金鑰，請到 https://platform.deepseek.com/ 註冊；少量餘額已足夠試用，金鑰可在 API keys 頁面建立。

金鑰絕不能直接寫進程式裡，否則任何讀到代碼的人都能拿走它。金鑰應放在同一資料夾內 一個名為 .env 的小檔案中，裡面只有一行： 

DEEPSEEK_API_KEY=paste-your-key-here

下載示範程式後，請自行建立這個檔案；zip 內並不包括它，因為金鑰是個人的。

逐段拆解程式

import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

這裡引入了三個函式庫。os 是 operating system（作業 系統）的縮寫；在這裡用來讀取環境變數，即存放在代碼以外的設定。 load_dotenv 讀取 .env 檔案，把每一行複製到那些環境變數 之中。OpenAI 是 openai 套件的連接器。它以另一間 AI 公司命名，但 DeepSeek 特意採用相同的訊息格式，所以同一個連接器兩者皆宜：你只需 更改它連接的地址。 

client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",
)

這裡建立連接器。os.environ.get("DEEPSEEK_API_KEY") 讀取 load_dotenv() 剛才從 .env 載入的金鑰，而 base_url 是 DeepSeek 服務的互聯網地址。從此連接器發出的每個請求 都會送往該地址並帶著金鑰，DeepSeek 便知道請求來自哪個帳戶。 

response = client.chat.completions.create(
    model="deepseek-flash",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is the traditional Chinese for Hong Kong?"},
    ],
    stream=False,
)

這裡送出問題並等候回覆。model="deepseek-flash" 選定由哪個 DeepSeek 模型作答；DeepSeek 的文件會列出最新的模型名稱，它們會隨時間改變。 messages 清單是迄今的對話：system 訊息設定模型的 行事方式，user 訊息則是實際的問題。stream=False 要求一次過取得整段回覆，而不是逐字逐字地看著它到來。 

print(response.choices[0].message.content)

回覆藏在回應包裹的幾層之下。choices 是候選回覆的清單——幾乎總是只有 一個——所以 [0] 取出第一個，而 message.content 就是 它的文字。印出來的正是這段文字。

完整程式

import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",
)

response = client.chat.completions.create(
    model="deepseek-flash",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is the traditional Chinese for Hong Kong?"},
    ],
    stream=False,
)

print(response.choices[0].message.content)

在自己的電腦上執行

下載 zip 檔案並 解壓到一個資料夾。這個 zip 包含程式和一個 pyproject.toml 專案檔案。 請如上所示，加入你自己的 .env 金鑰檔案。然後在 Visual Studio Code 中 開啟資料夾，在終端機逐行輸入以下三行： 

uv python pin 3.12.10
uv sync
uv run deepseek_chat.py

第一行記錄這個資料夾使用哪個 Python 版本。第二行設定專案，並安裝程式需要的兩個套件 openai 和 python-dotenv。第三行執行程式。幾秒之後， 回覆便會出現： 

The traditional Chinese for “Hong Kong” is **香港** — the same characters are used in both traditional and simplified Chinese.

- Cantonese: **Hoeng1 Gong2**
- Mandarin: **Xiānggǎng**

你執行時的措辭很可能不同，因為模型每次都會即場寫出新的回覆。

如果你還未設定 uv，請先從 如何安裝 Visual Studio Code？開始，然後看 uv 筆記： Windows 或 Mac。

限制

  • 它需要金鑰和互聯網。.env 裡沒有有效的金鑰，或者 沒有連線，程式都會以錯誤終止。
  • 回覆要花少許費用。DeepSeek 按處理的文字量收費。像這樣的一條 問題只需一仙的零頭，但程式若發問數千條問題，累積起來也可觀。
  • 回覆不保證正確。模型寫的是看似合理的文字，而非核實過的事實， 所以重要的答案仍需人看一眼。給模型提供參考資料會有幫助；見下方的 RAG 筆記。
  • 模型名稱會改變。deepseek-flash 是執筆時的通用 名稱；舊名稱可能失效，有疑問時請查閱文件。
