如何用 AI 改變你的眉毛？

林邦源 · AI 筆記 · 2026年11月1日 · 閱讀時間約 4 分鐘

English 繁體中文 简体中文

在本文中，我們再次使用 face_recognition 程式庫。它會找出勾勒出每條眉毛的五個點，程式然後把該區域填上半透明的深棕色。 整個程式只有 12 行。

如果你還未讀過 〈AI 如何找出你臉上的關鍵點？〉，請先從那裡開始。 那篇文章講解了程式庫如何找出關鍵點；本文則利用同一批關鍵點，在上面塗上顏色。

前後對比

程式如何運作

首五行與上一篇相同：讀取相片、找出關鍵點，然後把相片變成程式可以在上面畫圖的東西。 之後只有三個新概念。

1. 讓畫圖變成半透明

for face_landmarks in face_landmarks_list:
    d = ImageDraw.Draw(pil_image, 'RGBA')

迴圈每次取一張臉，下面縮排的所有程式碼都為該張臉執行一次。我們的相片只有一張臉， 所以只執行一次。

第二行建立一個名為 d 的畫圖工具。RGBA 代表紅、綠、藍和 alpha，而 alpha 就是顏色的透明程度。使用 'RGBA' 時，顏色會與底下的像素 混合，而不是覆蓋它們。

2. 選擇眉毛顏色

# (red, green, blue, see-through): each 0 to 255; see-through 0 = invisible, 255 = solid
color_eyebrow = (68, 54, 39, 128)

四個數字，不是三個。首三個是紅、綠、藍的分量，全部偏低，所以顏色偏深；紅色是三者中 最高的，所以呈現深棕色。第四個數字 128 約為 255 的一半，所以顏色是半透明的， 你原本的眉毛仍然能透出來。

3. 填滿兩條眉毛

d.polygon(face_landmarks['left_eyebrow'], fill=color_eyebrow)
d.polygon(face_landmarks['right_eyebrow'], fill=color_eyebrow)

每條眉毛由五個點勾勒。polygon 按順序連接這些點，從最後一點直接回到 第一點，然後填滿裡面的區域。 

pil_image.save("my_photo_eyebrow.jpg")

最後，程式把帶有棕色眉毛的相片用新名字儲存，原相片保持不變。

完整程式

把上面的部分拼回來。這就是完整的檔案，一共 12 行： 

from PIL import Image, ImageDraw
import face_recognition
image = face_recognition.load_image_file("my_photo.jpg")
face_landmarks_list = face_recognition.face_landmarks(image)
pil_image = Image.fromarray(image)
for face_landmarks in face_landmarks_list:
    d = ImageDraw.Draw(pil_image, 'RGBA')
    # (red, green, blue, see-through): each 0 to 255; see-through 0 = invisible, 255 = solid
    color_eyebrow = (68, 54, 39, 128)
    d.polygon(face_landmarks['left_eyebrow'], fill=color_eyebrow)
    d.polygon(face_landmarks['right_eyebrow'], fill=color_eyebrow)
    pil_image.save("my_photo_eyebrow.jpg")

在自己的電腦上執行

下載 zip 檔案並解壓到 一個資料夾。這個 zip 包含本系列的六個程式；本文使用 face02_eyebrow.py。把你自己的相片放進該資料夾，命名為 my_photo.jpg。在 Visual Studio Code 中開啟資料夾，然後在終端機輸入 以下三行： 

uv python pin 3.12.10
uv sync
uv run face02_eyebrow.py

第一行記錄這個資料夾使用的 Python 版本。第二行安裝 pyproject.toml 列出的所有套件，你不用逐一安裝。第三行執行程式，它會把結果儲存為 my_photo_eyebrow.jpg。

如果你還沒有設定 uv，請先閱讀 〈如何安裝 Visual Studio Code？〉， 然後是 Windows 或 Mac 的 uv 筆記。

技術備註：face-recognition 套件依賴另一個名為 dlib 的套件。 zip 中的專案檔案已指向預先編譯好的 dlib 版本，所以 uv sync 會直接安裝可用版本，你不需要安裝編譯器。

這有甚麼用

所有數碼「先試後買」工具的基本形態就是如此。程式知道你的眉毛在哪裡，而顏色只是一行 就能改動的數值——所以你可以在購買前先看看某個色調的效果，或並排比較兩種棕色。

有兩個限制值得留意。程式只改變顏色，不改變形狀：真正的眉筆還會增加長度和濃度。 而且由於程式填滿的是五個點圍成的區域，顏色主要集中在眉線上方；要填得更密， 就需要更多關鍵點或一點幾何計算。
