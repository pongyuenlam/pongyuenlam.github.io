如何用 Python 和 Flask 建立本機網站（版本 2）？

林邦源 · AI 筆記 · 2026年11月25日 · 閱讀時間約 5 分鐘

English 繁體中文简体中文

要快速讓網站回應訪客，可以加入文字框和按鈕。輸入名字，按一下 Say Hello， 頁面便會顯示 Hello Howard 這類問候語。

一個小型 Python 程式接收名字並回傳問候語。頁面和程式分別位於 templates/index.html 和 app.py。

開始前需要甚麼

  • Visual Studio Code，並可使用終端機。如尚未安裝，請先看 如何安裝 Visual Studio Code？
  • uv，用來安裝 Flask 的工具： Windows 或 Mac。
  • 瀏覽器。你需要自行開啟網址。

步驟 1：取得專案資料夾

下載 zip 檔案並解壓到一個資料夾。 內有 app.py、templates/index.html 和 pyproject.toml。 用 Visual Studio Code 開啟該資料夾。

在終端機記錄這個資料夾使用的 Python 版本。這行只需執行一次：

uv python pin 3.12.10

然後安裝 Flask，同樣只需一次：

uv sync

步驟 2：查看 Python 程式

以下是 app.py 的全部程式：

from flask import Flask, render_template, request, jsonify
app = Flask(__name__)
@app.route("/")
def index():
    return render_template("index.html")
@app.route("/greet", methods=["POST"])
def greet():
    data = request.get_json()
    user_name = data.get("user_name", "")
    return jsonify({"greeting": f"Hello {user_name}"})

第一條路由把頁面傳給瀏覽器。第二條路由接收名字，把它接在 Hello 後面，再回傳問候語。 每個 @app.route 行都把網址連接到下面的函式。

步驟 3：查看頁面

這是 templates/index.html：

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Hello User</title>
</head>
<body>
    <h1>Hello User</h1>
    <input type="text" id="userName" placeholder="Your name">
    <button onclick="greetUser()">Say Hello</button>
    <p id="greeting"></p>
    <script>
        function greetUser() {
            const userName = document.getElementById("userName").value;
            fetch("/greet", {
                method: "POST",
                headers: {"Content-Type": "application/json"},
                body: JSON.stringify({user_name: userName})
            })
            .then(response => response.json())
            .then(data => {
                document.getElementById("greeting").textContent = data.greeting;
            });
        }
    </script>
</body>
</html>

文字框保存名字，按鈕執行 greetUser()。這段程式把名字傳到 /greet， 接收答案，再放進按鈕下方的段落。

步驟 4：執行程式

在終端機輸入：

uv run flask run

Flask 會自動尋找 app.py，通常每次都使用 5000 連接埠。 終端機會顯示頁面網址： 

 * Debug mode: off
WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit

把 http://127.0.0.1:5000 複製並貼到瀏覽器的網址列，或直接輸入網址列。輸入名字並按一下 Say Hello。 問候語會顯示在按鈕下方。

要停止伺服器，請按一下終端機，然後同時按 Ctrl 和 C 兩個鍵。 下次只需在終端機輸入 uv run flask run。

限制

  • 使用者輸入的名字不會保存。程式只用它產生一次問候語，然後便忘記。
  • 空白文字框會產生不完整的問候語。程式不會檢查是否已輸入名字。
  • 這是開發用伺服器。Flask 的警告訊息明確指出不要把它用於正式環境； 它是讓你在自己的電腦上建立及試用應用程式。
