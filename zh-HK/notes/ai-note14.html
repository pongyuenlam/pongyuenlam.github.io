Python 程式如何用 Tavily 搜尋互聯網？

林邦源 · AI 筆記 · 2026年11月3日 · 閱讀時間約 4 分鐘

English 繁體中文 简体中文

程式有時需要來自互聯網的最新資訊：今天的新聞、一個價格、一個地址。普通的搜尋引擎是 為人而設——它回傳一頁頁夾雜廣告的連結，程式難以直接使用。Tavily 則是專為程式而設的搜尋服務：你用簡單英文向它發問，它便回傳一段簡短、現成的答案， 連同它用過的網頁。

本文的程式向 Tavily 提出 「Where is Hong Kong?」這個問題，並印出答案， 全程只用 11 行。

先取得金鑰

Tavily 需要知道誰在發問，所以程式要出示一條 API 金鑰：一串像密碼 一樣的保密字元。API 是 Application Programming Interface（應用 程式介面）的縮寫，即程式之間透過互聯網溝通的方式。要取得金鑰，請到 https://www.tavily.com/ 註冊；免費計劃已足夠試用，金鑰會顯示在儀表板上。

金鑰絕不能直接寫進程式裡，否則任何讀到代碼的人都能拿走它。金鑰應放在同一資料夾內 一個名為 .env 的小檔案中，裡面只有一行： 

TAVILY_API_KEY=paste-your-key-here

下載示範程式後，請自行建立這個檔案；zip 內並不包括它，因為金鑰是個人的。

逐段拆解程式

import os

from dotenv import load_dotenv
from tavily import TavilyClient

load_dotenv()

這裡引入了三個函式庫。os 是 operating system（作業 系統）的縮寫；在這裡用來讀取環境變數，即存放在代碼以外的設定。 load_dotenv 讀取 .env 檔案，把每一行複製到那些環境變數 之中。TavilyClient 是 Tavily 函式庫的連接器，即負責把問題送往服務的 物件。 

tavily_client = TavilyClient(api_key=os.getenv("TAVILY_API_KEY"))

這行建立連接器。os.getenv("TAVILY_API_KEY") 讀取 load_dotenv() 剛才從 .env 載入的金鑰，交給 TavilyClient。從此連接器發出的每個請求都帶著金鑰，Tavily 便知道 請求來自哪個帳戶。 

response = tavily_client.search("Where is Hong Kong?", include_answer=True)

search 呼叫負責送出問題。include_answer=True 要求 Tavily 不單回傳網頁清單，還要根據那些網頁寫出一段簡短答案。結果會以一個字典 （dictionary）的形式回傳：一組有名稱的部分，例如 "answer" 是寫好的答案， "results" 是網頁清單。 

print(response["answer"])

這行從字典中取出 "answer" 部分並印出來。想問其他問題，改動上一行的 問題即可。

完整程式

import os

from dotenv import load_dotenv
from tavily import TavilyClient

load_dotenv()

tavily_client = TavilyClient(api_key=os.getenv("TAVILY_API_KEY"))
response = tavily_client.search("Where is Hong Kong?", include_answer=True)

print(response["answer"])

在自己的電腦上執行

下載 zip 檔案並 解壓到一個資料夾。這個 zip 包含程式和一個 pyproject.toml 專案檔案。 請如上所示，加入你自己的 .env 金鑰檔案。然後在 Visual Studio Code 中 開啟資料夾，在終端機逐行輸入以下三行： 

uv python pin 3.12.10
uv sync
uv run tavily_search.py

第一行記錄這個資料夾使用哪個 Python 版本。第二行設定專案，並安裝程式需要的兩個套件 tavily-python 和 python-dotenv。第三行執行程式。幾秒之後， 答案便會出現： 

Hong Kong is located on the southeastern coast of China, at the eastern side of the Pearl River Delta, where the Pearl River meets the South China Sea. It sits directly south of Shenzhen and Guangdong province, making it a gateway between mainland China and the rest of the world.

你執行時的措辭很可能不同，因為 Tavily 會按它當刻找到的網頁，即場寫出新的答案。

如果你還未設定 uv，請先從 如何安裝 Visual Studio Code？開始，然後看 uv 筆記： Windows 或 Mac。

限制

  • 它需要金鑰和互聯網。.env 裡沒有有效的金鑰，或者 沒有連線，程式都會以錯誤終止。
  • 免費計劃有上限。Tavily 每月免費提供固定數量的搜尋；大量使用 需要付費計劃。
  • 答案的質素取決於找到的網頁。Tavily 閱讀網頁再寫出摘要，所以 問題含糊或來源欠佳，答案也會欠佳。問得精準會有幫助。
