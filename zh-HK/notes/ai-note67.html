如何把例子分成訓練與驗證兩部分（預測，版本 6）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 5 分鐘閱讀

這是預測系列的第 6 個版本，它仍然沒有訓練任何東西。它做一件事，令之後所有訓練都變得可信： 把 1,431 個例子分成訓練部分和驗證部分。模型會從第一部分學習， 並在第二部分被評分，而第二部分它從未學習過。

為甚麼要把例子留起？

一個模型可以在它訓練過的那些確切日子上拿到滿分，卻仍然毫無用處，就像一個背熟了去年試卷答案的 學生，其實對那門科目一無所知。唯一有說服力的測試，是一份學生沒見過的試卷。

驗證部分就是那份沒見過的試卷。訓練期間，程式會不斷量度模型在它上面的表現，而那些量度 — 不是訓練的那些 — 才會告訴你究竟有沒有東西真的在學。

為甚麼不是隨機分割

分割是按日期順序做的：較早的例子訓練模型，最新的例子驗證它。模型總是在它學習過的日子之後的 日子上被評分，就像真實使用時一樣。

程式怎樣運作

1. 建立和之前一樣的資料集

df = pd.read_csv('time_series.csv')

series_tensor = torch.tensor(series, dtype=torch.float32)

print("Features and targets shapes:")
print(features.shape)
print(targets.shape)
full_dataset = TensorDataset(features, targets)

torch.Size([1460])

torch.Size([1431, 29])

2. 選擇在哪裡切

total_windows = len(full_dataset)
train_size = int(total_windows * 0.8)  # 80% for training, 20% for validation
train_indices = list(range(train_size))
val_indices = list(range(train_size, total_windows))

len(full_dataset) 是 1,431。1,431 的 80% 是 1,144.8，而 int() 會丟掉小數點之後的一切，所以 train_size 變成 1,144。

range(1144) 由 0 數到 1,143：頭 1,144 個例子，最早的那些日子。 range(1144, 1431) 由 1,144 數到 1,430：其餘 287 個例子，最新的那些日子。

3. 為同一個資料集造兩個檢視

train_dataset = Subset(full_dataset, train_indices)
val_dataset = Subset(full_dataset, val_indices)

Subset 不會複製任何東西。它記錄一串位置，並透過那串位置呈現同一批底層的例子。

4. 造兩個載入器，打亂方式不同

batch_size = 32
train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=batch_size, shuffle=False)

每次模型走過訓練資料，訓練載入器都會打亂視窗的次序。它不會改變每個視窗裡面日子的時間順序。 這幫助模型從視窗裡面的銷售值學習，而不是從視窗被呈現的次序學習。

驗證載入器每次都讓例子保持同樣的次序。如果兩次執行對驗證日得出不同的誤差量度，你就知道差異 不是單純因為例子以不同的次序呈現。

5. 印出數目

print(f"Original series length: {len(series)}")
print(f"Total number of windows: {total_windows}")
print(f"Training windows: {len(train_dataset)}")
print(f"Validation windows: {len(val_dataset)}")
Original series length: 1460
Total number of windows: 1431

Validation windows: 287

6. 把分割畫出來

plt.plot(range(train_size), series[:train_size], 'b-', label='Training Data')
plt.plot(range(train_size, len(series)), series[train_size:], 'r-', label='Validation Data') 
plt.axvline(x=train_size, color='k', linestyle='--', label='Train/Val Split Point')

plt.xlabel('Time (days)')
plt.ylabel('Value')
plt.legend()
plt.grid(True)

頭兩行用兩種顏色畫出銷售數字：'b-' 是藍線，代表訓練日；'r-' 是紅線， 代表驗證日。第三行用 plt.axvline 在切口加一條黑色虛線的垂直線。 plt.legend() 印出解釋顏色的小圖例，而 plt.show() 打開視窗。

虛線標出界線：它左邊的一切，模型可以學習；它右邊的一切，模型只能被評分。

完整程式

把上面的各部分放回一起： 

import torch
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
import matplotlib.pyplot as plt
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    features = windows[:, :-1]  # All columns except the last
    targets = windows[:, -1:]   # Just the last column
    return features, targets

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
print("Series tensor shape:")
print(series_tensor.shape)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
print("Features and targets shapes:")
print(features.shape)
print(targets.shape)
full_dataset = TensorDataset(features, targets)

total_windows = len(full_dataset)
train_size = int(total_windows * 0.8)  # 80% for training, 20% for validation
train_indices = list(range(train_size))
val_indices = list(range(train_size, total_windows))

train_dataset = Subset(full_dataset, train_indices)
val_dataset = Subset(full_dataset, val_indices)

# Create DataLoaders
batch_size = 32
train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=batch_size, shuffle=False)

print(f"Original series length: {len(series)}")
print(f"Total number of windows: {total_windows}")
print(f"Training windows: {len(train_dataset)}")
print(f"Validation windows: {len(val_dataset)}")

plt.plot(range(train_size), series[:train_size], 'b-', label='Training Data')
plt.plot(range(train_size, len(series)), series[train_size:], 'r-', label='Validation Data') 
plt.axvline(x=train_size, color='k', linestyle='--', label='Train/Val Split Point')
plt.title('Time Series Train/Validation Split')
plt.xlabel('Time (days)')
plt.ylabel('Value')
plt.legend()
plt.grid(True)
plt.show()

在自己的電腦上執行

下載 zip 檔案並解壓到一個 資料夾。zip 裡有這個系列到目前為止的程式、time_series.csv 資料檔，以及 pyproject.toml。這篇筆記用的是 time_06.py。在 Visual Studio Code 裡打開資料夾，然後在終端機輸入這三行： 

uv python pin 3.12.10
uv sync
uv run time_06.py

第一行記錄這個資料夾用哪個 Python 版本，第二行安裝 pyproject.toml 列出的每一個 套件。第三行印出形狀和數目，然後打開圖表視窗；關閉它讓程式完成。

這三行只需要一次。下次想再執行程式，只打 uv run time_06.py。

如果你還沒有設定 uv，先看 如何安裝 Visual Studio Code？，然後看 uv 筆記的 Windows 或 Mac。
