如何在 macOS 安裝 Homebrew 套件管理程式？

林邦源 · AI 筆記 · 2026年11月4日 · 閱讀時間約 5 分鐘

Homebrew 自稱「The Package Manager for Everywhere」（適用於各處的套件管理程式）：它支援 macOS（Sequoia 15 或更新版本）、Linux，以及 Windows Subsystem for Linux（WSL）。套件管理程式是一條指令， 幫你下載並安裝其他程式，所以你不用四處找網站、再把檔案拖進 Applications 資料夾。 有了 Homebrew，安裝 git 之類的工具或 Firefox、Chrome 等應用程式，只需在終端機輸入短短一行。 本篇只介紹 macOS。

如影片未能載入，請在 Google 雲端硬碟開啟： 影片 （無需帳號）。

準備事項

  • 執行 macOS Sequoia（15）或更新版本的 Mac——這是 Homebrew 官方支援的版本。 舊版 macOS 或仍可使用，但不保證。
  • 網絡連線。
  • Mac 的管理員密碼——安裝程式需要權限建立自己的資料夾。如果你是自己 Mac 的唯一使用者，管理員密碼就是 Mac 鎖定畫面要求你輸入的密碼。
  • 終端機（Terminal）應用程式，在「應用程式 → 工具程式」內， 或在 Spotlight 輸入「Terminal」。

安裝指令

打開終端機，貼上這行來自 Homebrew 官方網頁的指令（截至撰寫本 AI 筆記之時）： 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

按 Return。指令會先說明它會做甚麼，然後暫停並要求你輸入密碼。 輸入 Mac 的登入密碼——畫面上不會顯示任何字元——再按一次 Return。 安裝可能需時幾分鐘，請等到指令完成並顯示 「Installation successful!」。

把 Homebrew 加入 PATH

安裝完成後，指令會在最後印出幾行，讓你的 Mac 找得到 brew 指令。 這一步很容易被忽略——但若略過，終端機會顯示 command not found。 關閉終端機前，請向上捲動到安裝程式最後印出的幾行，複製並原樣執行它們。 那幾行已因應你 Mac 的晶片給出正確資料夾，所以你不用猜是 Apple Silicon 還是 Intel。

檢查是否成功

關閉終端機再重新打開，然後輸入：

brew --version

它會印出版本編號，例如 Homebrew 4.4.0。若顯示 command not found: brew，代表 PATH 步驟尚未生效—— 請回到安裝程式印出的那幾行，重新執行一次，再重開終端機。

試試看：安裝工具與應用程式

Homebrew 有兩種套件。Formulae 是指令列工具與函式庫； casks 是完整的桌面應用程式。安裝一個指令列工具： 

brew install wget

安裝一個桌面應用程式（此例為 Firefox 瀏覽器），它會出現在 Applications 資料夾： 

brew install --cask firefox

更新 Homebrew 本身，以及升級所有以它安裝的套件： 

brew update
brew upgrade

局限

  • 需要管理員密碼才能建立資料夾與系統連結。
  • PATH 步驟最容易被遺漏。沒有它，即使安裝成功，brew 也找不到。
  • Apple Silicon 與 Intel 使用不同資料夾。請務必使用安裝程式印出的那幾行， 因為它已對應你的 Mac。
  • 每次安裝或更新套件都需要網絡連線。
