如何修改來自鏡頭的一格畫面（人臉辨識，版本 5）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 4 分鐘閱讀

版本 4 打開鏡頭，把每一格原樣顯示出來。版本 5 改變了這一點：在讀取一格和顯示它之間， 程式現在會修改它。這裡用的修改是轉換成灰階，但灰階不是重點。重點是迴圈中間的那一步， 影格停在一個變數裡，在任何人看到它之前還可以改動。

這一步一旦存在，整個系列後面的內容就看得清楚了。往裡放一個顏色轉換，視窗就顯示灰階。 放入版本 3 的人臉搜尋，視窗就能顯示一個名字。放一個框，視窗就顯示一個框。同一個鏡頭， 同一個迴圈，同一個按鍵；只有中間那一行變了。

程式怎麼運作

1. 打開鏡頭

import cv2
cap = cv2.VideoCapture(0)

和版本 4 相同的兩行：載入 OpenCV，連接第一台鏡頭。如果視窗一直不出現或者全黑， 原因在這裡，不在新加的那一行 — 權限問題，或者其他程式正在用鏡頭。

2. 讀一格，修改它，然後顯示改過的那一格

while True:
    ret, img = cap.read()
    gray_img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    cv2.imshow("Frame", gray_img)

三件事按順序發生。cap.read() 取一格彩色畫面，存進 img。下一行製作一個改動過的副本，gray_img。第三行顯示這個副本。 原來的 img 沒有被動過；改動後的版本是另一個變數。

cv2.cvtColor 就是版本 2 用來重排顏色通道的那個函式。這次的目標是 cv2.COLOR_BGR2GRAY：三個通道進去，一個通道出來。這個轉換不是簡單取平均； 綠色的權重最大，其次是紅色，最後是藍色，所以紅蘋果和青蘋果可能得出相近的亮度。

螢幕上顯示什麼，取決於哪個變數被送進 cv2.imshow。送 img，你看到的就是沒改過的鏡頭畫面，和版本 4 一樣。送 gray_img，你看到的就是改動。這一個選擇就是全部機制，後面每個版本都用不同的 中間一行再做一次。

3. 離開、放開、關閉

    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

和版本 4 一樣。waitKey(1) 既等待按鍵，也讓視窗重畫；q 或 Q 從鍵盤中斷迴圈；release 和 destroyAllWindows 在迴圈結束後收拾乾淨。記得打字之前在影片視窗上按一下， 否則按鍵會送到編輯器。

完整程式

把上面的片段拼回去。這是完整的檔案，一共 11 行： 

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    gray_img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    cv2.imshow("Frame", gray_img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

任何修改都是同一個做法

選灰階，是因為它只有一行，而且不會出錯，但這一步接受任何回傳同樣尺寸影像的操作。 換掉中間那一行，視窗就變了，程式裡別的地方都不用動。三個一行的例子，每個都用來替換 cvtColor 那一行： 

flipped  = cv2.flip(img, 1)                                # 鏡像
blurred  = cv2.GaussianBlur(img, (9, 9), 0)                # 讓畫面變柔和
brighter = cv2.convertScaleAbs(img, alpha=1.2, beta=20)    # 提高亮度

記得把新的變數傳給 cv2.imshow，否則視窗顯示的仍然是原來那一格， 看起來像什麼都沒發生。

關於灰階還有一點：它保留黑白之間的每一個深淺，通常 256 級。嚴格意義上的黑白只保留兩級， 把每個像素逼成 0 或 255。那個操作叫閾值化，丟掉的資訊比這個程式多得多。

在自己的電腦上執行

用和版本 1 相同的下載： 下載壓縮檔，解壓縮， 然後用 Visual Studio Code 打開這個資料夾。這一篇用的是 face05.py。 第一次在這個資料夾裡，執行全部三行： 

uv python pin 3.12.10
uv sync
uv run face05.py

這三行只需要做一次。下次想再執行這個程式，只需輸入 uv run face05.py。

往下讀之前，先試試上面三個替換中的一個：這是看清鏡頭那部分從來不變、只有中間那一行 在變的最快方法。
