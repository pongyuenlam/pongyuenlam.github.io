如何重用你已訓練好的模型（預測，版本 13）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 3 分鐘閱讀

這是預測系列的最後一篇筆記。版本 12 訓練了二百個模型，並把優勝者的權重儲存在一個叫 best_model_12.pt 的檔案裡。版本 13 完全不訓練：它重建同一個網路，載入那些 已儲存的權重，幾秒鐘就報出同樣的四個分數。

實際儲存的是甚麼

版本 12 模型部分的最後一行是 torch.save(best_trial["model"].state_dict(), "best_model_12.pt")。 state_dict 是一個數字的字典：每一層的權重與偏差，以它們所屬的層來命名。它不含 程式，也不含設定，而對這個優勝者來說，檔案只有大約十一 KB — 小到可以用電郵寄出。

所以檔案不能自己重建自己。版本 13 必須提供形狀 — 多少層、多寬，以及視窗多長。它按 那個形狀建立一個空的網路，然後 load_state_dict 把儲存的數字複製進去。如果 形狀不相符，PyTorch 會停下來報錯，而不是產生一個錯誤的預測。

組態從哪裡來

在版本 13 靠近頂部的地方，設定不是打進去的。它們是從版本 12 寫出的表格讀出來的： 

RESULTS_FILE = "search_results_12.xlsx"
MODEL_FILE   = "best_model_12.pt"
BATCH_SIZE   = 32

results  = pd.read_excel(RESULTS_FILE)
best_row = results.sort_values("val_loss").iloc[0]

BEST_CFG = {
    "window_size": int(best_row["window_size"]),
    "hidden_size": int(best_row["hidden_size"]),
    "num_layers":  int(best_row["num_layers"]),
}

read_excel 載入那張 200 行的表格。按 val_loss 由低到高排序， 再取 .iloc[0]，就選出優勝的那一行 — 這跟版本 12 的搜尋本身所用的規則 一樣 — 而決定形狀的三個設定按欄名複製出來。int() 把它們變成普通整數， 因為層的大小必須是普通整數。

六個設定中只需要三個。回合、學習率和優化器屬於一次訓練，而這個程式不訓練。因為表格是讀 出來的而不是打進去的，如果版本 12 重跑而另一個組合勝出，這個程式會自己跟隨新的優勝者。

程式怎樣運作

1. 用同樣的視窗長度重建資料

window_size = BEST_CFG["window_size"]
windows     = series_tensor.unfold(0, window_size, 1)
features    = windows[:, :-1]
targets     = windows[:, -1:]
full_dataset = TensorDataset(features, targets)

total   = len(full_dataset)
val_end = int(total * 0.85)
test_loader = DataLoader(Subset(full_dataset, range(val_end, total)),
                         batch_size=BATCH_SIZE, shuffle=False)

視窗和測試分割的建立方式，與 搜尋應該有多寬（版本 12）中解釋的完全一樣， 只有一個分別：這裡只建測試載入器，因為沒有東西在訓練。

2. 重建架構並載入權重

def build_model(input_size, hidden_size, num_layers):
    layers, in_dim = [], input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers)

model = build_model(window_size - 1, BEST_CFG["hidden_size"], BEST_CFG["num_layers"])
model.load_state_dict(torch.load(MODEL_FILE, map_location=device))
model.to(device)
model.eval()

網路完全按 搜尋應該有多寬（版本 12）的方式建立，所以它的 形狀與儲存的檔案相符。關鍵的那一行是 model.load_state_dict(torch.load(MODEL_FILE, map_location=device))： torch.load 讀取檔案，load_state_dict 把每一個儲存的數字複製到 相符的層。map_location 把那些數字放到任何可用的裝置上，而 model.to(device) 把網路搬到同一個地方。model.eval() 把它切換到 測試模式。

3. 讓測試日跑過已儲存的模型

preds, actuals = [], []
with torch.no_grad():
    for xb, yb in test_loader:
        preds.extend(model(xb.to(device)).cpu().numpy())
        actuals.extend(yb.numpy())

torch.no_grad() 告訴 PyTorch 這裡沒有東西在學習。程式只是在做預測，不是在 改進模型，所以這個設定節省時間和記憶體。預測值和真實值保持同樣的順序，因為載入器不會打亂 它們。

model.eval() 把網路置於測試模式。有些種類的層在訓練時和測試時行為不同，這個 設定會選用測試時的行為。這個網路只有簡單的層，所以在這裡沒有分別，但日後如果加入另一種層， 它仍然讓程式保持正確。

因為模型已經訓練好，你也可以把它用在不同的資料上。把新的銷售值以同樣格式放進一個 CSV 檔案，保持同樣的視窗長度，再執行程式一次。它會載入已儲存的權重，並為那些新的日子產生 預測，而不是那 215 個測試日。

4. 計算四個量度

mae  = torch.mean(torch.abs(p - a)).item()
mse  = torch.mean((p - a) ** 2).item()
rmse = torch.sqrt(torch.tensor(mse)).item()
r2   = (1 - torch.sum((a - p) ** 2) / torch.sum((a - torch.mean(a)) ** 2)).item()

MAE 平均誤差的大小，MSE 先把它們平方，RMSE 再取平方根，所以數字回到銷售額的單位。 R² 把模型與「總是預測測試日的平均值」相比，這在 如何衡量模型在它從未見過的資料上的表現（版本 8）裡 解釋過。

你應該會看到甚麼

一次真實執行的完整輸出，未經修改：

Config: {'window_size': 30, 'hidden_size': 32, 'num_layers': 2}

  MSE:  31.7479

四個數字與版本 12 為它的優勝者印出的完全相符，到小數第四位。沒有東西被訓練，沒有東西被 打亂，也沒有任何隨機種子參與評分。同樣的權重在同樣的 215 日上給出同樣的答案，這正是儲存 模型的用途。

整個系列一眼看完

十三個程式，一個問題：給定最近的過去，下一天的銷售額會是多少？版本 1 到 3 看資料，並把它 切成視窗。版本 4 到 6 把那些視窗變成特徵與目標，並按日期順序分割，好讓模型總是在它學習過 的日子之後的日子上評分。版本 7 訓練了一個網路。版本 8 在它從未見過的日子上誠實地給它 評分。版本 9 到 12 搜尋設定 — 訓練多久、走多大一步、用哪個優化器、多寬、多深、 往回看多遠 — 最後以二百次試驗結束。版本 13 保留了結果，並示範怎樣把它再拿起來用。

模型能做的很有限：它跟隨數列的水平與緩慢的上升趨勢，把 29 個過去的值變成一個數字，只需 一瞬間。它跟不上每日的波動；R² 大約 0.37，意味著測試日大約三分之二的變化仍然未有 解釋。網路只看最近的銷售值，所以它不知道星期幾、月份或假期。

更好的下一步不是更大的搜尋，而是更好的輸入，或者另一種模型，例如一種能記住更長模式的 模型。但有一個障礙先要解決：time_series.csv 的時間欄是 1 到 1,460 的步數， 不是日期，所以在為每一行接上真實日期之前，無法算出星期幾和月份。

完整程式

把上面的各部分放回一起。這就是完整的檔案： 

import os
os.environ["KMP_DUPLICATE_LIB_OK"] = "TRUE"

import torch
import torch.nn as nn
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from torch.utils.data import TensorDataset, DataLoader, Subset

# ── Best config, selected by validation loss in search_results_12.xlsx ───────
RESULTS_FILE = "search_results_12.xlsx"
MODEL_FILE   = "best_model_12.pt"
BATCH_SIZE   = 32

results  = pd.read_excel(RESULTS_FILE)
best_row = results.sort_values("val_loss").iloc[0]

BEST_CFG = {
    "window_size": int(best_row["window_size"]),
    "hidden_size": int(best_row["hidden_size"]),
    "num_layers":  int(best_row["num_layers"]),
}

# ── Load data ─────────────────────────────────────────────────────────────────
df = pd.read_csv("time_series.csv")
series = df["series"].values
series_tensor = torch.tensor(series, dtype=torch.float32)

window_size = BEST_CFG["window_size"]
windows     = series_tensor.unfold(0, window_size, 1)
features    = windows[:, :-1]
targets     = windows[:, -1:]
full_dataset = TensorDataset(features, targets)

total   = len(full_dataset)
val_end = int(total * 0.85)
test_loader = DataLoader(Subset(full_dataset, range(val_end, total)),
                         batch_size=BATCH_SIZE, shuffle=False)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# ── Rebuild model architecture & load weights ─────────────────────────────────
def build_model(input_size, hidden_size, num_layers):
    layers, in_dim = [], input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers)

model = build_model(window_size - 1, BEST_CFG["hidden_size"], BEST_CFG["num_layers"])
model.load_state_dict(torch.load(MODEL_FILE, map_location=device))
model.to(device)
model.eval()
print(f"Loaded: {MODEL_FILE}")
print(f"Config: {BEST_CFG}\n")

# ── Evaluate ──────────────────────────────────────────────────────────────────
preds, actuals = [], []
with torch.no_grad():
    for xb, yb in test_loader:
        preds.extend(model(xb.to(device)).cpu().numpy())
        actuals.extend(yb.numpy())

p = torch.tensor(np.array(preds))
a = torch.tensor(np.array(actuals))

mae  = torch.mean(torch.abs(p - a)).item()
mse  = torch.mean((p - a) ** 2).item()
rmse = torch.sqrt(torch.tensor(mse)).item()
r2   = (1 - torch.sum((a - p) ** 2) / torch.sum((a - torch.mean(a)) ** 2)).item()

print(f"Test Set Metrics:")
print(f"  MAE:  {mae:.4f}")
print(f"  MSE:  {mse:.4f}")
print(f"  RMSE: {rmse:.4f}")
print(f"  R²:   {r2:.4f}")

# ── Plots ─────────────────────────────────────────────────────────────────────
# 1. Predictions vs actual
plt.figure(figsize=(12, 5))
plt.plot(actuals, label="Actual",    color="lightgrey", linewidth=1.5)
plt.plot(preds,   label="Predicted", color="red",       linewidth=1.5)
plt.title(f"Best Model — Predictions vs Actual (Test Set)\nR²={r2:.4f}  RMSE={rmse:.4f}", fontsize=11)
plt.xlabel("Time"); plt.ylabel("Value")
plt.legend(); plt.grid(True)
plt.tight_layout()
plt.savefig("best_model_predictions.png", dpi=150)
plt.show()
print("Saved: best_model_predictions.png")

在自己的電腦上執行

下載 zip 檔案並解壓 到一個資料夾。zip 裡有這個系列的程式、time_series.csv 資料檔和 pyproject.toml。這篇筆記用的是 time_13.py。

版本 13 有一個之前任何筆記都沒有的要求：它需要 best_model_12.pt，而那個檔案只有在 time_12.py 於同一個資料夾 跑過一次之後才會存在。版本 12 跑二百次試驗，需要好一段時間才完成。 版本 13 只需幾秒，因為它完全不做那些工作。

在 Visual Studio Code 裡打開資料夾，然後在終端機輸入這三行： 

uv python pin 3.12.10
uv sync
uv run time_13.py

第一行記錄這個資料夾用哪個 Python 版本，第二行安裝 pyproject.toml 列出的每一個 套件。第三行載入已儲存的權重，印出四個分數並畫一張圖表，存成 best_model_predictions.png；看完之後關閉視窗。

這三行只需要一次。下次想再執行程式，只打 uv run time_13.py。

如果你還沒有設定 uv，先看 如何安裝 Visual Studio Code？，然後看 uv 筆記的 Windows 或 Mac。
