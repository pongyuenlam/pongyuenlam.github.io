如何安裝 Visual Studio Code？

林邦源 · AI 筆記 · 2026年11月1日 · 閱讀時間約 4 分鐘

English 繁體中文 简体中文

Visual Studio Code——簡稱 VS Code——是微軟推出的免費整合開發環境（Integrated Development Environment，IDE）。簡單來說，它是一個把檔案集中管理、讓你編輯檔案、 並在文字旁邊顯示 AI 協助的程式。它就是我在較早前的筆記 〈無程式碼、低程式碼、氛圍編程與編程〉中 介紹過的編輯器。你只需安裝一次，在 Windows 或 Mac 上都只需要幾分鐘。

觀看示範影片

如果影片無法載入，請在 Google Drive 開啟： 影片 （無需帳戶）。

下載安裝程式

前往 code.visualstudio.com/download， 選擇適合你電腦的按鈕。這個頁面由微軟發佈，下載完全免費。

在 Windows 上安裝

在下載頁面選擇 Windows 按鈕，執行下載的檔案。接受授權條款， 然後一直按 Next，直到出現 Install 並點擊它。 預設選項已經足夠。

在 Mac 上安裝

在下載頁面選擇 Mac 按鈕——如果你的 Mac 較新，選擇名為 「Apple silicon」的晶片版本；如果不確定，選擇「Intel」。

雙擊下載的檔案解壓，然後把 Visual Studio Code 拖進 Applications（應用程式）資料夾。之後從 Launchpad 或 Spotlight 開啟它，就像開啟 Word 或 Excel 一樣。

驗證安裝

開啟 Visual Studio Code。你應該會看到一個列出最近資料夾的 Welcome（歡迎）分頁。這就是所需的全部設定，暫時無需再配置任何東西。
