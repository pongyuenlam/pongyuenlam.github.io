如何在預測前先看你的銷售資料（預測，版本 1）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 4 分鐘閱讀

這是預測系列的第 1 個版本。這個系列每隔一小步，逐步建立一個能從過去銷售額預測未來銷售額的 程式。版本 1 完全沒有 AI：它讀取一個每日銷售數字的檔案，並畫出一張折線圖。這是刻意的—— 在電腦能預測任何事之前，你必須先看看你要求它學習的資料。

資料從哪裏來？

程式讀取一個名為 time_series.csv 的檔案。CSV 檔案是一個純文字表格：每一行 是一列，一列中的值用逗號分隔。這個檔案有兩欄，time 和 series， 以及 4 × 365 = 1,460 列 —— 每天一列，大約四年的每日銷售額，以港幣計。 

time,series
1.0,29.395714
2.0,33.40659
3.0,37.858486
4.0,29.14184

日期數字寫成 1.0、2.0 這樣，而不是 1、2： .0 標明它們是十進位（浮點）數字，和銷售數字是同一類數字，所以檔案通篇使用 一致的數字格式。

像這樣按時間順序排列的一串數字，叫做時間序列，檔案的名字就是由此而來。 預測就是利用這樣一串數字的前面部分，去預測接着出現的值。

程式怎樣運作

1. 載入兩個函式庫

import pandas as pd
import matplotlib.pyplot as plt

pandas 是讀取表格的函式庫，它被賦予簡短的名字 pd，讓程式碼保持 精簡。matplotlib 是畫圖表的函式庫，它的繪圖部分被賦予簡短的名字 plt。這兩行是幾乎每個資料程式都會見到的慣例。

2. 把檔案讀入表格

df = pd.read_csv('time_series.csv')
series = df['series'].values

第一行把 CSV 檔案讀入 df，一個 data frame（資料框）—— pandas 對有欄名的表格的叫法。第二行按名稱取出其中一欄 df['series']，而 .values 剝掉表格的外衣，只留下赤裸的數字：一行 1,460 個銷售數字， 準備好被繪畫或用於計算。

注意程式對 time 欄做了什麼：什麼都沒有。在這個檔案裡，各列已經按時間順序 排列，所以一個數字在清單中的位置就是它的時間。下面的圖表只是畫出第 1 天、第 2 天、 第 3 天，如此類推。

3. 畫出圖表

plt.plot(series)
plt.title('Sales per day')
plt.xlabel('Day')
plt.ylabel('Sales-HK$')
plt.grid(True)
plt.show()

plt.plot(series) 畫出一條穿過全部 1,460 個數字的線。接下來三行加上收尾的 修飾：plt.title('Sales per day') 是標題，plt.xlabel('Day') 是水平軸下面的標籤，plt.ylabel('Sales-HK$') 是垂直軸旁邊的標籤。 plt.grid(True) 加上淺色的背景線，讓人更容易從圖表上讀出數值。

最後一行 plt.show() 才是真正把視窗放上螢幕的那一步。

你應該會看到

一個視窗打開，一條線由左向右攀升：銷售額由每天接近 HK$30 開始，到接近 HK$160 結束， 沿途有小幅的上上落落。

在開始任何預測之前，有兩件事值得注意。第一，這個數列有向上的趨勢—— 後面的日子系統性地高於前面的日子。第二，這些上上落落是圍繞那個趨勢的、 看來隨機的雜訊。未來的版本必須處理這兩個事實，而親眼看見它們， 就是先畫這張圖的原因。

完整程式

把上面的各部分放回一起。這就是完整的檔案，共 10 行： 

import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_csv('time_series.csv')
series = df['series'].values
plt.plot(series)
plt.title('Sales per day')
plt.xlabel('Day')
plt.ylabel('Sales-HK$')
plt.grid(True)
plt.show()

在自己的電腦上執行

下載 zip 檔案並解壓到 一個資料夾。zip 裡有 time_01.py、time_series.csv 資料檔， 以及 pyproject.toml。在 Visual Studio Code 裡打開這個資料夾， 然後在終端機輸入這三行： 

uv python pin 3.12.10
uv sync
uv run time_01.py

第一行記錄這個資料夾用哪個 Python 版本，第二行安裝 pyproject.toml 列出的 每一個套件。第三行打開圖表視窗；關閉它，讓程式完成。

這三行只需要一次。下次想再執行程式，只打 uv run time_01.py。

如果你還沒有設定 uv，先看 如何安裝 Visual Studio Code？，然後看 uv 筆記的 Windows 或 Mac。

接下來是甚麼

版本 1 顯示資料，但一張圖表不是一個預測。版本 2 踏出朝向預測的第一步：把數列切成 滑動視窗 —— 這種安排把過去的銷售額變成模型可以學習的訓練例子。
