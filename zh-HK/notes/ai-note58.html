如何在每一格畫面上畫框和標籤（人臉辨識，版本 6）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 4 分鐘閱讀

版本 5 證明了影格在顯示之前可以被修改。版本 6 用這一步來畫：一個紅色矩形和一行字 "This is a test"，固定在畫面上的同一個位置。這個框還不跟著任何東西。它在這裡， 是為了版本 7 有地方放它的結果：框會移到人臉上，那行字會變成名字。

角在哪裡

影像沒有左下角的原點。位置以像素計算，從左上角算起：x 向右增大，y 向下增大。這和數學裡畫的座標圖相反，也是框 出現在意料之外的地方最常見的原因。

程式怎麼運作

1. 打開鏡頭，讀一格

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()

和版本 4 一樣。迴圈每一輪都在 img 裡給出一格新的畫面，這也讓畫圖變得安全： 現在畫上去的東西會隨著這一格一起消失，下一格來的時候是乾淨的。

2. 選定兩個角

    x1, y1 = 100, 200
    x2, y2 = x1 + 200, y1 + 150

第一行是左上角：距左邊 100 像素，距頂部 200 像素。第二行用尺寸而不是位置算出右下角： 寬 200 像素、高 150 像素，得到 (300, 350)。這樣寫，以後改尺寸很方便。

3. 畫矩形

    cv2.rectangle(img, (x1, y1), (x2, y2), (0, 0, 255), 2)

參數是影像、兩個角、顏色和線寬。顏色是按 BGR 順序的三個數，不是 RGB： (0, 0, 255) 是沒有藍、沒有綠、全紅。最後的 2 是線寬，單位像素； 數字更大，框的邊就更粗。

4. 寫標籤

    cv2.putText(img, "This is a test", (x1, y1 - 10), cv2.FONT_HERSHEY_DUPLEX, 1, (0, 0, 255), 2)

七個參數，順序是：影像、文字、位置、字體、大小、顏色、線寬。位置是文字的 左下角，不是左上角，所以 y1 - 10 把字抬到框的上邊之上十個 像素，而不是讓它壓在框上。

cv2.FONT_HERSHEY_DUPLEX 是 OpenCV 內建的幾種簡單字體之一，1 是大小倍數，寫 2 就會大一倍。顏色和線寬的意思和畫矩形時一樣。

5. 顯示，然後離開並收拾

    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

cv2.imshow 現在收到的是 img — 畫過的那一格 — 所以框出現在視窗裡。按鍵和收尾都和版本 4 一樣。

完整程式

把上面的片段拼回去。這是完整的檔案，一共 14 行： 

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    x1, y1 = 100, 200
    x2, y2 = x1 + 200, y1 + 150
    cv2.rectangle(img, (x1, y1), (x2, y2), (0, 0, 255), 2)
    cv2.putText(img, "This is a test", (x1, y1 - 10), cv2.FONT_HERSHEY_DUPLEX, 1, (0, 0, 255), 2)
    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

畫圖改的是畫面本身

版本 5 另外做了一個變數，原來的那個沒有動。這個版本不一樣： cv2.rectangle 和 cv2.putText 直接改 img，不回傳任何有用的東西。沒有 img_with_box。

在這裡這沒有害處，原因只有一個：每一輪結束時這一格就被丟掉，迴圈開頭會換成新的一格， 所以框每一格畫一次，畫在乾淨的畫面上。它不會越積越多。如果你改成在一張保存下來的相片上畫， 再寫回硬碟，那麼每執行一次就會多留下一個框。

移動這個框

改 100, 200，框就移動；改 200, 150，框就改變大小。超出畫面的 數值不是錯誤：框落在畫面外的部分只是不畫出來。這一點在版本 7 把貼著畫面邊緣的框交給 程式之前，值得先知道。

在自己的電腦上執行

用和版本 1 相同的下載： 下載壓縮檔，解壓縮， 然後用 Visual Studio Code 打開這個資料夾。這一篇用的是 face06.py。 第一次在這個資料夾裡，執行全部三行： 

uv python pin 3.12.10
uv sync
uv run face06.py

這三行只需要做一次。下次想再執行這個程式，只需輸入 uv run face06.py。

影片靠左上的位置應該有一個紅色的框，上面寫著 "This is a test"。如果框跑到畫面外， 檢查你改的是哪一個角：y1 大於畫面高度，框就被推到下面外面去了。

下一步

版本 7 在這個迴圈裡做版本 3 的工作：它在每一格裡找出人臉，把框畫在人臉外面而不是固定位置， 並把辨識出的名字放到現在測試標籤的位置。
