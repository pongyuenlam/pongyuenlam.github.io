如何用騰訊 WorkBuddy 取得網站連結？

林邦源 · AI 筆記 · 2026年11月26日 · 閱讀時間約 3 分鐘

English 繁體中文 简体中文

電腦上的 HTML 檔案沒有可以傳給別人的網址。要得到網址，檔案必須被託管： 一部連上互聯網的電腦保存這個頁面，並向訪客顯示。

騰訊 WorkBuddy 的國際版可以在對話中完成這件事：附加一個 HTML 檔案，請 WorkBuddy 託管， 它便回覆一條連結。

本文的例子是 如何用語音辨識讓網頁聽懂說話（版本 2）？中的聆聽頁面。 你可以開啟已託管的範例 看看結果。

開始前需要甚麼

  • 一個 HTML 檔案。它應能在瀏覽器開啟並運作。範例檔案名為 index.html。
  • 騰訊 WorkBuddy 國際版。在 www.workbuddy.ai 開啟，如網站要求就先登入。
  • 互聯網連線。WorkBuddy 讀取檔案並把頁面放上網。

步驟 1：準備 HTML 檔案

使用你自己的檔案，或從聆聽頁面的筆記下載 index.html。把檔案放在容易找到的位置，例如桌面或「下載」資料夾。

這個例子是單一自足檔案：頁面和腳本都在 index.html 內，沒有其他檔案要上載。

步驟 2：在 WorkBuddy 附加檔案

在 WorkBuddy 國際版開始新對話。用附件控制項加入 index.html，就像附加文件或 圖片一樣。

步驟 3：請 WorkBuddy 託管

附上檔案並送出這句：

read the attached html file, and let me know whether you can help host it online?

WorkBuddy 會讀取檔案並準備網上副本。如果回覆沒有連結，就請它託管頁面並提供網址。

步驟 4：複製並測試連結

WorkBuddy 會回覆一個網址。以範例檔案而言，網址是： 

https://wbapp-p9pnbs1i3wmpuod8agncme.apps.workbuddy.host/?sharecode=ND6FKZWMKB

在新的瀏覽器分頁開啟整個網址。頁面現在來自 WorkBuddy 的託管服務，而不是你電腦上的檔案。 把連結傳給任何人之前，先測試它的按鈕和其他功能。

複製整個網址，包括 sharecode= 之後的部分。完整網址就是可分享的連結。 訪客無需你傳送 HTML 檔案。

限制

  • 網址由 WorkBuddy 控制。它不是你的網域，託管服務也可能改變。截至本文刊登 日期，WorkBuddy 未說明連結的有效期限。最新資訊請看 騰訊的官方文件。 保留原始 HTML 檔案，以便連結失效時再託管。
  • 把分享頁面視為公開。上載前先移除檔案中的密碼、個人資料和其他私密資訊。
  • 這個例子只有一個 HTML 檔案。若網站有獨立的圖片、樣式檔或腳本，就需要一併 提供。Python 網站又不同，因為它需要執行 Python 的伺服器。
  • 託管不改變頁面的需要。聆聽範例仍然需要 Chrome 或 Edge、麥克風權限， 以及用於語音辨識的互聯網連線。
