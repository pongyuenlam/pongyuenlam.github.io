如何訓練你的第一個預測模型（預測，版本 7）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 6 分鐘閱讀

這是預測系列的第 7 個版本。版本 6 準備並分割了資料；版本 7 加入一個細小的神經網路，並讓它在 訓練例子中走過 100 遍。

模型是甚麼

模型接收最近 29 天作為輸入，回傳一個數字：它對下一天的猜測。內部是一個神經網路模型。這篇筆記 不會詳細解釋神經網路。將來的 AI 筆記會解釋它們怎樣運作。

訓練怎樣運作

一個回合是完全走過所有訓練例子一次，意思是模型把每個例子都看過一次。每個 回合裡，程式對每一批 32 個例子做同樣四件事：

  1. 把 29 天給模型看，收集它的猜測。
  2. 把猜測與真實的下一天比較，算出誤差，稱為損失。
  3. 找出哪些權重令損失變差，以及差了多少。
  4. 把每個權重稍微調整，以減少損失。

一個批次是一起處理的一組訓練例子。在這個程式裡，一個完整批次有 32 個例子。 這裡的損失是均方誤差：把答案減去猜測，平方，再對整個批次取平均。平方令錯得遠 的猜測比接近的猜測計得更重。

走完訓練批次之後，程式在驗證例子 — 較後的日子，模型從未學習過 — 上量度損失。 兩個數字都會記錄下來，以便畫出來。

程式怎樣運作

1. 定義網路

class TimeSeriesModel(nn.Module):
    def __init__(self, window_size):
        super(TimeSeriesModel, self).__init__()
        self.network = nn.Sequential(
            nn.Linear(window_size-1, 10),  # window_size-1 because our features are window_size-1
            nn.ReLU(),
            nn.Linear(10, 10),
            nn.ReLU(),
            nn.Linear(10, 1)
        )

    def forward(self, x):
        return self.network(x)

class ... (nn.Module) 是定義 PyTorch 模型的標準做法。__init__ 一次過建立各個層，而 nn.Sequential 的意思是按這個次序執行這些層。 forward 是模型被呼叫時發生的事：一批輸入進去，一批預測出來。當 window_size = 30，第一層預期 29 個數字，而這正是特徵所裝着的。

2. 選擇損失和優化器

model = TimeSeriesModel(window_size)
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters())

criterion 用均方誤差計算誤差。optimizer 用那個誤差調整模型的權重。 model.parameters() 把網路中每一個權重交給優化器，所以它知道自己可以改變哪些值。

3. 選擇運算在哪裡進行

num_epochs = 100
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model.to(device)

cuda 是 NVIDIA 用來借助其顯示卡更快做這些運算的技術。在 Mac 或沒有 NVIDIA 顯示卡的筆記型電腦上，程式會靜靜地改用 cpu。model.to(device) 把模型搬到那個地方，而各個批次也會被搬到相應的地方。

4. 訓練迴圈

for epoch in range(num_epochs):
    model.train()
    train_loss = 0
    for batch_features, batch_targets in train_loader:
        batch_features = batch_features.to(device)
        batch_targets = batch_targets.to(device)
        outputs = model(batch_features)
        loss = criterion(outputs, batch_targets)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        train_loss += loss.item()

model.train() 把網路置於學習模式。內層迴圈走過各個訓練批次。對每一批， model(batch_features) 作出猜測，而 criterion 把這些猜測變成一個損失。

接下來三行幫助模型從每一批學習。optimizer.zero_grad() 清除上一批留下的調整計算。 loss.backward() 算出每個權重應該怎樣改變才能減少誤差。optimizer.step() 套用那些改變。把這三行重複幾千次，就是模型學習的方式。

5. 在驗證日量度

    model.eval()
    val_loss = 0
    with torch.no_grad():
        for batch_features, batch_targets in val_loader:
            batch_features = batch_features.to(device)
            batch_targets = batch_targets.to(device)
            outputs = model(batch_features)
            val_loss += criterion(outputs, batch_targets).item()

model.eval() 切換到量度模式，而 torch.no_grad() 說不必費力算出 哪些權重要負責，我們在這裡不會改變它們。這節省時間和記憶體。然後驗證損失會除以批次的 數目，令訓練損失和驗證損失處於同一個尺度，而這一對數字每十個回合印一次。

6. 畫兩張圖

plt.plot(train_losses, label='Training Loss')
plt.plot(val_losses, label='Validation Loss')

第一張圖把兩個損失對回合數顯示出來：一條應該下降然後變平的線。第二張圖把模型的猜測與真實的 驗證日畫在一起，灰色是真實值，紅色是預測值，讓你可以看到兩條線是否疊在一起。

7. 把所有東西歸結為一個數字

mae_torch = torch.mean(torch.abs(val_predictions_tensor - val_targets_tensor))
print(f"Validation MAE (PyTorch): {mae_torch:.4f}")

MAE，平均絕對誤差，是預測值與實際值之間的平均差距，不理會每個預測是偏高還是 偏低。在這次執行中，它大約是 HK$4.76。驗證部分的每日銷售額大約是 HK$140，所以 (4.76 ÷ 140) × 100 ≈ 3.4%。換句話說，平均預測誤差大約是典型一日 銷售額的 3%。MAE 比平方損失更容易向經理解釋，因為它是以銷售金額的元為單位。

你的數字不會和這些完全一樣。權重由隨機值開始，所以每次執行都會走一條稍微不同的下坡路。應該 一樣的是形狀：兩個損失最初都快速下降，然後在同一個水平附近起伏。

完整程式

把上面的各部分放回一起。這就是完整的檔案： 

import torch
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
import matplotlib.pyplot as plt
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    features = windows[:, :-1]  # All columns except the last
    targets = windows[:, -1:]   # Just the last column
    return features, targets

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
full_dataset = TensorDataset(features, targets)

total_windows = len(full_dataset)
train_size = int(total_windows * 0.8)  # 80% for training, 20% for validation
train_indices = list(range(train_size))
val_indices = list(range(train_size, total_windows))

train_dataset = Subset(full_dataset, train_indices)
val_dataset = Subset(full_dataset, val_indices)

# Create DataLoaders
batch_size = 32
train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=batch_size, shuffle=False)

import torch
import torch.nn as nn
import torch.optim as optim

# Define the model
class TimeSeriesModel(nn.Module):
    def __init__(self, window_size):
        super(TimeSeriesModel, self).__init__()
        self.network = nn.Sequential(
            nn.Linear(window_size-1, 10),  # window_size-1 because our features are window_size-1
            nn.ReLU(),
            nn.Linear(10, 10),
            nn.ReLU(),
            nn.Linear(10, 1)
        )

    def forward(self, x):
        return self.network(x)

# Initialize model, loss function, and optimizer
model = TimeSeriesModel(window_size)
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters())

# Training loop
num_epochs = 100
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model.to(device)

# Lists to store losses for plotting
train_losses = []
val_losses = []

for epoch in range(num_epochs):
    # Training phase
    model.train()
    train_loss = 0
    for batch_features, batch_targets in train_loader:
        batch_features = batch_features.to(device)
        batch_targets = batch_targets.to(device)

        # Forward pass
        outputs = model(batch_features)
        loss = criterion(outputs, batch_targets)

        # Backward pass and optimize
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        train_loss += loss.item()

    # Validation phase
    model.eval()
    val_loss = 0
    with torch.no_grad():
        for batch_features, batch_targets in val_loader:
            batch_features = batch_features.to(device)
            batch_targets = batch_targets.to(device)

            outputs = model(batch_features)
            val_loss += criterion(outputs, batch_targets).item()

    # Calculate average losses
    train_loss /= len(train_loader)
    val_loss /= len(val_loader)

    train_losses.append(train_loss)
    val_losses.append(val_loss)

    if (epoch + 1) % 10 == 0:
        print(f'Epoch [{epoch+1}/{num_epochs}], '
              f'Train Loss: {train_loss:.4f}, '
              f'Val Loss: {val_loss:.4f}')

# Plot training progress
plt.figure(figsize=(10, 6))
plt.plot(train_losses, label='Training Loss')
plt.plot(val_losses, label='Validation Loss')
plt.title('Model Loss Over Time')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()
plt.grid(True)
plt.show()

# Make predictions
model.eval()
with torch.no_grad():
    # Get predictions for validation set
    val_predictions = []
    val_targets = []
    for batch_features, batch_targets in val_loader:
        batch_features = batch_features.to(device)
        outputs = model(batch_features)
        val_predictions.extend(outputs.cpu().numpy())
        val_targets.extend(batch_targets.numpy())

# Plot predictions vs actual for validation set
plt.plot(val_targets, label='Actual', color="lightgrey")
plt.plot(val_predictions, label='Predicted', color="red")
plt.title('Predictions vs Actual Values (Validation Set)')
plt.xlabel('Time')
plt.ylabel('Value')
plt.legend()
plt.grid(True)
plt.show()

val_predictions_tensor = torch.tensor(val_predictions)
val_targets_tensor = torch.tensor(val_targets)
mae_torch = torch.mean(torch.abs(val_predictions_tensor - val_targets_tensor))
print(f"Validation MAE (PyTorch): {mae_torch:.4f}")

在自己的電腦上執行

下載 zip 檔案並解壓到一個 資料夾。zip 裡有這個系列到目前為止的程式、time_series.csv 資料檔，以及 pyproject.toml。這篇筆記用的是 time_07.py。在 Visual Studio Code 裡打開資料夾，然後在終端機輸入這三行： 

uv python pin 3.12.10
uv sync
uv run time_07.py

第一行記錄這個資料夾用哪個 Python 版本，第二行安裝 pyproject.toml 列出的每一個 套件。第三行每十個回合印出一行，然後打開損失圖和預測圖；關閉每個視窗讓程式繼續。

這三行只需要一次。下次想再執行程式，只打 uv run time_07.py。

如果你還沒有設定 uv，先看 如何安裝 Visual Studio Code？，然後看 uv 筆記的 Windows 或 Mac。
