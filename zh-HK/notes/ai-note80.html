如何用語音合成讓網頁把文字讀出來（版本 1）？

林邦源 · AI 筆記 · 2026年11月26日 · 閱讀時間約 4 分鐘

English 繁體中文 简体中文

大多數瀏覽器本身就會說話。網頁不需要伺服器、不需要 Python 程式，也無需安裝任何東西： 一個 HTML 檔案，連按兩下開啟，就能讀出你輸入的文字。

這個頁面用的是語音合成（speech synthesis），也就是每個現代瀏覽器都內建的 Web Speech API 的其中一半。

開始前需要甚麼

  • 一個瀏覽器。Chrome、Edge、Safari 和 Firefox 都能把文字讀出來。
  • 一個文字編輯器。有 Visual Studio Code 就用它；否則先看 如何安裝 Visual Studio Code？
  • 開啟聲音。朗讀聲音會從電腦的揚聲器播出。

步驟 1：建立檔案

下載 zip 檔案並解壓。 Mac 上連按兩下 zip；Windows 上按右鍵，選 Extract All。你會得到一個名為 Folder-AI-Speech-01-Read-Aloud 的資料夾，內有 index.html。 連按兩下 index.html，它就會在瀏覽器開啟。無需使用終端機，也無需啟動伺服器。

步驟 2：整個檔案

以下是 index.html 的全部內容：

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Read aloud</title>
</head>
<body>
<h1>Read aloud</h1>
<label for="text">Text:</label>
<textarea id="text" rows="3">Hello, World!</textarea>
<button onclick="speak()">Speak</button>
<button onclick="stopSpeaking()">Stop</button>
<script>
function speak() {
  speechSynthesis.cancel();
  const text = document.getElementById('text').value;
  const utterance = new SpeechSynthesisUtterance(text);
  speechSynthesis.speak(utterance);
}
function stopSpeaking() {
  speechSynthesis.cancel();
}
</script>
</body>
</html>

上半部是普通網頁：一個標題、一個標籤、一個內含 Hello, World! 的文字框，以及兩個按鈕。 textarea 是接受多行的輸入框，所以整段文字也放得下。每個按鈕都有一個 onclick 屬性，指明按下時要執行的函數。

步驟 3：腳本中的三個名稱

只有三個名稱要緊。speechSynthesis 是瀏覽器的語音引擎。 SpeechSynthesisUtterance 是一段準備朗讀的文字；每次都要建立新的， 因為每個都載有自己的字句。speak() 把它交給引擎。

speechSynthesis.cancel() 會停止仍在朗讀的內容。它出現兩次：一次在 speak() 開頭，以免第二次按下與第一次重疊；一次在 stopSpeaking() 內，也就是 Stop 按鈕所呼叫的函數。

步驟 4：試一試

輸入一句或一段英文，按一下 Speak，電腦便會讀出來。按一下 Stop 可中途停止。

輸入中文句子通常不會有聲音。頁面從沒告訴瀏覽器要用哪種語言朗讀，所以瀏覽器會退回預設語音， 通常就是英文。如何指定語言，見「限制」一節。

限制

  • 聲音由電腦選擇。頁面沒有說明要用哪種語言，瀏覽器便使用預設語音，通常是 英文。交給英文語音的中文文字一般會被略過，靜默無聲。為文字指定語言，例如 utterance.lang = 'zh-CN'，是另一個題目。
  • 按下之後才會開始朗讀。瀏覽器會讓頁面保持靜音，直到訪客與頁面互動； Speak 按鈕就提供了這個互動。
  • 語音來自裝置。多數系統離線也能朗讀，因為語音已安裝在本機；但少數瀏覽器 會改用網上語音。
