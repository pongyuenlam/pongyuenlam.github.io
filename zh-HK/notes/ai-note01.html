如何在無程式碼、低程式碼、氛圍編程與傳統編程中使用 AI？

林邦源 · AI 筆記 · 2026年10月31日 · 閱讀時間約 5 分鐘

English 繁體中文 简体中文

大多數人透過聊天框接觸 AI，對編程一無所知。懂一點程式能令三件事更容易：修正 AI 的輸出、在自己的電腦上運行免費的開源套件與模型，以及混合使用本地與雲端工具以獲得更好的效益。這也讓我們使用 AI 時更不容易出錯。

很多年前，沒有人懂得使用 PowerPoint、Excel 或 Word。今天我們期望每個人都懂得使用它們。 AI 正走著同一條路。

今天，許多人在完全不懂編程的情況下使用 AI——這就是「無程式碼」AI。他們只需在以下 服務商的聊天介面中輸入訊息：

  • chat.deepseek.com
  • chat.qwen.ai
  • kimi.ai
  • gemini.google.com

我們也可以繼續用自然語言——例如英文或中文——輸入指示，讓 AI 為我們製作 PowerPoint、 Excel 和 Word 檔案。但如果 我們也懂得直接在這些應用程式中修改，就能快速修正 AI 的輸出——甚至不需要問 AI， 自己用 SUM 公式建立一個簡單的試算表來加總數字。

氛圍編程

使用「氛圍編程」時，我們只需用自然語言描述想要的效果，AI 便會替我們完成。對於草稿、 原型和一次性任務，它既快速又寬容。但當我們看不懂 AI 產出的內容時，局限就出現了 ——因為我們無法判斷它是否正確。

低程式碼：代理模式與整合開發環境（Integrated Development Environment，IDE）模式

理解關鍵的編程概念，或懂得使用別人已開發好的免費程式與套件，確實大有好處。這裡的 「低程式碼」指的是只需少量程式碼，大部分的輸入工作由 AI 代勞。

因此，學習以「代理模式」和「IDE 模式」使用 AI，比單靠「聊天模式」更有優勢。

  • 聊天模式只回傳文字，你需要自己複製到檔案中。
  • 代理模式會編輯檔案、執行指令並檢查結果，你只需審視每項修改。
  • IDE 模式把代理放進編輯器中，就在它正在修改的專案旁邊。

好消息是，許多 AI 公司都不想重複造輪子：它們使用與 Visual Studio Code（VS Code） ——微軟的免費 IDE——相同的指令與介面。大部分的擴充功能、鍵盤快捷鍵和設定都可以 直接沿用。

打個比方：沒有鍵盤製造商會重新設計一個比現行 asdf 配置「更好」的鍵盤——我們左手 四隻手指早已熟悉它了。同樣，AI 公司也沒有必要發明新介面——以 VS Code 為標準對大家 都有好處。勝出的標準不一定是最好的，而是大家都在使用的那一個。

從這裡開始

如要免費下載及安裝 Visual Studio Code，請前往 code.visualstudio.com/download。 如需逐步設定教學，請參閱我的 〈使用 uv 設定 VS Code + Python 指南〉。

你不需要成為開發者。但懂得使用 Visual Studio Code，就像懂得使用 PowerPoint、Excel 和 Word 一樣，能幫助你有效地使用 AI——得到你真正想要的結果——而且更有效率：你可以 在自己的電腦上運行模型並反覆修改，而不是每次都要等待雲端模型回應，並為每一來回付費。 你當年花了多少小時學習 PowerPoint、Excel 和 Word？學會 VS Code，你就能成為 AI 的 專家用戶，而非普通用戶。

如此一來，AI 就能成為你的盟友，而非對手。用廣東話說：「AI係你對手，唔係你嘅對手。」

上面的廣東話句子改寫自以下新聞報道： 「五年規劃｜AI係你嘅對手定係你對手？鄧炳強：善用並規管得宜絕非威脅」 （星島頭條，2026年9月21日，中文）——香港保安局局長認為，只要善用並規管得宜，AI 是工具而非威脅。
