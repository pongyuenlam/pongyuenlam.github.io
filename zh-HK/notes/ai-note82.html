如何讓網頁聽完你說話後以語音回答（版本 3）？

林邦源 · AI 筆記 · 2026年11月27日 · 閱讀時間約 5 分鐘

English 繁體中文 简体中文

網頁可以在同一頁上聆聽和說話。這個頁面聽見你說的話、顯示文字，然後開口回答。 它仍然是一個 HTML 檔案、一段短腳本。

頁面同時使用 Web Speech API 的兩半：語音辨識用來聆聽，語音合成用來回答。 Chrome 和 Edge 兩者兼備，Firefox 則兩者皆無。

頁面需要麥克風。第一次按 Start listening 時，瀏覽器會問 是否允許頁面使用麥克風；請選擇 Allow。

開始前需要甚麼

  • Chrome 或 Edge。Firefox 無法執行此頁。
  • 一個麥克風。多數手提電腦已內建。
  • 揚聲器或耳機，並開啟聲音。回答會從它們播出。
  • 互聯網連線。Chrome 會把錄下的聲音送到它的語音服務，再把文字送回來。
  • 一個文字編輯器。有 Visual Studio Code 就用它；否則先看 如何安裝 Visual Studio Code？

步驟 1：建立檔案

下載 zip 檔案並解壓。 Mac 上連按兩下 zip；Windows 上按右鍵，選 Extract All。你會得到一個名為 Folder-AI-Speech-03-Speak-Reply 的資料夾，內有 index.html。

步驟 2：開啟頁面

選項 1：這部電腦。連按兩下 index.html，它就會在瀏覽器開啟。 無需伺服器。

選項 2：你的免費網站。把這個 HTML 檔案複製到免費 GitHub 網站的資料夾 （見 如何在 username.github.io 建立一個免費網站？），然後上載變更。 如果資料夾已有名為 index.html 的頁面，先把它重新命名，例如改為 speak-reply.html，以免上載時取代你網站的首頁。再在 Chrome 中開啟該頁的 https:// 網址。

選項 3：本網站。開啟 本網站上的同一個頁面，按一下 Start listening。它會立即運行，無需下載任何東西。

檔案不必命名為 index.html。任何名稱都可以，名稱會成為連結的結尾：名為 speak-reply.html 的檔案，網址就是 https://your-username.github.io/speak-reply.html。

名為 index.html 的檔案很特別，它是訪客最先看到的頁面。所以用這個名稱的檔案， 會取代你網站的首頁。

步驟 3：整個檔案

以下是 index.html 的全部內容：

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Answer</title>
</head>
<body>
<h1>Answer</h1>
<button onclick="startListening()">Start listening</button>
<button onclick="stopListening()">Stop</button>
<p>You said: <span id="heard">nothing yet</span></p>
<p>Reply: <span id="reply">nothing yet</span></p>
<script>
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
const recognition = new SpeechRecognition();
recognition.lang = 'en-US';
recognition.onresult = function (event) {
  const heard = event.results[0][0].transcript;
  document.getElementById('heard').textContent = heard;
  const reply = 'I heard you say: ' + heard;
  document.getElementById('reply').textContent = reply;
  speak(reply);
};
function startListening() {
  recognition.start();
}
function stopListening() {
  recognition.stop();
}
function speak(text) {
  speechSynthesis.cancel();
  const utterance = new SpeechSynthesisUtterance(text);
  speechSynthesis.speak(utterance);
}
</script>
</body>
</html>

上半部是普通網頁：一個標題、兩個按鈕，以及兩行文字。一行顯示頁面聽見了甚麼，另一行顯示 它即將說甚麼。每個按鈕都有一個 onclick 屬性，指明按下時要執行的函數。

步驟 4：腳本中的名稱

SpeechRecognition 是瀏覽器的聆聽引擎。Chrome 也以較舊的名稱 webkitSpeechRecognition 提供它，所以第一行會採用瀏覽器擁有的那個名稱。 recognition.lang = 'en-US' 告訴引擎講者所說的語言。

recognition.onresult 指明文字到達時要執行的函數。 event.results[0][0].transcript 是句子本身，以純文字表示。接下來兩行把這句話 放到頁面上，並組成回答 'I heard you say: ' + heard，也就是在句子前面加一句短語。

speak(text) 是說話的那一半。speechSynthesis.cancel() 停止先前的回答， SpeechSynthesisUtterance 準備好要朗讀的新文字， speechSynthesis.speak() 把它交給引擎。最後，start() 開啟麥克風， stop() 關閉它。

步驟 5：試一試

在 Chrome 中開啟頁面。按一下 Start listening，瀏覽器要求麥克風時選擇 Allow，然後說一句英文，例如 Hello, World!。

文字會出現在 You said: 旁邊，電腦接著把回答讀出來。按一下 Stop 可提早關閉麥克風。如果你一時間沒有說話，頁面會自行停止；再按 Start listening 便可繼續說。

限制

  • 必須允許麥克風。如果瀏覽器不為電腦上的檔案提供麥克風，請把頁面上載到 你的免費網站，並在那裡開啟。
  • 回答只是回聲，不是對話。頁面只在你的話前面加一句再重複，並不理解內容， 裡面也沒有 AI 模型。
  • 聆聽的一半需要互聯網。Chrome 把聲音送到它的語音服務。說話的一半通常 離線也可用，因為語音已安裝在電腦上。
  • 一次一句。短暫停頓後，頁面停止聆聽，然後回答一次。
  • 並不完美。背景噪音、濃重口音和不尋常的名字都會變成錯誤的字詞， 回答也會重複同樣的錯誤。
  • 本版本只支援英文。聆聽語言固定為 'en-US'，聲音則是電腦的 預設語音，通常為英文。
