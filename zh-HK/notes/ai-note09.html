如何從網路攝影機取得即時影像？

林邦源 · AI 筆記 · 2026年11月1日 · 閱讀時間約 4 分鐘

English 繁體中文 简体中文

電腦上的鏡頭，是任何需要「觀察真實世界並作出反應」的程式的起點。口紅的例子正展示了 這一點：影片是許多靜止畫格一個接一個送來。在每一格中找出人臉，塗上口紅， 顯示這一格，再繼續下一格。每一格都這樣做，結果就是一張帶著口紅的動態人臉。

下面的程式是基礎：10 行程式碼，開啟你的鏡頭，在視窗中顯示即時影像，直到你按下 q 或 Q。它不含任何 AI，只負責從鏡頭取得畫格並顯示出來—— 刻意如此，好讓鏡頭部分在加入 AI 之前先弄清楚。

你的眼睛看到甚麼，程式看到甚麼

你的眼睛看到流暢的動態影像。程式看到的是一連串獨立的畫格，每一格迅速取代前一格， 快得讓你看不出變化。

程式如何運作

1. 開啟鏡頭

import cv2
cap = cv2.VideoCapture(0)

cv2 是 OpenCV（Open Source Computer Vision，開源電腦視覺）， 本系列用來開啟相片和影片的程式庫。第一行把它載入。

第二行連接鏡頭，並把這個連接保存在 cap（capture，擷取）裡。0 指電腦上的第一個鏡頭，通常是內建鏡頭。在 Mac 上，第一次執行時電腦會要求授權； 在 Windows 上，如果沒有畫面出現，請檢查「設定」中是否允許了鏡頭存取。

2. 每次讀取一格

while True:
    ret, img = cap.read()
    cv2.imshow("Frame", img)

第一行啟動一個不會自行停止的迴圈，因為 True 永遠為真。它下面縮排的 每一行都會一遍又一遍地執行，每格一次。

cap.read() 取出一格。ret（return）表示有沒有成功讀到畫格， img（image）就是畫格本身：一個像素值的網格。這個 img 就是任何鏡頭程式要處理的東西——與之前筆記中的相片檔案完全一樣。

cv2.imshow 把畫格顯示在標題為 "Frame" 的視窗中。每一格新畫面 取代前一格，所以視窗看起來就像即時影像。

3. 按 q 或 Q 時停止

key = cv2.waitKey(1)
if key in (ord('q'), ord('Q')):
    break

cv2.waitKey(1) 等待一毫秒看有沒有按鍵，然後繼續。key 是一個代碼，告訴你按了哪個鍵，沒有按鍵就回傳 -1。這個短暫的等待 也讓視窗有時間畫出畫格——影片能顯示出來，正是因為它。

下一行檢查 q 或 Q。ord() 把字母變成數字—— ord('q') 是 113——這樣字母就能與 key 中的數字比較。 兩個都測試，大寫鎖定（Caps Lock）就沒有影響。

break 離開迴圈，繼續執行最後兩行。執行程式後，Visual Studio Code 的 終端機仍是目前選取的視窗，所以你按的 q 或 Q 會送往 Visual Studio Code，而不是顯示影片的程式。把滑鼠指標移到影片視窗上，按一下選取它， 然後按 q 或 Q 結束程式。

還有一個更快的停止方法：在 Visual Studio Code 終端機中，同時按 Ctrl 和 C 兩個鍵。

4. 關閉鏡頭

cap.release()
cv2.destroyAllWindows()

cap.release() 中斷與鏡頭的連接，其他程式就能再次使用它，鏡頭指示燈 也會熄滅。cv2.destroyAllWindows() 關閉視窗。

完整程式

把上面的部分拼回來。這就是完整的檔案，一共 10 行： 

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

儲存其中一格

許多工作只需要一格畫面，而不是一條影像串流：取一格，然後分析它。你不需要為此 另寫一個程式。在迴圈內，img 已經是一格畫面，所以多加一行就能把它 儲存為檔案： 

cv2.imwrite("camera_frame.jpg", img)

把那行加在 cap.read() 之後，程式就會為每一格寫一個新檔案。如果只想 保留一格，把它加在 break 那行上面，這樣檔案會在你按 q 時儲存：你那一刻在螢幕上看到的，就是你得到的。

一旦畫格成為檔案，之前筆記中的一切就都能套用——包括 〈AI 如何找出你臉上的關鍵點？〉中的 face_recognition.load_image_file。

在自己的電腦上執行

下載 zip 檔案並解壓到 一個資料夾。這個 zip 包含本系列的六個程式；本文使用 face05.py。 這個程式不需要在資料夾裡放相片。在 Visual Studio Code 中開啟資料夾，然後在終端機 輸入以下三行： 

uv python pin 3.12.10
uv sync
uv run face05.py

第一行記錄這個資料夾使用的 Python 版本，第二行安裝 pyproject.toml 列出的所有套件（包括 OpenCV）。第三行開啟鏡頭視窗。在該視窗中按 q 即可關閉。

如果你還沒有設定 uv，請先閱讀 〈如何安裝 Visual Studio Code？〉， 然後是 Windows 或 Mac 的 uv 筆記。
