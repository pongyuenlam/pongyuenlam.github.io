如何用 AI 為你塗口紅？

林邦源 · AI 筆記 · 2026年11月1日 · 閱讀時間約 6 分鐘

English 繁體中文 简体中文

本文使用兩個短程式。第一個把嘴唇塗上半透明的深紅色，並沿邊緣加一條更深的線， 就像唇線筆。第二個把同樣的嘴唇分別塗上 10 種具名紅色，每種顏色儲存一張圖。

兩者都從你在 〈AI 如何找出你臉上的關鍵點？〉見過的關鍵點開始。 嘴唇是唯一在外緣和內緣都有關鍵點的最大部位，所以最容易填色而不蓋過牙齒。

前後對比

第一部分：一種紅色，加上輪廓線

第一個程式有 14 行。開頭與之前的筆記完全相同：讀取相片、找出關鍵點， 然後建立一個能與底下像素混合顏色的畫圖工具。

1. 選擇紅色

color_lip = (150,0,0,125)

紅色分量 150，綠色和藍色為零，就是深紅色。第四個數字 125 約為 255 的一半， 所以顏色是半透明的，你原本的嘴唇仍然能透出來。

2. 填滿上唇和下唇

# Fill the lip with color_lip
d.polygon(face_landmarks['top_lip'], fill=color_lip)
d.polygon(face_landmarks['bottom_lip'], fill=color_lip)

每片嘴唇有 12 個點。它們沿嘴唇外緣走一圈，再沿內緣（嘴唇與口腔開口相接之處） 折返。polygon 按順序連接這些點並填滿內部，所以填出來的形狀是嘴唇本身， 而不是口腔。這就是牙齒保持潔白的原因。

3. 沿邊緣畫一條更深的線

d.line(face_landmarks['top_lip'], fill=color_lip, width=8)
d.line(face_landmarks['bottom_lip'], fill=color_lip, width=8)

同樣的 12 個嘴唇關鍵點被第二次使用，這次用同樣顏色、8 像素粗的線沿嘴唇邊界畫一圈。 所以邊界被塗了兩次，而嘴唇內部只塗了一次。半透明顏色疊兩層比一層更深， 因此嘴唇邊界比內部顏色更深。

第二部分：10 種紅色

第二個程式有 33 行，沿用了同樣的兩個填色指令。新穎之處在於它如何選擇顏色， 以及如何儲存結果。

1. 把 10 種顏色集中在一處

# 10 colors of red: (red, green, blue, see-through)
# The 4th number is 0 (invisible) to 255 (solid)
colors = {
    'cherry':    (190, 20, 40, 120),
    'scarlet':   (230, 30, 20, 110),
    'crimson':   (170, 10, 50, 120),
    'ruby':      (155, 15, 70, 120),
    'brick':     (165, 50, 35, 110),
    'coral':     (240, 90, 80, 110),
    'rose':      (210, 70, 100, 110),
    'wine':      (115, 15, 40, 130),
    'burgundy':  (100, 10, 30, 140),
    'blood':     (140, 0, 0, 130),
}

花括號裡是一個字典：十對「名字配四個數字」。每對中紅色都是首三個數字裡最大的， 所以十種都是紅色系。綠色和藍色越高，色調越淺——coral 是這裡最淺的。全部數字都低， 色調就深——burgundy 是最深的。第四個數字接近一半，所以嘴唇仍然能透出來。

2. 每次塗一種顏色，從全新副本開始

# Make the 10 colors one by one
for name, color_lip in colors.items():
    # Start from a fresh copy of the photo each time, so the colors do not pile up
    lip_image = pil_image.copy()
    d = ImageDraw.Draw(lip_image, 'RGBA')

迴圈執行十次。每次 name 是一個顏色名字，color_lip 是它的四個數字。

副本很關鍵。如果程式直接在原圖上塗，第二種顏色會疊在第一種上面，第三種疊在第二種上面， 到第十種時嘴唇就會變成十種顏色混在一起的污濁色。在副本上畫，每種顏色都從乾淨的相片開始。

3. 用顏色名字為每個檔案命名

    # Save each color as an image file named after the color, e.g. lip_cherry.jpg
    lip_image.save("lip_" + name + ".jpg")
    print("Saved", "lip_" + name + ".jpg")

三段文字用 + 連起來："lip_"、顏色名字和 ".jpg"。 以 cherry 為例，就得到 lip_cherry.jpg。程式還會逐一印出每個名字， 讓你看著十個檔案依次寫出來。

十種色調

完整程式

第一個程式，完整版本，14 行： 

from PIL import Image, ImageDraw
import face_recognition
image = face_recognition.load_image_file("my_photo.jpg")
face_landmarks_list = face_recognition.face_landmarks(image)
pil_image = Image.fromarray(image)
for face_landmarks in face_landmarks_list:
    d = ImageDraw.Draw(pil_image, 'RGBA')
    color_lip = (150,0,0,125)
    # Fill the lip with color_lip
    d.polygon(face_landmarks['top_lip'], fill=color_lip)
    d.polygon(face_landmarks['bottom_lip'], fill=color_lip)
    d.line(face_landmarks['top_lip'], fill=color_lip, width=8)
    d.line(face_landmarks['bottom_lip'], fill=color_lip, width=8)
    pil_image.save("my_photo_lip.jpg")

第二個程式，完整版本，33 行： 

from PIL import Image, ImageDraw
import face_recognition

# 10 colors of red: (red, green, blue, see-through)
# The 4th number is 0 (invisible) to 255 (solid)
colors = {
    'cherry':    (190, 20, 40, 120),
    'scarlet':   (230, 30, 20, 110),
    'crimson':   (170, 10, 50, 120),
    'ruby':      (155, 15, 70, 120),
    'brick':     (165, 50, 35, 110),
    'coral':     (240, 90, 80, 110),
    'rose':      (210, 70, 100, 110),
    'wine':      (115, 15, 40, 130),
    'burgundy':  (100, 10, 30, 140),
    'blood':     (140, 0, 0, 130),
}

image = face_recognition.load_image_file("my_photo.jpg")
face_landmarks_list = face_recognition.face_landmarks(image)
pil_image = Image.fromarray(image)
# Make the 10 colors one by one
for name, color_lip in colors.items():
    # Start from a fresh copy of the photo each time, so the colors do not pile up
    lip_image = pil_image.copy()
    d = ImageDraw.Draw(lip_image, 'RGBA')
    for face_landmarks in face_landmarks_list:
        # Fill the lip with color_lip
        d.polygon(face_landmarks['top_lip'], fill=color_lip)
        d.polygon(face_landmarks['bottom_lip'], fill=color_lip)
    # Save each color as an image file named after the color, e.g. lip_cherry.jpg
    lip_image.save("lip_" + name + ".jpg")
    print("Saved", "lip_" + name + ".jpg")

在自己的電腦上執行

下載 zip 檔案並解壓到 一個資料夾。這個 zip 包含本系列的六個程式；本文使用 face03_lip.py 和 face04_lip.py。把你自己的相片放進該資料夾， 命名為 my_photo.jpg。在 Visual Studio Code 中開啟資料夾，然後在終端機 輸入以下四行： 

uv python pin 3.12.10
uv sync
uv run face03_lip.py
uv run face04_lip.py

第一行記錄這個資料夾使用的 Python 版本，第二行安裝 pyproject.toml 列出的所有套件。第三行儲存 my_photo_lip.jpg；第四行儲存從 lip_cherry.jpg 到 lip_blood.jpg 的十個檔案。

如果你還沒有設定 uv，請先閱讀 〈如何安裝 Visual Studio Code？〉， 然後是 Windows 或 Mac 的 uv 筆記。

技術備註：face-recognition 套件依賴另一個名為 dlib 的套件。 zip 中的專案檔案已指向預先編譯好的 dlib 版本，所以 uv sync 會直接安裝可用版本，你不需要安裝編譯器。

這有甚麼用

這就是「先試後買」工具的最簡形態。AI 回答「嘴唇在哪裡？」，而改動一行——無論是 color_lip 裡的數字，還是 colors 裡的一個名字——就能得到 不同的色調。加上一個名字和四個數字，你就有第十一種色調，儲存到它自己的檔案。

有兩個限制值得留意。顏色能改，形狀不能：真正的口紅還能加寬或銳化唇線。而輪廓線的技巧 是靠同一顏色畫兩次來讓邊緣變深，所以不對程式稍作改動，邊緣就無法使用與填色不同的顏色。
