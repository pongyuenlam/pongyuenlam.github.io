如何看出照片裡的人是誰（人臉辨識，版本 3）？

林邦源博士 · AI 筆記 · 2026 年 11 月 13 日 · 約 5 分鐘閱讀

版本 2 為它認識的每個人存了一組 128 個數字。版本 3 終於用上它們。它打開一張新照片， 量度裡面的每一張臉，把這些測量值跟存下來的比較，然後印出對得上的那個人的名字。 這是第一個能回答問題的版本，而不只是為問題做準備。

整個比較建立在版本 2 的一個事實上：同一個人的兩張照片會產生兩個靠得很近的清單， 兩個不同的人會產生離得遠一點的清單。下面所有內容，都是在量度這種接近程度， 並決定多近才算夠近。

程式怎麼運作

1. 多一個函式庫

import face_recognition
import cv2
import os
import glob
import numpy as np

numpy 是 NumPy，Numerical Python 的簡稱。它一次處理整份 數字清單，而這裡要算的正是一整串距離。as np 只是一個綽號，所以程式碼可以寫 np.round，不用寫 numpy.round。

前四行做的是版本 2 的同一件事：找出資料夾裡的照片，把每一張已知的臉變成數字。唯一的 差別是，這個版本不印出執行中的數目，而是直接去建那兩個清單。

2. 一張要檢查的新照片

img = cv2.imread("image-source.JPG")
rgb_img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)

image-source.JPG 是你要認的那張照片：一張班級照、一張合照、別人傳給你的圖。 它放在程式旁邊，不在 images 裡面，因為它還不是程式認識的人。第二行用跟 版本 2 一樣的方式修正顏色順序。

一個實際問題：程式碼裡的檔名必須跟真實的檔案完全一致，包括大小寫。Mac 的截圖常常是 大寫 .JPG。Windows 和預設設定的 Mac 不管這個差別，Linux 管，所以值得檢查一下你打的名字。

3. 量度之前先找出人臉

face_locations = face_recognition.face_locations(rgb_img)
face_encodings = face_recognition.face_encodings(rgb_img, face_locations)

face_locations 是一個清單，找到幾張臉就有幾項，每一項是框住那張臉的一個框。 一張合照裡可能有五個。

第二行把這些框交回給 face_encodings。函式庫自己也能再找一遍臉，但告訴它臉在哪裡， 省掉這份工作，也保證測量值和框指的是同一批臉。

注意這次沒有 [0]。版本 2 只留第一張臉，因為每張已知的照片裡只有一個人。 這裡照片裡每一張臉都要量，因為問題是誰在照片裡，而不是照片裡第一個人是誰。

4. 一張臉一張臉地比較

for face_encoding in face_encodings:
    matches = face_recognition.compare_faces(known_face_encodings, face_encoding)

compare_faces 拿新的一張臉和整份已知臉的清單，為每個已知的人回傳一個 True 或 False，順序跟 known_face_names 一樣。 已知三個人時，結果看起來像 [True, False, False]：這張臉對得上第一個人， 對不上另外兩個。

那個 True 背後有一個門檻。函式庫用距離比較兩張臉，距離小於等於 0.6 就算同一個人。 這個系列的第 9 個版本會改這個數字；現在 0.6 是預設值。

5. 每張已知的臉有多遠？

    face_distances = face_recognition.face_distance(known_face_encodings, face_encoding)
    print(np.round(face_distances, 2))
    best_match_index = np.argmin(face_distances)

face_distance 回傳每個已知的人的實際數字，而不是是或否：類似 [0.28, 0.63, 0.64]。越小表示越像。同一個人拍兩次，通常低於 0.4； 兩個不同的人通常高於 0.6。

np.round(..., 2) 只是把顯示整理到兩位小數。然後 np.argmin 找出最小數字的位置——也就是最接近的那張已知的臉。位置從 0 開始，所以 0 表示 known_face_names 裡的第一個名字。

6. 兩個都要：最近，而且夠近

    name = "Unknown"
    if matches[best_match_index]:
        name = known_face_names[best_match_index]
        face_names.append(name)

最近不等於對得上。一張陌生人的照片裡，已知清單裡總會有一個人是最近的，距離也許是 0.7。 matches[best_match_index] 這一行問的是：這個最近的人有沒有通過 0.6 的測試。 只有通過了，名字才被接受。

append 在 if 裡面，所以沒有對上的臉就直接不進清單。這就是為什麼 開頭設成 "Unknown" 的那個變數，永遠不出現在輸出裡：陌生人什麼都不加， 而不是加上 Unknown 這個詞。

完整程式

把上面的片段拼回去，為了篇幅把版本 2 裡印出執行數目的那一行去掉： 

import face_recognition
import cv2
import os
import glob
import numpy as np

images_folder = "images"
images_path = glob.glob(os.path.join(images_folder, "*.*"))

known_face_encodings = []
known_face_names = []
for img_path in images_path:
    img = cv2.imread(img_path)
    rgb_img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    basename = os.path.basename(img_path)
    (filename, ext) = os.path.splitext(basename)
    img_encoding = face_recognition.face_encodings(rgb_img)[0]
    known_face_encodings.append(img_encoding)
    known_face_names.append(filename)

img = cv2.imread("image-source.JPG")
rgb_img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
face_locations = face_recognition.face_locations(rgb_img)
face_encodings = face_recognition.face_encodings(rgb_img, face_locations)

face_names = []
for face_encoding in face_encodings:
    matches = face_recognition.compare_faces(known_face_encodings, face_encoding)
    name = "Unknown"
    face_distances = face_recognition.face_distance(known_face_encodings, face_encoding)
    best_match_index = np.argmin(face_distances)
    if matches[best_match_index]:
        name = known_face_names[best_match_index]
        face_names.append(name)

print("The matched name's image file is", face_names)

輸出是什麼意思

如果 image-source.JPG 是 Howard 的照片，最後一行會印出： 

The matched name's image file is ['Howard']

如果你把兩行 print 加回去，執行中間會顯示推算過程： 

[0.28 0.63 0.64]
0

Howard 最近，距離 0.28，遠在 0.6 的範圍之內，所以留下的就是他的名字。一個陌生人會給出 類似 [0.71 0.74 0.69] 的距離，最近的是 0.69，if 不成立， 印出來的清單就是空的：[]。

空清單是正確答案，不是 bug。它的意思是照片裡沒有一個是程式認識的人。

在自己的電腦上執行

用跟版本 1 一樣的下載： 下載壓縮檔，解壓， 用 Visual Studio Code 打開這個資料夾。這一篇用的是 face03.py。 第一次在這個資料夾裡執行時，三行都跑： 

uv python pin 3.12.10
uv sync
uv run face03.py

這三行只需要做一次。下次想再執行這個程式，只需輸入 uv run face03.py。

把想檢查的照片放在 face03.py 旁邊，命名為 image-source.JPG。 壓縮檔裡已經有一張，所以解壓後程式馬上就能跑。換成你自己的照片，才能測一個真實的問題。 一張清晰、正面對著鏡頭的臉給出最好的答案；一張轉過去或者光線很差的臉，即使那個人 在資料夾裡，也可能回傳沒有對上。

下一步

版本 1 到 3 都只處理已經存在的檔案。版本 4 會打開鏡頭，顯示即時影片， 那是讓辨識可以在你移動時發生的必要一步。
