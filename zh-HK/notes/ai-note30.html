如何在 Google Search Console 驗證你的網站？

林邦源博士 · AI 筆記 · 2026 年 11 月 10 日 · 約 5 分鐘閱讀

Google Search Console 是 Google 免費提供的工具，讓你看到網站在 Google 搜尋中的表現：Google 找到了哪些頁面、哪些搜尋字詞帶來訪客、有沒有頁面出了問題。 不過，在 Google 讓你看到這些資料之前，你必須先驗證網站 — 也就是向 Google 證明這個網站真的是你的。只有網站的擁有者，才可以看到它的私人搜尋數據。

這篇筆記會逐步說明 HTML 檔案上載方法，本站用的也正是這個方法。只要你能把 一個檔案放到網站的最上層資料夾，這個方法就適用 — 包括像 如何在 username.github.io 建立一個免費網站？ 那樣的免費 GitHub Pages 網站。

開始之前，你需要準備甚麼

  • 一個 Google 帳戶（例如你用來收 Gmail 的同一個）。
  • 一個已經上線的網站，好讓 Google 可以造訪它。
  • 能把一個檔案放到該網站最上層資料夾的能力。在 GitHub Pages 上， 你的網站存放在一個名為 username.github.io 的儲存庫 （repository，即 GitHub 對專案資料夾的稱呼）— 例如本站就存放在 pongyuenlam.github.io 這個儲存庫。所謂「最上層資料夾」，就是你在 GitHub 打開該儲存庫時看到的第一頁：也就是 index.html 所在的位置。驗證檔案要放在 index.html 旁邊，而不是任何子資料夾之內。

一句話說清楚

Google 給你一個名字又長又獨特的細小檔案；你把檔案放到網站的最上層資料夾；Google 造訪那個網址並找到檔案。這個檔案不是秘密 — 一旦放上網，任何人 都可以讀取 — 但只有控制這個網站的人，才能把它放到那裡，所以 Google 找到它， 就證明網站是你的。

第 1 步：在 Search Console 新增你的網站

前往 search.google.com/search-console 並登入。按 Add property（新增資源），選擇 URL prefix （網址前置字元）選項。輸入網站的完整網址，例如： 

https://username.github.io

把 username 換成你自己的 GitHub 用戶名稱。

第 2 步：選擇 HTML 檔案方法

Search Console 提供幾種驗證方式。選擇 HTML file（HTML 檔案）。Google 會給你一個名字又長又隨機的檔案，例如： 

googlexx...html

按按鈕把它下載。不要更改檔案名稱，也不要改動裡面的內容。如果你打開它， 會見到裡面只有一行文字，類似： 

google-site-verification: googlexx...html

第 3 步：把檔案放到網站上

檔案必須放在網站的最上層資料夾，這樣它的網址才會是： 

https://username.github.io/googlexx...html

要在 GitHub 找到那個最上層資料夾，先打開 github.com/username。這是你的 個人檔案頁 — 它只會列出你的儲存庫，不會顯示任何檔案， 所以你在那裡找不到驗證檔案。按一下 username.github.io 儲存庫。你現在看到的 第一頁 — 那個包含 index.html 的檔案清單 — 就是最上層資料夾。

在該頁用 Add file → Upload files 把驗證檔案放到 index.html 旁邊，然後提交變更。之後照慣例等一至兩分鐘，讓網站更新。

第 4 步：檢查檔案是否可以取用

開一個新的瀏覽器分頁，造訪 https://username.github.io/googlexx...html （換上你自己的用戶名稱和檔案名稱）。如果你見到第 2 步那一行文字，檔案就放對了位置。 如果見到「404 not found」錯誤，等一分鐘再重新載入，或者檢查檔案是否真的在最上層資料夾， 而不是在子資料夾裡。

第 5 步：按「驗證」

回到 Search Console，按 Verify（驗證）。Google 會造訪該網址、找到檔案， 確認你是擁有者。驗證即時完成。

之後不要把檔案刪掉

Google 會不時重新檢查該檔案。如果你刪除它或更改它的名稱，Google 可能判斷你不再是擁有者， 你查看 Search Console 資料的權限便會中止。這個檔案非常細小 — 讓它留在原位就好。 例如本站至今仍把驗證檔案（googlexx...html）留在最上層資料夾，正是這個原因。

順帶一提

  • 驗證是免費的，而且只需成功一次。
  • 單靠 Google Analytics 標籤並不能驗證你的網站。
  • 驗證之後，在 Search Console 提交你的 sitemap.xml，請 Google 檢視你的頁面。
