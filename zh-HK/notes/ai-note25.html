如何在 username.github.io 建立一個免費網站？

林邦源博士 · AI 筆記 · 2026 年 11 月 6 日 · 約 5 分鐘閱讀

你可以用 GitHub Pages 免費把一個網站放上互聯網。 GitHub 是一個讓人存放和分享程式碼的網站；GitHub Pages 是一項免費服務， 可以把你其中一個程式碼資料夾變成一個真正的網站。網站的地址是 username.github.io，其中 username 是你註冊 GitHub 時選擇的名稱。不需要信用卡，也沒有月費。

這篇筆記會帶你走完整個過程，由開立 GitHub 帳戶，到看見自己的第一個網頁上線， 全程只需要用瀏覽器打開 GitHub 網站 — 無需安裝任何額外軟件。

在 Google Drive 觀看 （無需帳戶）。

開始之前你需要甚麼

  • 一個你可以即時查看的 電郵地址（GitHub 會發送驗證碼給你）。
  • 一個你喜歡的 用戶名稱（username） — 它會成為你網址的一部分， 所以要小心選擇。GitHub 的用戶名稱只可以包含英文字母、數字和連字號（-）； 不可以有底線或空格。

第 1 步：註冊 GitHub 帳戶

前往 github.com ，然後按 Sign up。GitHub 會要求你輸入：

  • 你的 電郵地址。
  • 一個 密碼。
  • 一個 用戶名稱。這是最重要的選擇，因為它會成為你網站的地址。 如果你選擇 pongyuenlam，你的網站就會是 pongyuenlam.github.io。

按 Create account。

第 2 步：驗證你的電郵

GitHub 會發送一個簡短的數字驗證碼到你的電郵地址。在 GitHub 頁面輸入這個驗證碼， 證明你擁有這個電郵。之後你就可以登入新帳戶了。

第 3 步：建立名為 username.github.io 的儲存庫

儲存庫（repository）是 GitHub 對專案資料夾的稱呼。 要建立個人網站，儲存庫的名稱有一個非常嚴格的規定：它必須完全等於你的 GitHub 用戶名稱再加上 .github.io。

在 GitHub 上，按你的頭像，然後選擇 New repository。 在 Repository name 欄位輸入： 

username.github.io

把 username 換成你真正的 GitHub 用戶名稱。例如，如果你的用戶名稱是 pongyuenlam，儲存庫名稱就必須是 pongyuenlam.github.io。 如果名稱和你的用戶名稱不完全一樣，免費網址就不會生效。

其他設定保持不變，然後按 Create repository。

第 4 步：建立 index.html 檔案

網站是由檔案組成的。訪客看到的第一頁永遠叫 index.html。 在你的新儲存庫頁面，按 creating a new file。

在要求輸入檔案名稱的方框中，輸入： 

index.html

然後，在下方較大的編輯區域，輸入一個簡單的網頁。以下是一個你可以複製和修改的小例子： 

<!DOCTYPE html>
<html>
<head>
  <title>My Website</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>This is my first website on GitHub Pages.</p>
</body>
</html>

第 5 步：提交（儲存）檔案

在頁面底部，按 Commit changes。GitHub 會要求你確認提交； 再按一次 Commit changes。Commit（提交）是 GitHub 對儲存檔案某個版本的稱呼。

第 6 步：等候並查看你的網站

GitHub 需要一點時間來發佈你的網頁。開啟一個新的瀏覽器分頁，前往： 

https://username.github.io

同樣，把 username 換成你真正的用戶名稱。通常需要大約 一至兩分鐘頁面才會出現。如果一開始看到錯誤，請再等一會，然後重新整理頁面。

日後如何編輯你的網站

要修改網頁，請回到你的儲存庫，按 index.html 檔案， 然後按鉛筆圖示（Edit this file）。作出修改，捲動到頁面底部， 按兩次 Commit changes。等候約一至兩分鐘，重新整理 username.github.io，更新後的網頁就會出現。要重新整理，請在 Mac 上按 Cmd + R，或在 Windows 上按 Ctrl + R， 又或者按瀏覽器網址列上的圓形重新整理圖示。

之後你可以做甚麼

  • 新增更多頁面。在同一個儲存庫建立更多 .html 檔案， 例如 about.html，並在 index.html 中加入連結指向它們。
  • 加入圖片。把圖片檔案上傳到儲存庫，然後用 <img> 標籤在網頁上顯示。
  • 使用現成的設計。搜尋「GitHub Pages themes」， 無需自己撰寫所有樣式，也能讓網站看起來更精美。

限制

  • 儲存庫名稱必須是 username.github.io。 如果不一樣，GitHub 就不會在該地址發佈網站。
  • 每次提交後，網站需要一至兩分鐘才會更新。 如果看不到你的改動，請等候並重新整理。
  • GitHub Pages 是為靜態網站而設 — 由 HTML、CSS 和圖片組成的頁面。 它本身不能執行資料庫或伺服器端程式。如果你已經有一個使用資料庫或伺服器端程式的網站， 你可以簡單地在 username.github.io 的某個頁面加入連結指向它。
