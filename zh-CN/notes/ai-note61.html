人脸比对应有多严格（人脸识别，版本 9）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 6 分钟阅读

版本 8 处理速度。最后一个版本处理一个更安静的问题：版本 8 判断两张脸是不是同一个人， 用的数字不是任何人选的。库的默认值是 0.6，那是一个合理的猜测，不是一个决定。 版本 9 把它变成一个决定：给这个数字起名，并把它搬到文件顶部的一个地方。

从版本 8 改了两行。就这样。改动小，是因为这个旋钮一直都在；它只是藏在库的默认值里。

一个数字，两种错误

匹配一张脸会产生一个距离：这张脸离一个已知的脸有多远，用 128 个数字来量。零就是完全相同。 容差是那条界线——任何高于它的距离都被当成另一个人。

转动这个旋钮，两种错误会朝相反方向移动，没有任何设置能让两者同时消失：

  • 太松 — 陌生人被安上最像的那个人的名字。屏幕自信地显示错误的人。
  • 太严 — 对的人被拒绝，因为同一张脸从来不会两次拍得一模一样。 屏幕对一个它认识的人显示 Unknown。

哪种错误更要紧，是关于用途的问题，不是关于代码的问题。一扇绝对不能让错的人打开的门， 要严的设置。一个应该找出朋友每一张照片的照片库，松一点也无妨。

1. 把容差设一次

images_folder = "images"
my_tolerance = 0.5  # 库默认值是 0.6

这个变量和其他设置放在一起，在文件夹搜索上面，所以容易找到，也容易改。# 后面的文字是注释：Python 忽略它，它留在文件里，告诉下一个读的人：没有这一行时，数字会是多少。 把默认值这样摆出来，比记住它便宜。

2. 把这个数字传给 compare_faces

        matches = face_recognition.compare_faces(known_face_encodings, face_encoding, tolerance=my_tolerance)

那一行里其他东西都是版本 7 的工作。加的是 tolerance=my_tolerance： 等号左边的名字是 compare_faces 内部的设置，必须一字不差地写成这样； 等号右边是上面设的变量。

注意下一行的 face_distance 没有动。它没有容差，因为它只报距离； 多远的距离可以接受，这个决定属于 compare_faces。所以两行是一致的： 距离量一次，同一个界线套在它们上面。

距离大概是什么样子

编码向量的长度大约是 1，所以实际上距离很少超过 1.2。典型的值：

  • 0 — 两张完全相同的照片。
  • 大约 0.3–0.5 — 同一个人的两张照片，拍摄时间不同。
  • 大约 0.7 以上 — 两个不同的人。

所以有用的设置大致落在 0.4 到 0.7 之间：

  • 0.4–0.5 — 严格。错误的姓名更少，Unknown 更多。
  • 0.6 — 库的默认值，也是库自己的文档推荐的起点。
  • 0.7 以上 — 宽松。陌生人开始从文件夹里借名字。
  • 1.0 以上 — 几乎什么都匹配，等于完全不检查。

库的建议和这张表一致：如果两个不同的人被报成同一个人，就把数字调低。

容差和缩放会互相拉扯

版本 8 在编码之前把画面缩到一半，这要付出细节，也把距离推高一点。版本 9 又把界线收紧。 两件都做，效果会叠加：一张在 0.6 默认值下以 0.57 通过的脸，现在可能坐在 0.62，在 0.5 下面失败。

所以这两个设置应该一起选。如果你收紧了容差，对的人却一直显示 Unknown， 先把 scale_ratio 调高靠近 1.0，再考虑放松容差。 靠保留更多像素来恢复准确率，通常比靠接受更弱的证据来恢复更好。

完整程序

版本 1 的下载里已经有这个文件。和版本 8 相比，多了一行，还有一行多了一个设置； 后面每一行的行号都往后挪了一位。 

import face_recognition
import cv2
import os
import glob
import numpy as np
images_folder = "images"
my_tolerance = 0.5 # 库默认值 = 0.6
images_path = glob.glob(os.path.join(images_folder, "*.*"))

known_face_encodings=[]
known_face_names=[]
for img_path in images_path:
    img = cv2.imread(img_path)
    rgb_img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    basename = os.path.basename(img_path)
    (filename, ext) = os.path.splitext(basename)
    img_encoding = face_recognition.face_encodings(rgb_img)[0]
    known_face_encodings.append(img_encoding)
    known_face_names.append(filename)

cap = cv2.VideoCapture(0)
scale_ratio = 0.5
multiple = int(1 / scale_ratio)
ret, img = cap.read()
width=int(img.shape[1]*scale_ratio)
height=int(img.shape[0]*scale_ratio)
dim=(width,height)

while True:
    ret, img = cap.read()
    resized=cv2.resize(img,dim,interpolation=cv2.INTER_NEAREST)
    rgb_img = cv2.cvtColor(resized,cv2.COLOR_BGR2RGB)
    face_locations = face_recognition.face_locations(rgb_img)
    face_encodings = face_recognition.face_encodings(rgb_img, face_locations)

    face_names = []
    for face_encoding in face_encodings:
        matches = face_recognition.compare_faces(known_face_encodings, face_encoding, tolerance=my_tolerance)
        name = "Unknown"
        face_distances = face_recognition.face_distance(known_face_encodings, face_encoding)
        best_match_index = np.argmin(face_distances)
        if matches[best_match_index]:
            name = known_face_names[best_match_index]
        face_names.append(name)

    for face_loc, name in zip(face_locations, face_names):
        y1, x2, y2, x1 = face_loc[0], face_loc[1], face_loc[2], face_loc[3]
        y1=y1*multiple
        x2=x2*multiple
        y2=y2*multiple
        x1=x1*multiple
        cv2.putText(img, name, (x1, y1 - 10), cv2.FONT_HERSHEY_DUPLEX, 1, (0, 200, 0), 2)
        cv2.rectangle(img, (x1, y1), (x2, y2), (0, 200, 0), 4)

    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break

cap.release()
cv2.destroyAllWindows()

先加上你自己的照片

和之前一样，只有当 images 文件夹里有那个名字的文件时，脸才会被叫出名字， 例如 Peter.jpg。没有它，不管容差是多少，每张脸都是 Unknown。

在自己的电脑上运行

用和版本 1 相同的下载： 下载 zip 文件，解压， 在 Visual Studio Code 里打开文件夹。这篇笔记用的是 face09.py。 在这个文件夹里第一次运行时，三行都跑： 

uv python pin 3.12.10
uv sync
uv run face09.py

这三行只需要一次。下次想再运行程序，只打 uv run face09.py。

整个系列一眼看完

  • 版本 1 — 显示文件夹里的每一张照片。
  • 版本 2 — 把每张照片变成 128 个数字，把文件名留作标签。
  • 版本 3 — 给一张照片里的人脸命名。
  • 版本 4 — 在窗口里显示摄像头。
  • 版本 5 — 显示之前先改动一帧。
  • 版本 6 — 在帧上画一个框和一个标签。
  • 版本 7 — 实时识别并命名人脸。
  • 版本 8 — 只搜索四分之一的像素，换取速度。
  • 版本 9 — 选择匹配要多严格。

九个小程序，每一个都是能用一句话说清楚的一步。拼在一起，它们是一台能叫出面前是谁的摄像头； 而同一个模式——列一串数字、比对、决定、把决定画出来——也躺在远大于它们的系统底下。
