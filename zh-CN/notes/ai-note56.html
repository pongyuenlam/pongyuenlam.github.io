如何显示摄像头的实时画面（人脸识别，版本 4）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 4 分钟阅读

版本 1 到 3 处理的都是已经存在硬盘上的照片。要认出坐在电脑前的那个人，程序需要有 源源不断的新照片，摄像头就是这个来源：它每秒送出很多帧静止画面。版本 4 建立这个来源。 它打开摄像头并显示视频，别的什么都不做。不找人脸，不打印名字。

这看起来像退了一步，但它把两个问题分开了。如果版本 7 识别失败，这个程序能告诉你 摄像头那一部分究竟有没有在工作。如果你读过 如何从摄像头取得实时视频？，这篇笔记的大部分内容你会觉得熟悉； 这里把它放回系列里，因为后面每一个版本都往这个循环里加自己的工序。

摄像头送来的是一帧帧画面，不是一段视频

你的眼睛看到的是流畅的动作。程序收到的是一张张独立的静止画面，每一张都在足够短的时间里 替换掉上一张，所以你看不出变化。这很有用：帧和照片文件是同一种对象，所以你在照片上 量度人脸学到的一切，原样适用于帧。

程序怎么运作

1. 打开摄像头

import cv2
cap = cv2.VideoCapture(0)

cv2.VideoCapture 连接一台摄像头；cap 是 capture（捕获）的缩写， 保存这个连接。这里的 0 表示第一台摄像头，通常是内置摄像头；1 会是第二台，例如 USB 摄像头。

在 Mac 上，第一次运行时系统会请求权限，你不允许它就什么也不显示。如果窗口一直黑着， 到"系统设置"里检查终端或编辑器有没有摄像头权限，并确认没有其他程序正在使用摄像头。

2. 不停地重复

while True:
    ret, img = cap.read()
    cv2.imshow("Frame", img)

while True 开始一个自己永远不会停的循环，因为 True 永远为真。它下面缩进的所有内容每帧执行一次，只要程序还在运行就一直执行。

cap.read() 取一帧，返回两样东西。ret 是 return value（返回值） 的缩写，说明这次读取有没有成功。img 是 image（图像）的缩写，就是这一帧： 一个由像素值组成的格子，顺序是 OpenCV 使用的蓝-绿-红。 cv2.imshow 把这一帧放进标题为 "Frame" 的窗口，循环下一轮再把它 替换掉。每秒显示的帧数足够多，窗口看起来就像视频。

3. 按下 q 就停

    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break

cv2.waitKey(1) 等待按键一毫秒。它把按下的键作为数字返回，没有按键就返回 -1。这一毫秒也是 OpenCV 用来画窗口的时间；不调用 waitKey， 窗口会卡住或者空白。

ord() 把字母变成它的数字，ord('q') 是 113，这样字母就能和 waitKey 返回的数字比较。同时检查 q 和 Q，开不开 Caps Lock 都一样。break 离开循环。

只有视频窗口是活动窗口时，按键才会送到程序。运行之后，编辑器的终端通常还拿着焦点， 所以先在视频窗口上点一下，再按 q。忘了的话，在终端里按 Ctrl 和 C 也能停掉程序。

4. 放开摄像头

cap.release()
cv2.destroyAllWindows()

这两行没有缩进，所以循环结束后执行一次。cap.release() 断开与摄像头的连接， 关掉它的指示灯，让其他程序可以使用。cv2.destroyAllWindows() 关掉窗口。

完整程序

把上面的片段拼回去。这是完整的文件，一共 10 行： 

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

为什么是一毫秒

waitKey(0) 会一直等到有按键才返回，画面永远不会更新。 waitKey(30) 大约每秒更新 33 次，看起来流畅，但会带来延迟。一毫秒让窗口 保持响应，并让循环以摄像头允许的最快速度运行。

在自己的电脑上运行

用和版本 1 相同的下载： 下载压缩包，解压， 然后用 Visual Studio Code 打开这个文件夹。这一篇用的是 face04.py。 第一次在这个文件夹里，运行全部三行： 

uv python pin 3.12.10
uv sync
uv run face04.py

这三行只需要做一次。下次想再运行这个程序，只需输入 uv run face04.py。

会打开一个窗口，显示你的摄像头画面。在它上面点一下，然后按 q 关掉。 摄像头指示灯应该在同一时刻熄灭。

下一步

下两个版本都留在这个循环里。版本 5 把每一帧变成灰色，版本 6 在帧上画一个框和标签， 这样版本 7 真正做识别的时候，已经有地方可以放结果。
