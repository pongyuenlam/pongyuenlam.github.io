如何用 AI 改变你的眉毛？

林邦源 · AI 笔记 · 2026年11月1日 · 阅读时间约 4 分钟

English 繁體中文 简体中文

在本文中，我们再次使用 face_recognition 库。它会找出勾勒出每条眉毛的五个点，程序然后把该区域填上半透明的深棕色。 整个程序只有 12 行。

如果你还未读过 〈AI 如何找出你脸上的关键点？〉，请先从那里开始。 那篇文章讲解了库如何找出关键点；本文则利用同一批关键点，在上面涂上颜色。

前后对比

程序如何运行

前五行与上一篇相同：读取照片、找出关键点，然后把照片变成程序可以在上面画图的东西。 之后只有三个新概念。

1. 让画图变成半透明

for face_landmarks in face_landmarks_list:
    d = ImageDraw.Draw(pil_image, 'RGBA')

循环每次取一张脸，下面缩进的所有代码都为该张脸执行一次。我们的照片只有一张脸， 所以只执行一次。

第二行创建一个名为 d 的画图工具。RGBA 代表红、绿、蓝和 alpha，而 alpha 就是颜色的透明程度。使用 'RGBA' 时，颜色会与底下的像素 混合，而不是覆盖它们。

2. 选择眉毛颜色

# (red, green, blue, see-through): each 0 to 255; see-through 0 = invisible, 255 = solid
color_eyebrow = (68, 54, 39, 128)

四个数字，不是三个。前三个是红、绿、蓝的分量，全部偏低，所以颜色偏深；红色是三者中 最高的，所以呈现深棕色。第四个数字 128 约为 255 的一半，所以颜色是半透明的， 你原本的眉毛仍然能透出来。

3. 填满两条眉毛

d.polygon(face_landmarks['left_eyebrow'], fill=color_eyebrow)
d.polygon(face_landmarks['right_eyebrow'], fill=color_eyebrow)

每条眉毛由五个点勾勒。polygon 按顺序连接这些点，从最后一点直接回到 第一点，然后填满里面的区域。 

pil_image.save("my_photo_eyebrow.jpg")

最后，程序把带有棕色眉毛的照片用新名字保存，原照片保持不变。

完整程序

把上面的部分拼回来。这就是完整的文件，一共 12 行： 

from PIL import Image, ImageDraw
import face_recognition
image = face_recognition.load_image_file("my_photo.jpg")
face_landmarks_list = face_recognition.face_landmarks(image)
pil_image = Image.fromarray(image)
for face_landmarks in face_landmarks_list:
    d = ImageDraw.Draw(pil_image, 'RGBA')
    # (red, green, blue, see-through): each 0 to 255; see-through 0 = invisible, 255 = solid
    color_eyebrow = (68, 54, 39, 128)
    d.polygon(face_landmarks['left_eyebrow'], fill=color_eyebrow)
    d.polygon(face_landmarks['right_eyebrow'], fill=color_eyebrow)
    pil_image.save("my_photo_eyebrow.jpg")

在自己的电脑上运行

下载 zip 文件并解压到 一个文件夹。这个 zip 包含本系列的六个程序；本文使用 face02_eyebrow.py。把你自己的照片放进该文件夹，命名为 my_photo.jpg。在 Visual Studio Code 中打开文件夹，然后在终端输入 以下三行： 

uv python pin 3.12.10
uv sync
uv run face02_eyebrow.py

第一行记录这个文件夹使用的 Python 版本。第二行安装 pyproject.toml 列出的所有软件包，你不用逐一安装。第三行运行程序，它会把结果保存为 my_photo_eyebrow.jpg。

如果你还没有设置 uv，请先阅读 〈如何安装 Visual Studio Code？〉， 然后是 Windows 或 Mac 的 uv 笔记。

技术备注：face-recognition 软件包依赖另一个名为 dlib 的软件包。 zip 中的项目文件已指向预先编译好的 dlib 版本，所以 uv sync 会直接安装可用版本，你不需要安装编译器。

这有什么用

所有数字“先试后买”工具的基本形态就是如此。程序知道你的眉毛在哪里，而颜色只是一行 就能改动的数值——所以你可以在购买前先看看某个色调的效果，或并排比较两种棕色。

有两个限制值得留意。程序只改变颜色，不改变形状：真正的眉笔还会增加长度和浓度。 而且由于程序填满的是五个点围成的区域，颜色主要集中在眉线上方；要填得更密， 就需要更多关键点或一点几何计算。
