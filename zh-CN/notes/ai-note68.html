如何训练你的第一个预测模型（预测，版本 7）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 6 分钟阅读

这是预测系列的第 7 个版本。版本 6 准备并切分了数据；版本 7 加入一个很小的神经网络，并让它 把训练例子完整跑 100 次。

模型是什么

模型把最近 29 天作为输入，给出一个数字：它对下一天的猜测。在内部，它是一个神经网络模型。 这篇笔记不会详细解释神经网络。之后的一篇 AI 笔记会说明它们怎样运作。

训练怎样运作

一个回合是把所有训练例子完整跑一遍，意思是模型把每一个例子都看过一次。 在每个回合里，程序对每一批 32 个例子做同样四件事：

  1. 把这 29 天给模型看，收集它的猜测。
  2. 把猜测与真正的下一天比较，算出误差，这叫做损失。
  3. 找出是哪些权重让损失变差，以及差了多少。
  4. 把每一个权重稍微调整一下，以降低损失。

一个批次是一组一起被处理的训练例子。在这个程序里，一个完整的批次包含 32 个 例子。这里的损失是均方误差：用答案减去猜测，取平方，再对这一批求平均。 取平方让差得远的错误比差一点点的错误更被看重。

处理完训练批次之后，程序在验证例子上测量损失 — 那些较晚的日子，模型从未从它们身上 学习。两个数字都被记录下来，好让它们可以被画出来。

程序怎样运作

1. 定义网络

class TimeSeriesModel(nn.Module):
    def __init__(self, window_size):
        super(TimeSeriesModel, self).__init__()
        self.network = nn.Sequential(
            nn.Linear(window_size-1, 10),  # window_size-1 because our features are window_size-1
            nn.ReLU(),
            nn.Linear(10, 10),
            nn.ReLU(),
            nn.Linear(10, 1)
        )

    def forward(self, x):
        return self.network(x)

class ... (nn.Module) 是定义 PyTorch 模型的标准做法。__init__ 把各层建立一次，nn.Sequential 的意思是按这个顺序运行这些层。 forward 是模型被调用时发生的事情：一批数据进去，一批预测出来。当 window_size = 30 时，第一层期待 29 个数字，这正是特征所持有的。

2. 选择损失和优化器

model = TimeSeriesModel(window_size)
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters())

criterion 用均方误差计算误差。optimizer 用那个误差来调整模型的 权重。model.parameters() 把网络里的每一个权重都交给优化器，这样它就知道自己 可以改变哪些值。

3. 选择计算在哪里进行

num_epochs = 100
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model.to(device)

cuda 是 NVIDIA 的技术，用它的显卡把这些算术做得更快。在 Mac 上，或在没有 NVIDIA 显卡的笔记本上，程序会安静地改用 cpu。model.to(device) 把模型搬到那个地方，批次也会跟着被搬过去。

4. 训练循环

for epoch in range(num_epochs):
    model.train()
    train_loss = 0
    for batch_features, batch_targets in train_loader:
        batch_features = batch_features.to(device)
        batch_targets = batch_targets.to(device)
        outputs = model(batch_features)
        loss = criterion(outputs, batch_targets)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        train_loss += loss.item()

model.train() 把网络切换成学习模式。里面的循环走过训练批次。对每一批， model(batch_features) 做出猜测，criterion 把它们变成一个损失。

接下来三行帮助模型从每一批中学习。optimizer.zero_grad() 清掉上一批留下的调整 计算。loss.backward() 算出每一个权重应该怎样改变才能降低误差。 optimizer.step() 把这些改变应用上去。把这三行重复几千次，就是模型学习的方式。

5. 在验证日上测量

    model.eval()
    val_loss = 0
    with torch.no_grad():
        for batch_features, batch_targets in val_loader:
            batch_features = batch_features.to(device)
            batch_targets = batch_targets.to(device)
            outputs = model(batch_features)
            val_loss += criterion(outputs, batch_targets).item()

model.eval() 切换到测量模式，而 torch.no_grad() 说的是 不必费心去算哪些权重该负责，我们在这里不改变它们。这节省时间和内存。验证损失随后 除以批次数，好让训练损失和验证损失处在同一个尺度上，然后每十个回合打印一次这两个数字。

6. 画两张图

plt.plot(train_losses, label='Training Loss')
plt.plot(val_losses, label='Validation Loss')

第一张图把两个损失对着回合数画出来：一条应该先下降、然后变平的线。第二张图把模型的猜测对着 真正的验证日画出来，灰色是真实值，红色是预测值，这样你就能看到两条线是否贴在一起。

7. 把一切归结为一个数字

mae_torch = torch.mean(torch.abs(val_predictions_tensor - val_targets_tensor))
print(f"Validation MAE (PyTorch): {mae_torch:.4f}")

MAE，即平均绝对误差，是预测值与实际值之间差值的平均，不看每个预测是偏高 还是偏低。在这次运行里，它大约是 4.76 港元。验证部分的每日销售额大约在 140 港元左右，所以 (4.76 ÷ 140) × 100 ≈ 3.4%。换句话说，平均预测误差大约是 典型一天销售额的 3%。MAE 比平方损失更容易向经理解释，因为它是以销售额的货币单位衡量的。

完整程序

把上面的各部分放回一起。这就是完整的文件： 

import torch
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
import matplotlib.pyplot as plt
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    features = windows[:, :-1]  # All columns except the last
    targets = windows[:, -1:]   # Just the last column
    return features, targets

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
full_dataset = TensorDataset(features, targets)

total_windows = len(full_dataset)
train_size = int(total_windows * 0.8)  # 80% for training, 20% for validation
train_indices = list(range(train_size))
val_indices = list(range(train_size, total_windows))

train_dataset = Subset(full_dataset, train_indices)
val_dataset = Subset(full_dataset, val_indices)

# Create DataLoaders
batch_size = 32
train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=batch_size, shuffle=False)

import torch
import torch.nn as nn
import torch.optim as optim

# Define the model
class TimeSeriesModel(nn.Module):
    def __init__(self, window_size):
        super(TimeSeriesModel, self).__init__()
        self.network = nn.Sequential(
            nn.Linear(window_size-1, 10),  # window_size-1 because our features are window_size-1
            nn.ReLU(),
            nn.Linear(10, 10),
            nn.ReLU(),
            nn.Linear(10, 1)
        )

    def forward(self, x):
        return self.network(x)

# Initialize model, loss function, and optimizer
model = TimeSeriesModel(window_size)
criterion = nn.MSELoss()
optimizer = optim.Adam(model.parameters())

# Training loop
num_epochs = 100
device = torch.device('cuda' if torch.cuda.is_available() else 'cpu')
model.to(device)

# Lists to store losses for plotting
train_losses = []
val_losses = []

for epoch in range(num_epochs):
    # Training phase
    model.train()
    train_loss = 0
    for batch_features, batch_targets in train_loader:
        batch_features = batch_features.to(device)
        batch_targets = batch_targets.to(device)

        # Forward pass
        outputs = model(batch_features)
        loss = criterion(outputs, batch_targets)

        # Backward pass and optimize
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        train_loss += loss.item()

    # Validation phase
    model.eval()
    val_loss = 0
    with torch.no_grad():
        for batch_features, batch_targets in val_loader:
            batch_features = batch_features.to(device)
            batch_targets = batch_targets.to(device)

            outputs = model(batch_features)
            val_loss += criterion(outputs, batch_targets).item()

    # Calculate average losses
    train_loss /= len(train_loader)
    val_loss /= len(val_loader)

    train_losses.append(train_loss)
    val_losses.append(val_loss)

    if (epoch + 1) % 10 == 0:
        print(f'Epoch [{epoch+1}/{num_epochs}], '
              f'Train Loss: {train_loss:.4f}, '
              f'Val Loss: {val_loss:.4f}')

# Plot training progress
plt.figure(figsize=(10, 6))
plt.plot(train_losses, label='Training Loss')
plt.plot(val_losses, label='Validation Loss')
plt.title('Model Loss Over Time')
plt.xlabel('Epoch')
plt.ylabel('Loss')
plt.legend()
plt.grid(True)
plt.show()

# Make predictions
model.eval()
with torch.no_grad():
    # Get predictions for validation set
    val_predictions = []
    val_targets = []
    for batch_features, batch_targets in val_loader:
        batch_features = batch_features.to(device)
        outputs = model(batch_features)
        val_predictions.extend(outputs.cpu().numpy())
        val_targets.extend(batch_targets.numpy())

# Plot predictions vs actual for validation set
plt.plot(val_targets, label='Actual', color="lightgrey")
plt.plot(val_predictions, label='Predicted', color="red")
plt.title('Predictions vs Actual Values (Validation Set)')
plt.xlabel('Time')
plt.ylabel('Value')
plt.legend()
plt.grid(True)
plt.show()

val_predictions_tensor = torch.tensor(val_predictions)
val_targets_tensor = torch.tensor(val_targets)
mae_torch = torch.mean(torch.abs(val_predictions_tensor - val_targets_tensor))
print(f"Validation MAE (PyTorch): {mae_torch:.4f}")

在自己的电脑上运行

下载 zip 文件并解压到一个 文件夹。zip 里有这个系列到目前为止的程序、time_series.csv 数据文件，以及 pyproject.toml。这篇笔记用的是 time_07.py。在 Visual Studio Code 中打开文件夹，然后在终端输入这三行： 

uv python pin 3.12.10
uv sync
uv run time_07.py

第一行记录这个文件夹用哪个 Python 版本，第二行安装 pyproject.toml 列出的每一个 包。第三行每十个回合打印一行，然后打开损失图和预测图；关闭每个窗口，程序才会继续。

这三行只需要一次。下次想再运行程序，只输入 uv run time_07.py。

如果你还没有设置 uv，先看 如何安装 Visual Studio Code？，然后看 uv 笔记的 Windows 或 Mac。

接下来是什么

现在有模型了，但它的好坏只在验证日上被评判，而验证日只是数据的最后 20%。版本 8 加入第三 部分 — 一个从未被动过的测试集 — 并在它上面报告四个指标：MAE、MSE、RMSE 和 R²。
