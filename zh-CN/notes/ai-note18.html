如何在 macOS 安装 Homebrew 套件管理程序？

林邦源 · AI 笔记 · 2026年11月4日 · 阅读时间约 5 分钟

Homebrew 自称「The Package Manager for Everywhere」（适用于各处的套件管理程序）：它支援 macOS（Sequoia 15 或更新版本）、Linux，以及 Windows Subsystem for Linux（WSL）。套件管理程序是一条命令， 帮你下载并安装其他程序，所以你不用四处找网站、再把文件拖进 Applications 文件夹。 有了 Homebrew，安装 git 之类的工具或 Firefox、Chrome 等应用程序，只需在终端输入短短一行。 本篇只介绍 macOS。

观看示范影片

如影片未能载入，请在 Google 云端硬盘开启： 影片 （无需账号）。

准备事项

  • 执行 macOS Sequoia（15）或更新版本的 Mac——这是 Homebrew 官方支援的版本。 旧版 macOS 或仍可使用，但不保证。
  • 网络连线。
  • Mac 的管理员密码——安装程序需要权限建立自己的文件夹。如果你是自己 Mac 的唯一使用者，管理员密码就是 Mac 锁定画面要求你输入的密码。
  • 终端机（Terminal）应用程序，在「应用程序 → 工具程序」内， 或在 Spotlight 输入「Terminal」。

安装命令

打开终端机，贴上这行来自 Homebrew 官方网页的命令（截至撰写本 AI 笔记之时）： 

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

按 Return。命令会先说明它会做什么，然后暂停并要求你输入密码。 输入 Mac 的登入密码——画面上不会显示任何字符——再按一次 Return。 安装可能需时数分钟，请等到命令完成并显示 「Installation successful!」。

把 Homebrew 加入 PATH

安装完成后，命令会在最后印出几行，让你的 Mac 找得到 brew 命令。 这一步很容易被忽略——但若略过，终端机会显示 command not found。 关闭终端机前，请向上滚动到安装程序最后印出的几行，复制并原样执行它们。 那几行已因应你 Mac 的晶片给出正确文件夹，所以你不用猜是 Apple Silicon 还是 Intel。

检查是否成功

关闭终端机再重新打开，然后输入：

brew --version

它会印出版本编号，例如 Homebrew 4.4.0。若显示 command not found: brew，代表 PATH 步骤尚未生效—— 请回到安装程序印出的那几行，重新执行一次，再重开终端机。

试试看：安装工具与应用程序

Homebrew 有两种套件。Formulae 是命令列工具与函式库； casks 是完整的桌面应用程序。安装一个命令列工具： 

brew install wget

安装一个桌面应用程序（此例为 Firefox 浏览器），它会出现在 Applications 文件夹： 

brew install --cask firefox

更新 Homebrew 本身，以及升级所有以它安装的套件： 

brew update
brew upgrade

局限

  • 需要管理员密码才能建立文件夹与系统连结。
  • PATH 步骤最容易被遗漏。没有它，即使安装成功，brew 也找不到。
  • Apple Silicon 与 Intel 使用不同文件夹。请务必使用安装程序印出的那几行， 因为它已对应你的 Mac。
  • 每次安装或更新套件都需要网络连线。
