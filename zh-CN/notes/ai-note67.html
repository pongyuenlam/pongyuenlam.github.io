如何把例子分成训练和验证两部分（预测，版本 6）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 5 分钟阅读

这是预测系列的第 6 个版本，它仍然没有训练任何东西。它做了一件事，让之后所有的训练都值得 信任：把 1,431 个例子分成训练部分和验证部分。模型会用 第一部分来学习，用第二部分来评判，而第二部分它从未学习过。

为什么要留出一部分例子？

一个模型可以在它训练过的那些确切日子上得满分，却仍然毫无用处，就像一个把去年试题的答案 背下来的学生，对这门科目其实一无所知。唯一有说服力的测验，是学生没见过的那份试卷。

验证部分就是那份没见过的试卷。训练期间，程序会不断测量模型在它上面的表现，而这些测量 结果 — 不是训练时的那些 — 才会告诉你，究竟有没有任何东西真的被学到。

为什么切分不是随机的

切分是按日期顺序做的：较早的例子训练模型，最新的例子验证模型。模型总是在它学习过的那些 日子之后的日子里被评判，和它在实际使用中的处境完全一样。

2. 选择在哪里切

total_windows = len(full_dataset)
train_size = int(total_windows * 0.8)  # 80% for training, 20% for validation
train_indices = list(range(train_size))
val_indices = list(range(train_size, total_windows))

len(full_dataset) 是 1,431。1,431 的 80% 是 1,144.8，而 int() 会把小数点之后的全部丢掉，所以 train_size 变成 1,144。

range(1144) 从 0 数到 1,143：也就是前 1,144 个例子，最早的那些日子。 range(1144, 1431) 从 1,144 数到 1,430：也就是剩下的 287 个例子，最新的那些 日子。

3. 为一个数据集做两个视图

train_dataset = Subset(full_dataset, train_indices)
val_dataset = Subset(full_dataset, val_indices)

Subset 不复制任何东西。它记下一串位置，并通过那串位置来呈现同一批底层的例子。

4. 做两个加载器，打乱方式不同

batch_size = 32
train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=batch_size, shuffle=False)

模型每遍历一次训练数据，训练加载器都会打乱窗口的顺序。它不会改变每个窗口里面那些日子的 时间先后。这帮助模型从窗口内的销售额数值中学习，而不是从窗口被呈现的顺序中学习。

验证加载器每次都让例子保持同样的顺序。如果两次运行对验证日得出不同的误差测量，你就知道 这个差别并不只是因为例子以不同的顺序被呈现。

5. 打印计数

print(f"Original series length: {len(series)}")
print(f"Total number of windows: {total_windows}")
print(f"Training windows: {len(train_dataset)}")
print(f"Validation windows: {len(val_dataset)}")

头两行用两种颜色画出销售额：'b-' 是训练日的蓝线，'r-' 是验证日的 红线。第三行用 plt.axvline 在切点加一条黑色虚线竖线。plt.legend() 打印解释颜色的小图例，plt.show() 打开窗口。

那条虚线标出界线：它左边的全部，模型可以学习；它右边的全部，模型只能被评判。

完整程序

把上面的各部分放回一起： 

import torch
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
import matplotlib.pyplot as plt
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    features = windows[:, :-1]  # All columns except the last
    targets = windows[:, -1:]   # Just the last column
    return features, targets

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
print("Series tensor shape:")
print(series_tensor.shape)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
print("Features and targets shapes:")
print(features.shape)
print(targets.shape)
full_dataset = TensorDataset(features, targets)

total_windows = len(full_dataset)
train_size = int(total_windows * 0.8)  # 80% for training, 20% for validation
train_indices = list(range(train_size))
val_indices = list(range(train_size, total_windows))

train_dataset = Subset(full_dataset, train_indices)
val_dataset = Subset(full_dataset, val_indices)

# Create DataLoaders
batch_size = 32
train_loader = DataLoader(train_dataset, batch_size=batch_size, shuffle=True)
val_loader = DataLoader(val_dataset, batch_size=batch_size, shuffle=False)

print(f"Original series length: {len(series)}")
print(f"Total number of windows: {total_windows}")
print(f"Training windows: {len(train_dataset)}")
print(f"Validation windows: {len(val_dataset)}")

plt.plot(range(train_size), series[:train_size], 'b-', label='Training Data')
plt.plot(range(train_size, len(series)), series[train_size:], 'r-', label='Validation Data') 
plt.axvline(x=train_size, color='k', linestyle='--', label='Train/Val Split Point')
plt.title('Time Series Train/Validation Split')
plt.xlabel('Time (days)')
plt.ylabel('Value')
plt.legend()
plt.grid(True)
plt.show()

在自己的电脑上运行

下载 zip 文件并解压到一个 文件夹。zip 里有这个系列到目前为止的程序、time_series.csv 数据文件，以及 pyproject.toml。这篇笔记用的是 time_06.py。在 Visual Studio Code 中打开文件夹，然后在终端输入这三行： 

uv python pin 3.12.10
uv sync
uv run time_06.py

第一行记录这个文件夹用哪个 Python 版本，第二行安装 pyproject.toml 列出的每一个 包。第三行打印形状和计数，然后打开图表窗口；关闭它，程序就会结束。

这三行只需要一次。下次想再运行程序，只输入 uv run time_06.py。

如果你还没有设置 uv，先看 如何安装 Visual Studio Code？，然后看 uv 笔记的 Windows 或 Mac。

接下来是什么
