如何让网页听懂中文（普通话或粤语）并用语音回答（版本 4）？

林邦源 · AI 笔记 · 2026年11月27日 · 阅读时间约 5 分钟

English 繁體中文 简体中文

网页可以听中文，也可以开口回答。这个页面听得懂普通话或粤语、显示文字，再读出一句简短的回答。 它仍然是一个 HTML 文件、一段短脚本。

页面同时使用 Web Speech API 的两半：语音识别用来聆听，语音合成用来回答。 Chrome 和 Edge 两者兼备，Firefox 则两者皆无。

页面需要麦克风。第一次点击 开始听 时，浏览器会询问是否允许页面 使用麦克风；请选择 Allow。

开始前需要什么

  • Chrome 或 Edge。Firefox 无法运行此页。
  • 一个麦克风。多数笔记本电脑已经内置。
  • 扬声器或耳机，并打开声音。回答会从它们播出。
  • 一个中文语音。多数电脑都有。如果回答没有声音，或用英文腔读出，请在电脑的 声音设置中添加中文语音。
  • 互联网连接。Chrome 会把录下的声音送到它的语音服务，再把文字送回来。
  • 一个文字编辑器。有 Visual Studio Code 就用它；否则先看 如何安装 Visual Studio Code？

步骤 1：创建文件

下载 zip 文件并解压。 在 Mac 上双击 zip；在 Windows 上右键单击，选择 Extract All。你会得到一个名为 Folder-AI-Speech-04-Putonghua-Reply 的文件夹，里面有 index.html。

步骤 2：打开页面

选项 1：这台电脑。双击 index.html，它就会在浏览器中打开。 无需服务器。

选项 2：你的免费网站。把这个 HTML 文件复制到免费 GitHub 网站的文件夹 （见 如何在 username.github.io 创建一个免费网站？），然后上传更改。 如果文件夹已有名为 index.html 的页面，先把它重命名，例如改为 chinese-reply.html，以免上传时取代你网站的首页。再在 Chrome 中打开该页的 https:// 网址。

选项 3：本网站。打开 本网站上的同一个页面，点击 开始听。它会立即运行，无需下载任何东西。

文件不必命名为 index.html。任何名称都可以，名称会成为链接的结尾：名为 chinese-reply.html 的文件，网址就是 https://your-username.github.io/chinese-reply.html。

名为 index.html 的文件很特别，它是访客最先看到的页面。所以用这个名称的文件， 会取代你网站的首页。

步骤 3：整个文件

以下是 index.html 的全部内容：

<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<title>Answer</title>
</head>
<body>
<h1>答案</h1>
<button onclick="startListening()">开始听</button>
<button onclick="stopListening()">停止</button>
<p>你说：<span id="heard">还没有</span></p>
<p>回答：<span id="reply">还没有</span></p>
<script>
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
const recognition = new SpeechRecognition();
recognition.lang = 'zh-CN';
recognition.onresult = function (event) {
  const heard = event.results[0][0].transcript;
  document.getElementById('heard').textContent = heard;
  const reply = '你说的是：' + heard;
  document.getElementById('reply').textContent = reply;
  speak(reply);
};
function startListening() {
  recognition.start();
}
function stopListening() {
  recognition.stop();
}
function speak(text) {
  speechSynthesis.cancel();
  const utterance = new SpeechSynthesisUtterance(text);
  utterance.lang = 'zh-CN';
  speechSynthesis.speak(utterance);
}
</script>
</body>
</html>

上半部分是普通网页：一个标题、两个按钮，以及两行文字。标题是中文的“答案”，按钮是“开始听”和 “停止”，两行文字则显示出现的字句。每个按钮都有一个 onclick 属性，指明按下时 要执行的函数。

步骤 4：脚本中的名称

SpeechRecognition 是浏览器的聆听引擎。Chrome 也以较旧的名称 webkitSpeechRecognition 提供它，所以第一行会采用浏览器拥有的那个名称。 recognition.lang = 'zh-CN' 告诉引擎说话者所说的是中文。'zh-CN' 要求中国大陆的标准汉语，而识别器实际上也能接受粤语，并以书面中文返回。

recognition.onresult 指明文字到达时要执行的函数。 event.results[0][0].transcript 是句子本身，以纯文本表示。接下来两行把这句话 放到页面上，并组成回答 '你说的是：' + heard，也就是在句子前面加一句简短的中文。

speak(text) 是说话的那一半。speechSynthesis.cancel() 停止先前的回答， SpeechSynthesisUtterance 准备好要朗读的新文字， speechSynthesis.speak() 把它交给引擎。utterance.lang = 'zh-CN' 这一行要求普通话语音，所以即使你说粤语，回答也会用普通话读出。没有这一行，电脑可能用英文 语音读中文字，或者完全不发声。最后，start() 打开麦克风，stop() 关闭它。

步骤 5：试一试

在 Chrome 中打开页面。点击 开始听，浏览器要求麦克风时选择 Allow，然后用普通话或粤语说一句，例如 你好，世界！。

文字会出现在 你说： 旁边，电脑接着用中文把回答读出来。点击 停止 可以提前关闭麦克风。如果你一时没有说话，页面会自行停止；再次点击 开始听 便可继续。

限制

  • 必须允许麦克风。如果浏览器不为电脑上的文件提供麦克风，请把页面上传到 你的免费网站，并在那里打开。
  • 回答只是回声，不是对话。页面只在你的话前面加一句再重复，并不理解内容， 里面也没有 AI 模型。
  • 聆听的一半需要互联网。Chrome 把声音送到它的语音服务。说话的一半通常 离线也可用，因为语音已安装在电脑上。
  • 一次一句。短暂停顿后，页面停止聆听，然后回答一次。
  • 并不完美。背景噪音、浓重口音和不寻常的名字都会变成错误的字词， 回答也会重复同样的错误。
  • 只限普通话和粤语。聆听语言固定为 'zh-CN'，涵盖普通话， 实际上也能处理粤语。其他语言无法识别。回答用中文语音读出；如果电脑没有中文语音， 回答可能无声，请在声音设置中添加。
