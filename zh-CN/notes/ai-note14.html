Python 程序如何用 Tavily API 搜索互联网？

林邦源 · AI 笔记 · 2026年11月3日 · 阅读时间约 4 分钟

English 繁體中文 简体中文

程序有时需要来自互联网的最新信息：今天的新闻、一个价格、一个地址。普通的搜索引擎是 为人而设——它返回一页页夹杂广告的链接，程序难以直接使用。Tavily 则是专为程序而设的搜索服务：你用简单英文向它提问，它便返回一段简短、现成的答案， 连同它用过的网页。

本文的程序向 Tavily 提出 “Where is Hong Kong?”这个问题，并打印答案， 全程只用 11 行。

先获取密钥

Tavily 需要知道谁在提问，所以程序要出示一个 API 密钥：一串像密码 一样的保密字符。API 是 Application Programming Interface（应用 程序接口）的缩写，即程序之间通过互联网沟通的方式。要获取密钥，请到 https://www.tavily.com/ 注册；免费套餐已足够试用，密钥会显示在控制台上。

密钥绝不能直接写进程序里，否则任何读到代码的人都能拿走它。密钥应放在同一文件夹内 一个名为 .env 的小文件中，里面只有一行： 

TAVILY_API_KEY=paste-your-key-here

下载示例程序后，请自行创建这个文件；zip 内并不包括它，因为密钥属于个人。

逐段拆解程序

import os

from dotenv import load_dotenv
from tavily import TavilyClient

load_dotenv()

这里引入了三个库。os 是 operating system（操作系统） 的缩写；在这里用来读取环境变量，即存放在代码以外的设置。load_dotenv 读取 .env 文件，把每一行复制到那些环境变量之中。 TavilyClient 是 Tavily 库的连接器，即负责把问题发送给服务的对象。 

tavily_client = TavilyClient(api_key=os.getenv("TAVILY_API_KEY"))

这行创建连接器。os.getenv("TAVILY_API_KEY") 读取 load_dotenv() 刚才从 .env 加载的密钥，交给 TavilyClient。从此连接器发出的每个请求都带着密钥，Tavily 便知道 请求来自哪个账户。 

response = tavily_client.search("Where is Hong Kong?", include_answer=True)

search 调用负责发送问题。include_answer=True 要求 Tavily 不仅返回网页列表，还要根据那些网页写出一段简短答案。结果会以一个字典 （dictionary）的形式返回：一组有名称的部分，例如 "answer" 是写好的答案， "results" 是网页列表。 

print(response["answer"])

这行从字典中取出 "answer" 部分并打印出来。想问其他问题，改动上一行的 问题即可。

完整程序

import os

from dotenv import load_dotenv
from tavily import TavilyClient

load_dotenv()

tavily_client = TavilyClient(api_key=os.getenv("TAVILY_API_KEY"))
response = tavily_client.search("Where is Hong Kong?", include_answer=True)

print(response["answer"])

在自己的电脑上运行

下载 zip 文件并 解压到一个文件夹。这个 zip 包含程序和一个 pyproject.toml 项目文件。 请如上所示，加入你自己的 .env 密钥文件。然后在 Visual Studio Code 中 打开文件夹，在终端逐行输入以下三行： 

uv python pin 3.12.10
uv sync
uv run tavily_search.py

第一行记录这个文件夹使用哪个 Python 版本。第二行设置项目，并安装程序需要的两个软件包 tavily-python 和 python-dotenv。第三行运行程序。几秒之后， 答案便会出现： 

Hong Kong is located on the southeastern coast of China, at the eastern side of the Pearl River Delta, where the Pearl River meets the South China Sea. It sits directly south of Shenzhen and Guangdong province, making it a gateway between mainland China and the rest of the world.

你运行时的措辞很可能不同，因为 Tavily 会按它当时找到的网页，即时写出新的答案。

如果你还没有设置 uv，请先从 如何安装 Visual Studio Code？开始，然后看 uv 笔记： Windows 或 Mac。

局限

  • 它需要密钥和互联网。.env 里没有有效的密钥，或者 没有连接，程序都会因错误而终止。
  • 免费套餐有上限。Tavily 每月免费提供固定数量的搜索；大量使用 需要付费套餐。
  • 答案的质量取决于找到的网页。Tavily 阅读网页再写出摘要，所以 问题含糊或来源欠佳，答案也会欠佳。问得精准会有帮助。
