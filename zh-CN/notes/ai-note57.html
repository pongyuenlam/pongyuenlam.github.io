如何修改来自摄像头的一帧画面（人脸识别，版本 5）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 4 分钟阅读

版本 4 打开摄像头，把每一帧原样显示出来。版本 5 改变了这一点：在读取一帧和显示它之间， 程序现在会修改它。这里用的修改是转换成灰色，但灰色不是重点。重点是循环中间的那一步， 帧停在一个变量里，在任何人看到它之前还可以被改动。

这一步一旦存在，整个系列后面的内容就看得清楚了。往里放一个颜色转换，窗口就显示灰色。 放入版本 3 的人脸搜索，窗口就能显示一个名字。放一个框，窗口就显示一个框。同一个摄像头， 同一个循环，同一个按键；只有中间那一行变了。

程序怎么运作

1. 打开摄像头

import cv2
cap = cv2.VideoCapture(0)

和版本 4 相同的两行：载入 OpenCV，连接第一台摄像头。如果窗口一直不出现或者全黑， 原因在这里，不在新加的那一行 — 权限问题，或者其他程序正在用摄像头。

2. 读一帧，修改它，然后显示改过的那一帧

while True:
    ret, img = cap.read()
    gray_img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    cv2.imshow("Frame", gray_img)

三件事按顺序发生。cap.read() 取一帧彩色画面，存进 img。下一行制作一个改动过的副本，gray_img。第三行显示这个副本。 原来的 img 没有被动过；改动后的版本是另一个变量。

cv2.cvtColor 就是版本 2 用来重排颜色通道的那个函数。这次的目标是 cv2.COLOR_BGR2GRAY：三个通道进去，一个通道出来。这个转换不是简单取平均； 绿色的权重最大，其次是红色，最后是蓝色，所以红苹果和青苹果可能得出相近的亮度。

屏幕上显示什么，取决于哪个变量被送进 cv2.imshow。送 img，你看到的就是没改过的摄像头画面，和版本 4 一样。送 gray_img，你看到的就是改动。这一个选择就是全部机制，后面每个版本都用不同的 中间一行再做一次。

3. 退出、放开、关闭

    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

和版本 4 一样。waitKey(1) 既等待按键，也让窗口重画；q 或 Q 从键盘中断循环；release 和 destroyAllWindows 在循环结束后收拾干净。记得打字之前在视频窗口上点一下， 否则按键会送到编辑器。

完整程序

把上面的片段拼回去。这是完整的文件，一共 11 行： 

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    gray_img = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    cv2.imshow("Frame", gray_img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

任何修改都是同一个做法

选灰色，是因为它只有一行，而且不会出错，但这一步接受任何返回同样尺寸图像的操作。 换掉中间那一行，窗口就变了，程序里别的地方都不用动。三个一行的例子，每个都用来替换 cvtColor 那一行： 

flipped  = cv2.flip(img, 1)                                # 镜像
blurred  = cv2.GaussianBlur(img, (9, 9), 0)                # 让画面变柔和
brighter = cv2.convertScaleAbs(img, alpha=1.2, beta=20)    # 提高亮度

记得把新的变量传给 cv2.imshow，否则窗口显示的仍然是原来那一帧， 看起来像什么都没发生。

关于灰色还有一点：它保留黑白之间的每一个深浅，通常 256 级。严格意义上的黑白只保留两级， 把每个像素逼成 0 或 255。那个操作叫阈值化，丢掉的信息比这个程序多得多。

在自己的电脑上运行

用和版本 1 相同的下载： 下载压缩包，解压， 然后用 Visual Studio Code 打开这个文件夹。这一篇用的是 face05.py。 第一次在这个文件夹里，运行全部三行： 

uv python pin 3.12.10
uv sync
uv run face05.py

这三行只需要做一次。下次想再运行这个程序，只需输入 uv run face05.py。

往下读之前，先试试上面三个替换中的一个：这是看清摄像头那部分从来不变、只有中间那一行 在变的最快方法。
