如何用语音合成让网页把文字读出来（版本 1）？

林邦源 · AI 笔记 · 2026年11月26日 · 阅读时间约 4 分钟

English 繁體中文 简体中文

大多数浏览器本身就会说话。网页不需要服务器、不需要 Python 程序，也无需安装任何东西： 一个 HTML 文件，双击打开，就能读出你输入的文字。

这个页面用的是语音合成（speech synthesis），也就是每个现代浏览器都内置的 Web Speech API 的其中一半。

开始前需要什么

  • 一个浏览器。Chrome、Edge、Safari 和 Firefox 都能把文字读出来。
  • 一个文字编辑器。有 Visual Studio Code 就用它；否则先看 如何安装 Visual Studio Code？
  • 打开声音。朗读声音会从电脑的扬声器播出。

步骤 1：创建文件

下载 zip 文件并解压。 在 Mac 上双击 zip；在 Windows 上右键单击，选择 Extract All。你会得到一个名为 Folder-AI-Speech-01-Read-Aloud 的文件夹，里面有 index.html。 双击 index.html，它就会在浏览器中打开。无需使用终端，也无需启动服务器。

步骤 2：整个文件

以下是 index.html 的全部内容：

<!DOCTYPE html>
<html lang="en">
<head>
<meta charset="UTF-8">
<title>Read aloud</title>
</head>
<body>
<h1>Read aloud</h1>
<label for="text">Text:</label>
<textarea id="text" rows="3">Hello, World!</textarea>
<button onclick="speak()">Speak</button>
<button onclick="stopSpeaking()">Stop</button>
<script>
function speak() {
  speechSynthesis.cancel();
  const text = document.getElementById('text').value;
  const utterance = new SpeechSynthesisUtterance(text);
  speechSynthesis.speak(utterance);
}
function stopSpeaking() {
  speechSynthesis.cancel();
}
</script>
</body>
</html>

上半部分是普通网页：一个标题、一个标签、一个内含 Hello, World! 的文本框，以及两个按钮。 textarea 是接受多行输入的文字框，所以整段文字也放得下。每个按钮都有一个 onclick 属性，指明按下时要执行的函数。

步骤 3：脚本中的三个名称

只有三个名称要紧。speechSynthesis 是浏览器的语音引擎。 SpeechSynthesisUtterance 是一段准备朗读的文字；每次都要新建一个， 因为每个都载有自己的字句。speak() 把它交给引擎。

speechSynthesis.cancel() 会停止仍在朗读的内容。它出现两次：一次在 speak() 开头，以免第二次按下与第一次重叠；一次在 stopSpeaking() 内，也就是 Stop 按钮所调用的函数。

步骤 4：试一试

输入一句或一段英文，点击 Speak，电脑就会读出来。点击 Stop 可中途停止。

输入中文句子通常不会有声音。页面从没告诉浏览器要用哪种语言朗读，所以浏览器会退回默认语音， 通常就是英文。如何指定语言，见“限制”一节。

限制

  • 声音由电脑选择。页面没有说明要用哪种语言，浏览器便使用默认语音，通常是 英文。交给英文语音的中文文字一般会被略过，悄无声息。为文字指定语言，例如 utterance.lang = 'zh-CN'，是另一个题目。
  • 按下之后才会开始朗读。浏览器会让页面保持静音，直到访客与页面互动； Speak 按钮就提供了这个互动。
  • 语音来自设备。多数系统离线也能朗读，因为语音已安装在本机；但少数浏览器 会改用在线语音。
