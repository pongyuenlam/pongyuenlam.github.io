AI 代理如何在没有任何工具的情况下回答（ReAct，版本 2，只推理）？

林邦源博士 · AI 笔记 · 2026 年 11 月 9 日 · 约 3 分钟阅读

上一篇笔记建立了一个 会思考、行动和观察的代理。本篇删去三步之中的两步。没有行动、没有观察 — 模型只能思考，也就是所谓的思维链，然后凭 自己的记忆回答。它说的每一句，都没有对照真实世界核实。它面对的问题故意 含糊：“Mark 何时推出 Muse？”

代码

这是 ReAct02.py 目前的内容：

# "Reason only" (Chain-of-Thought): NO tool and NO loop.
# The model can only THINK step by step and answer from its own memory.
# Nothing is checked against the real world, so the answer may be wrong (hallucination).
# Compare the result with react03.py (Reason + Act), which searches the web with Tavily.
import os
from openai import OpenAI
from dotenv import load_dotenv
load_dotenv()

client = OpenAI(
    api_key=os.environ.get('DEEPSEEK_API_KEY'),
    base_url="https://api.deepseek.com")

def ask(prompt):
    """Send one prompt to the model and return its text reply."""
    response = client.chat.completions.create(
        model="deepseek-flash",
        messages=[{"role": "user", "content": prompt}],
    )
    return response.choices[0].message.content

task = ("When did Mark launch Muse")

# ---- THINK only (Reasoning) — no Action, no Observation ----
prompt = f"""Task: {task}
You have NO tools. Think step-by-step using only what you already know,
then end with one line: Answer: <your answer>"""
reply = ask(prompt)
print("=== Thought (reasoning trace, no tools) ===")
print(reply)

每一部分的作用

  • DeepSeek 客户端和 ask() 与上一篇笔记完全 相同：一个来自 .env 文件的密钥，一个发出提示词并返回回复的 辅助函数。
  • 任务没有指明姓氏，也没有指明产品类别。“Mark”可能是 Mark Zuckerberg；“Muse”可能是那支乐队、一个应用，或者根本不存在。 要答得好，需要一些模型几乎肯定没有的事实。
  • 提示词禁止使用工具。它让模型只凭已知的东西逐步思考， 最后以 Answer: 开头的一行作结。整个程序就是这样：一次调用、 一次打印。

一次真实运行

=== Thought (reasoning trace, no tools) ===
Mark Zuckerberg launched Muse? I don't have knowledge of Mark launching something called Muse. There is a band Muse, but not launched by Mark. Perhaps you mean Meta's AI model? I'm not aware.

Answer: I don't know.

有两点值得注意。第一，推理确实有用：模型看出了其中的含糊（“有一支叫 Muse 的乐队，但不是 Mark 推出的”），而不是假装问题很清楚。第二，最终答案是 诚实的 — 至少这一次。程序里没有任何东西强制它诚实。问一个 听起来更普通的问题，同样只靠记忆的推理，就可能产生一个自信、流畅但错误 的答案：幻觉。这里没有观察步骤可以抓住它。

在自己的电脑上运行

下载演示程序 （Folder-AI-ReAct02.zip）。zip 里包含三个文件： ReAct02.py（上面的程序）、pyproject.toml （包清单）和 README.md。

  1. 在 Visual Studio Code 中打开这个文件夹。
  2. 在文件夹里新建一个名为 .env 的文件，写入一行： 
    DEEPSEEK_API_KEY=your-key-here
    到 DeepSeek 控制台获取密钥；新账户附带试用额度。
  3. 在终端运行： 
    uv sync
uv run ReAct02.py
    uv sync 只需第一次运行；它会读取 pyproject.toml，把 openai 和 python-dotenv 安装到项目中。

试着把任务改成一个有众所周知答案的问题，然后改成关于一家小型本地公司的 问题。两次运行的对比，就是这一课。

为什么这个实验重要

  • 推理不是知识。逐步思考改善模型运用已知知识的方式；但它 无法提供它从不知道的东西。
  • 诚实是靠运气，不是设计。“我不知道”在这里是模型的选择， 不是保证。只有观察步骤才能让答案可靠。
  • 它为比较铺路。这个系列的下一篇笔记会加入一个工具 — 网上搜索 — 再问同一类问题，让你看清楚行动带来了什么改变。
