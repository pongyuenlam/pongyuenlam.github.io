如何为 AI 代理创建时间工具？

林邦源博士 · AI 笔记 · 2026 年 11 月 8 日 · 约 3 分钟阅读

AI 代理能够规划、起草和推理，却不知道当下的时间和日期。它对“现在”的概念 来自训练时读过的文本，所以你问它今天是几号，它可能会叫你自己去查。任何依赖 时间的事情，在代理得到一个“查看”的方法之前，都不可靠。

工具就是那个方法：一个代理获准调用的普通函数。本篇笔记创建 一个最小的实用工具 —— 一个返回当前日期和时间的函数 —— 并在牵涉任何代理之前 先测试它。整个工具只有九行 Python。

工具

这是 tool01_time.py 目前的内容：

from datetime import datetime
def get_current_time():
    """
    Returns the current date and time as a string.
    """
    return datetime.now().strftime("%Y-%m-%d %H:%M:%S")
result = get_current_time()
print(result)

每一部分的作用

  • datetime 是 Python 内置的，无需安装任何东西。
  • get_current_time() 不接受任何参数。这是刻意的：没有参数的 工具，是模型最容易正确调用的类型。
  • docstring 不是装饰。当这个函数交给代理使用时，这句话就成为模型决定是否 调用它之前所读到的描述。“Returns the current date and time as a string” 既说明会返回什么，也说明什么时候值得调用这个工具。
  • strftime —— string format time 的缩写 —— 把 datetime 转成文字，而 strftime("%Y-%m-%d %H:%M:%S") 固定了格式，例如 2026-11-08 14:32:07。固定格式很重要，因为模型会把这个值引用 给用户，也可能把它拆成日期和时间两部分。
  • 最后两行调用函数并打印结果，让你在还未牵涉任何代理之前，就可以在终端 检查这个工具。

单独测试

运行这个文件：

python tool01_time.py

你应该会看到一行，例如 2026-11-08 14:32:07。这是运行脚本那台 电脑的时钟。如果脚本放在其他地区的服务器上，你得到的是服务器的本地时间， 不是你的时间。

为什么这是好的第一个工具

  • 没有参数，模型没有出错的空间。
  • 只读：它不能改文件、发消息或花钱。
  • 容易核对：跟自己屏幕上的时钟比较即可。
  • 即时有用：它修正了代理每一个与日期有关的答案。
