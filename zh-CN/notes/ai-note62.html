如何在做预测之前先看你的销售数据（预测，版本 1）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 4 分钟阅读

这是预测系列的第 1 个版本。这个系列一小步一小步地搭建一个程序，用过去的销售额预测未来的 销售额。版本 1 完全不含 AI。它读入一个装着每日销售额数字的文件，画出一张折线图。 这是刻意的：在电脑能够预测任何事情之前，你必须先看看你要求它学习的数据。

数据从哪里来？

程序读入一个叫 time_series.csv 的文件。CSV 文件是一个纯文本表格：每一行是 一行数据，一行里的各个值用逗号分隔。这个文件有两列，time 和 series，共 4 × 365 = 1,460 行 — 每天一行，大约四年的每日 销售额，以港币计。 

time,series
1.0,29.395714
2.0,33.40659
3.0,37.858486
4.0,29.14184

日期编号写成 1.0、2.0 这样，而不是 1、 2：.0 把它们标记为小数（浮点数），和销售额数字是同一种数， 所以整个文件使用统一的数字格式。

像这样按时间顺序排列的一串数字，叫做时间序列，文件名由此而来。预测， 就是用这样一段记录的前一部分，去预测接下来出现的值。

程序怎样运作

1. 载入两个库

import pandas as pd
import matplotlib.pyplot as plt

pandas 是读表格的库，给它一个短名 pd，让代码保持紧凑。 matplotlib 是画图表的库，它的绘图部分被命名为 plt。这两行 都是几乎每个数据程序里都会看到的惯例。

2. 把文件读进一张表

df = pd.read_csv('time_series.csv')
series = df['series'].values

第一行把 CSV 文件读进 df，一个 DataFrame — pandas 对带列名的表格的叫法。第二行按名字取出一列，df['series']，而 .values 剥掉表格的外衣，只留下裸的数字：1,460 个销售额数字排成一行， 可以直接画出来，或者拿去计算。

注意程序对 time 这一列做了什么：什么也没做。在这个文件里，行已经按时间 顺序排好，所以一个数字在列表里的位置就是它的时间。下面的图只是画出第 1 天、第 2 天、 第 3 天，依此类推。

3. 画出图表

plt.plot(series)
plt.title('Sales per day')
plt.xlabel('Day')
plt.ylabel('Sales-HK$')
plt.grid(True)
plt.show()

plt.plot(series) 用一条线穿过全部 1,460 个数字。接下来三行加的是收尾的 点缀：plt.title('Sales per day') 是标题，plt.xlabel('Day') 是横轴下方的标签，plt.ylabel('Sales-HK$') 是纵轴旁边的标签。 plt.grid(True) 加上浅色的背景线，让读数更容易。

最后一行，plt.show()，才是真正把窗口放到你屏幕上的那一行。

你应该会看到什么

一个窗口打开，里面有一条从左往右爬升的线：销售额从每天约 HK$30 开始，最后接近 HK$160，中间有小幅的起伏。

在任何预测开始之前，有两件事值得注意。第一，这个序列有向上趋势 — 后面的日子系统性地高于前面的日子。第二，这些起伏是趋势周围看起来 随机的噪声。之后的版本必须同时处理这两个事实，而亲眼看到它们，正是先画这张图 的理由。

完整程序

把上面的各部分放回一起。这就是完整的文件，一共 10 行： 

import pandas as pd
import matplotlib.pyplot as plt
df = pd.read_csv('time_series.csv')
series = df['series'].values
plt.plot(series)
plt.title('Sales per day')
plt.xlabel('Day')
plt.ylabel('Sales-HK$')
plt.grid(True)
plt.show()

在自己的电脑上运行

下载 zip 文件，解压到 一个文件夹。zip 里有 time_01.py、time_series.csv 数据文件， 以及 pyproject.toml。在 Visual Studio Code 中打开文件夹，然后在终端输入 这三行： 

uv python pin 3.12.10
uv sync
uv run time_01.py

第一行记录这个文件夹用哪个 Python 版本，第二行安装 pyproject.toml 列出的 每一个包。第三行打开图表窗口；关闭它以让程序结束。

这三行只需要一次。下次想再运行程序，只输入 uv run time_01.py。

如果你还没有设置 uv，先看 如何安装 Visual Studio Code？，然后看 uv 笔记的 Windows 或 Mac。
