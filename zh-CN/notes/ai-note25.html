如何在 username.github.io 创建一个免费网站？

林邦源博士 · AI 笔记 · 2026 年 11 月 6 日 · 约 5 分钟阅读

你可以用 GitHub Pages 免费把一个网站放上互联网。 GitHub 是一个让人存放和分享程序代码的网站；GitHub Pages 是一项免费服务， 可以把你其中一个程序代码文件夹变成一个真正的网站。网站的地址是 username.github.io，其中 username 是你注册 GitHub 时选择的名称。不需要信用卡，也没有月费。

这篇笔记会带你走完整个过程，由开立 GitHub 账户，到看见自己的第一个网页上线， 全程只需要用浏览器打开 GitHub 网站 — 无需安装任何额外软件。

开始之前你需要什么

  • 一个你可以即时查看的 电邮地址（GitHub 会发送验证码给你）。
  • 一个你喜欢的 用户名称（username） — 它会成为你网址的一部分， 所以要小心选择。GitHub 的用户名称只可以包含英文字母、数字和连字符（-）； 不可以有下划线或空格。

第 1 步：注册 GitHub 账户

前往 github.com ，然后按 Sign up。GitHub 会要求你输入：

  • 你的 电邮地址。
  • 一个 密码。
  • 一个 用户名称。这是最重要的选择，因为它会成为你网站的地址。 如果你选择 pongyuenlam，你的网站就会是 pongyuenlam.github.io。

按 Create account。

第 2 步：验证你的电邮

GitHub 会发送一个简短的数字验证码到你的电邮地址。在 GitHub 页面输入这个验证码， 证明你拥有这个电邮。之后你就可以登入新账户了。

第 3 步：创建名为 username.github.io 的储存库

储存库（repository）是 GitHub 对项目文件夹的称呼。 要创建个人网站，储存库的名称有一个非常严格的规定：它必须完全等于你的 GitHub 用户名称再加上 .github.io。

在 GitHub 上，按你的头像，然后选择 New repository。 在 Repository name 字段输入： 

username.github.io

把 username 换成你真正的 GitHub 用户名称。例如，如果你的用户名称是 pongyuenlam，储存库名称就必须是 pongyuenlam.github.io。 如果名称和你的用户名称不完全一样，免费网址就不会生效。

其他设置保持不变，然后按 Create repository。

第 4 步：创建 index.html 文件

网站是由文件组成的。访客看到的第一页永远叫 index.html。 在你的新储存库页面，按 creating a new file。

在要求输入文件名称的方框中，输入： 

index.html

然后，在下方较大的编辑区域，输入一个简单的网页。以下是一个你可以复制和修改的小例子： 

<!DOCTYPE html>
<html>
<head>
  <title>My Website</title>
</head>
<body>
  <h1>Hello, world!</h1>
  <p>This is my first website on GitHub Pages.</p>
</body>
</html>

第 5 步：提交（储存）文件

在页面底部，按 Commit changes。GitHub 会要求你确认提交； 再按一次 Commit changes。Commit（提交）是 GitHub 对储存文件某个版本的称呼。

第 6 步：等候并查看你的网站

GitHub 需要一点时间来发布你的网页。开启一个新的浏览器分页，前往： 

https://username.github.io

同样，把 username 换成你真正的用户名称。通常需要大约 一至两分钟页面才会出现。如果一开始看到错误，请再等一会，然后刷新页面。

日后如何编辑你的网站

要修改网页，请回到你的储存库，按 index.html 文件， 然后按铅笔图标（Edit this file）。作出修改，滚动到页面底部， 按两次 Commit changes。等候约一至两分钟，刷新 username.github.io，更新后的网页就会出现。要刷新，请在 Mac 上按 Cmd + R，或在 Windows 上按 Ctrl + R， 又或者按浏览器网址列上的圆形刷新图标。

之后你可以做什么

  • 新增更多页面。在同一个储存库创建更多 .html 文件， 例如 about.html，并在 index.html 中加入链接指向它们。
  • 加入图片。把图片文件上传到储存库，然后用 <img> 标签在网页上显示。
  • 使用现成的设计。搜索「GitHub Pages themes」， 无需自己撰写所有样式，也能让网站看起来更精美。

限制

  • 储存库名称必须是 username.github.io。 如果不一样，GitHub 就不会在该地址发布网站。
  • 每次提交后，网站需要一至两分钟才会更新。 如果看不到你的改动，请等候并刷新。
  • GitHub Pages 是为静态网站而设 — 由 HTML、CSS 和图片组成的页面。 它本身不能执行数据库或服务器端程序。如果你已经有一个使用数据库或服务器端程序的网站， 你可以简单地在 username.github.io 的某个页面加入链接指向它。
