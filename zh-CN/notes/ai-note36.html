如何为 AI 代理创建天气工具？

林邦源博士 · AI 笔记 · 2026 年 11 月 8 日 · 约 4 分钟阅读

AI 代理无法走到户外，也不知道你身在何处。天气工具用一次调用同时解答这两个 问题。互联网上每台设备都有一个号码，称为 网际协议（IP）地址，而这个 号码登记在某个地区，所以一个查询服务可以把它转成大约的位置 —— 只到城市， 不会到街道。工具接着向免费天气服务查询该城市当前的气温。两个服务都无需 注册或密钥。

工具

这是 tool02_weather.py 目前的内容：

# https://open-meteo.com/
import requests
def get_weather_from_ip():
    """
    Get the current temperature in Celsius for the user's location
    using the IP address and return it as a string.
    """
    location = requests.get("https://ipinfo.io/json", timeout=10).json()
    latitude, longitude = location["loc"].split(",")

    params = {
        "latitude": latitude,
        "longitude": longitude,
        "current": "temperature_2m",
        "temperature_unit": "celsius",
        "timezone": "auto",
    }

    weather_data = requests.get(
        "https://api.open-meteo.com/v1/forecast",
        params=params,
        timeout=10,
    ).json()

    return f"Current: {weather_data['current']['temperature_2m']}°C"

result = get_weather_from_ip()
print(result)

每一部分的作用

  • requests 是这里唯一的外部库，并不属于 Python 本身。它 列在项目的 pyproject.toml 内，所以 uv sync 会替 你安装。
  • 第一次请求去 ipinfo.io。它返回一个小的 JSON 对象： 纯文本，把数据存成一个一个有标签的值，例如 {"city": "Hong Kong"}，程序可以逐个字段读取。loc 把纬度和经度存成一个字符串，"22.3193,114.1694"，所以程序用逗号 把它分开。
  • 这个位置来自对外 IP 地址，所以只准确到城市，不会到街道。对天气问题来说 已经足够。这个请求也会把你的对外 IP 地址送到 ipinfo.io，那是唯一离开你 电脑的个人资料。
  • 第二次请求去 Open-Meteo。params 让问题变得 精确：只要当前状况、离地两米的气温、以摄氏表示，时区则取自坐标。
  • timeout=10 出现两次。没有它，网络一慢，代理就会一直等不到 答案。有了它，每次请求十秒后就放弃，并抛出错误，而不是卡住。
  • 函数返回的是一句话，不是 JSON 对象：Current: 24.6°C。 模型得到的是可以直接引用的文字。
  • 最后两行调用函数并打印结果，让你在还未牵涉任何代理之前，就可以在终端 检查这个工具。

在自己的电脑上运行

下载 zip 文件并 解压到一个文件夹。zip 内有 tool02_weather.py、 pyproject.toml 和 README.md。在 Visual Studio Code 打开这个文件夹，然后在终端运行以下两条命令： 

uv sync
uv run tool02_weather.py

uv sync 只需要第一次运行。它会创建一个本地环境，只装这个项目 需要的一个包，不会装到电脑其他地方。

你应该会看到一行，例如 Current: 24.6°C。跟你手机上的天气应用 比较一下。

如果这一行始终没有出现，原因几乎总是以下三种之一：没有连接互联网、IP 地址 被 ipinfo.io 限制了请求频率，或者 Open-Meteo 短暂无法提供服务。两个服务对 轻量使用都是免费的，这也是它们适合课堂的原因；但免费也意味着没有正常运行 时间的保证。

为什么这是好的起步工具

  • 只读：它读取公开数据，不会改动任何东西。
  • 容易核对：任何天气应用都可以给你第二个意见。
  • 即时有用：“要带伞吗？”变成代理可以用事实回答的问题。

延伸阅读

  • Open-Meteo —— 接口文档 —— 可以请求的当前、每小时与每日变量完整清单。
  • ipinfo.io —— 开发者文档 —— 位置响应中的各个字段，以及没有密钥时的请求频率限制。
  • requests —— 文档 —— HTTP 调用的超时、参数与错误处理。
