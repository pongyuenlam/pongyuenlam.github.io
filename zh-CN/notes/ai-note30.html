如何在 Google Search Console 验证你的网站？

林邦源博士 · AI 笔记 · 2026 年 11 月 10 日 · 约 5 分钟阅读

Google Search Console 是 Google 免费提供的工具，让你看到网站在 Google 搜索中的表现：Google 找到了哪些页面、哪些搜索词带来访客、有没有页面出了问题。 不过，在 Google 让你看到这些数据之前，你必须先验证网站 —— 也就是向 Google 证明这个网站真的是你的。只有网站的所有者，才可以看到它的私密搜索数据。

这篇笔记会逐步说明 HTML 文件上传方法，本站用的也正是这个方法。只要你能把 一个文件放到网站的最上层文件夹，这个方法就适用 —— 包括像 如何在 username.github.io 创建一个免费网站？ 那样的免费 GitHub Pages 网站。

开始之前，你需要准备什么

  • 一个 Google 账户（例如你用来收 Gmail 的同一个）。
  • 一个已经上线的网站，好让 Google 可以访问它。
  • 能把一个文件放到该网站最上层文件夹的权限。在 GitHub Pages 上， 你的网站存放在一个名为 username.github.io 的仓库 （repository，即 GitHub 对项目文件夹的称呼）—— 例如本站就存放在 pongyuenlam.github.io 这个仓库。所谓“最上层文件夹”，就是你在 GitHub 打开该仓库时看到的第一页：也就是 index.html 所在的位置。验证文件要放在 index.html 旁边，而不是任何子文件夹里。

一句话说清楚

Google 给你一个名字又长又独特的很小的文件；你把文件放到网站的最上层文件夹；Google 访问那个网址并找到文件。这个文件不是秘密 —— 一旦放到网上，任何人 都可以读取 —— 但只有控制这个网站的人，才能把它放到那里，所以 Google 找到它， 就证明网站是你的。

第 1 步：在 Search Console 添加你的网站

前往 search.google.com/search-console 并登录。点击 Add property（添加资源），选择 URL prefix （网址前缀）选项。输入网站的完整网址，例如： 

https://username.github.io

把 username 换成你自己的 GitHub 用户名。

第 2 步：选择 HTML 文件方法

Search Console 提供几种验证方式。选择 HTML file（HTML 文件）。Google 会给你一个名字又长又随机的文件，例如： 

googlexx...html

点击按钮把它下载。不要更改文件名，也不要改动里面的内容。如果你打开它， 会看到里面只有一行文字，类似： 

google-site-verification: googlexx...html

第 3 步：把文件放到网站上

文件必须放在网站的最上层文件夹，这样它的网址才会是： 

https://username.github.io/googlexx...html

要在 GitHub 找到那个最上层文件夹，先打开 github.com/username。这是你的 个人主页 —— 它只会列出你的仓库，不会显示任何文件， 所以你在那里找不到验证文件。点击 username.github.io 仓库。你现在看到的 第一页 —— 那个包含 index.html 的文件列表 —— 就是最上层文件夹。

在该页用 Add file → Upload files 把验证文件放到 index.html 旁边，然后提交更改。之后照惯例等一两分钟，让网站更新。

第 4 步：检查文件是否可以访问

打开一个新的浏览器标签页，访问 https://username.github.io/googlexx...html （换成你自己的用户名和文件名）。如果你看到第 2 步那一行文字，文件就放对了位置。 如果看到“404 not found”错误，等一分钟再刷新，或者检查文件是否真的在最上层文件夹， 而不是在子文件夹里。

第 5 步：点击“验证”

回到 Search Console，点击 Verify（验证）。Google 会访问该网址、找到文件， 确认你是所有者。验证立即完成。

之后不要把文件删掉

Google 会不时重新检查该文件。如果你删除它或更改它的名称，Google 可能判断你不再是所有者， 你查看 Search Console 数据的权限就会中止。这个文件非常小 —— 让它留在原处就好。 例如本站至今仍把验证文件（googlexx...html）留在最上层文件夹，正是这个原因。

顺带一提

  • 验证是免费的，而且只需成功一次。
  • 单靠 Google Analytics 标签并不能验证你的网站。
  • 验证之后，在 Search Console 提交你的 sitemap.xml，请 Google 查看你的页面。
