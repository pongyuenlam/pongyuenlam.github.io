如何在每一格画面上画框和标签（人脸识别，版本 6）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 4 分钟阅读

版本 5 证明了帧在显示之前可以被修改。版本 6 用这一步来画：一个红色矩形和一行字 "This is a test"，固定在画面上的同一个位置。这个框还不跟着任何东西。它在这里， 是为了版本 7 有地方放它的结果：框会移到人脸上，那行字会变成名字。

角在哪里

图像没有左下角的原点。位置以像素计算，从左上角算起：x 向右增大，y 向下增大。这和数学里画的坐标图相反，也是框 出现在意料之外的地方最常见的原因。

程序怎么运作

1. 打开摄像头，读一帧

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()

和版本 4 一样。循环每一轮都在 img 里给出一帧新的画面，这也让画图变得安全： 现在画上去的东西会随着这一帧一起消失，下一帧来的时候是干净的。

2. 选定两个角

    x1, y1 = 100, 200
    x2, y2 = x1 + 200, y1 + 150

第一行是左上角：距左边 100 像素，距顶部 200 像素。第二行用尺寸而不是位置算出右下角： 宽 200 像素、高 150 像素，得到 (300, 350)。这样写，以后改尺寸很方便。

3. 画矩形

    cv2.rectangle(img, (x1, y1), (x2, y2), (0, 0, 255), 2)

参数是图像、两个角、颜色和线宽。颜色是按 BGR 顺序的三个数，不是 RGB： (0, 0, 255) 是没有蓝、没有绿、全红。最后的 2 是线宽，单位像素； 数字更大，框的边就更粗。

4. 写标签

    cv2.putText(img, "This is a test", (x1, y1 - 10), cv2.FONT_HERSHEY_DUPLEX, 1, (0, 0, 255), 2)

七个参数，顺序是：图像、文字、位置、字体、大小、颜色、线宽。位置是文字的 左下角，不是左上角，所以 y1 - 10 把字抬到框的上边之上十个 像素，而不是让它压在框上。

cv2.FONT_HERSHEY_DUPLEX 是 OpenCV 内置的几种简单字体之一，1 是大小倍数，写 2 就会大一倍。颜色和线宽的意思和画矩形时一样。

5. 显示，然后退出并收拾

    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

cv2.imshow 现在收到的是 img — 画过的那一帧 — 所以框出现在窗口里。按键和收尾都和版本 4 一样。

完整程序

把上面的片段拼回去。这是完整的文件，一共 14 行： 

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    x1, y1 = 100, 200
    x2, y2 = x1 + 200, y1 + 150
    cv2.rectangle(img, (x1, y1), (x2, y2), (0, 0, 255), 2)
    cv2.putText(img, "This is a test", (x1, y1 - 10), cv2.FONT_HERSHEY_DUPLEX, 1, (0, 0, 255), 2)
    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

画图改的是帧本身

版本 5 另外做了一个变量，原来的那个没有动。这个版本不一样： cv2.rectangle 和 cv2.putText 直接改 img，不返回任何有用的东西。没有 img_with_box。

在这里这没有害处，原因只有一个：每一轮结束时这一帧就被丢掉，循环开头会换成新的一帧， 所以框每帧画一次，画在干净的画面上。它不会越积越多。如果你改成在一张保存下来的照片上画， 再写回硬盘，那么每运行一次就会多留下一个框。

移动这个框

改 100, 200，框就移动；改 200, 150，框就改变大小。超出画面的 数值不是错误：框落在画面外的部分只是不画出来。这一点在版本 7 把贴着画面边缘的框交给 程序之前，值得先知道。

在自己的电脑上运行

用和版本 1 相同的下载： 下载压缩包，解压， 然后用 Visual Studio Code 打开这个文件夹。这一篇用的是 face06.py。 第一次在这个文件夹里，运行全部三行： 

uv python pin 3.12.10
uv sync
uv run face06.py

这三行只需要做一次。下次想再运行这个程序，只需输入 uv run face06.py。

视频靠左上的位置应该有一个红色的框，上面写着 "This is a test"。如果框跑到画面外， 检查你改的是哪一个角：y1 大于画面高度，框就被推到下面外面去了。

下一步

版本 7 在这个循环里做版本 3 的工作：它在每一帧里找出人脸，把框画在人脸外面而不是固定位置， 并把识别出的名字放到现在测试标签的位置。
