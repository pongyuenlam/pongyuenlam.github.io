如何用冒号缩短切片（预测，版本 5）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 4 分钟阅读

这是预测系列的第 5 个版本。和版本 4 相比，改动只有两行，它们用简写产生同样的特征与目标值。

一个看不见任何改变的版本仍然值得写下来，因为这种简写几乎会出现在你之后读到的每一个 Python 程序里，也常常出现在其他开发者写的 Python 程序里。一次学会读懂它，以后就少困惑很多次。

同一件事的两种说法

版本 4 是这样写全的： 

row_n = windows.shape[0]
col_n = windows.shape[1]
features = windows[0:row_n, 0:col_n-1]
targets = windows[0:row_n, col_n-1:col_n]

版本 5 用简写说同一件事： 

features = windows[:, :-1]
targets = windows[:, -1:]

长写法的每一部分都还在，只是被隐含了。
0:row_n 意思是每一行，所以变成了一个单独的 :。
0:col_n-1 意思是除了最后一列之外的所有列，所以变成了 :-1。
而 col_n-1:col_n 意思是只有最后一列，所以变成了 -1:。

怎样读一个冒号和一个负一

1. 一个单独的冒号表示「全部」

windows[:, :-1]

方括号里有两个位置，用逗号隔开：行在前，列在后。行位置上的那个单独冒号表示取每一行， 所以 1,431 个例子全都留下来。

2. 负一从末尾开始数

windows[:, :-1]
windows[:, -1:]

负数是从后往前数的：-1 是最后一项，-2 是它前面那一项。所以 :-1 意思是从开头一直到最后一列之前，但不包括最后一列 — 也就是 29 个已知的日子。而 -1: 意思是从最后一列到末尾 — 也就是要预测的 那单独一天。

3. 文件其余部分没有改动

读取 CSV、转换成张量、建立数据集和加载器，以及打印四个计数和三个例子 — 这些都和版本 4 完全一样。只有函数里面那两行切片改变了。

你应该会看到什么

Series length: 1460
Number of windows: 1431
Feature shape: torch.Size([1431, 29])
Target shape: torch.Size([1431, 1])

和之前一样的四个数字，以及跟在后面的同样的三个例子窗口。

完整程序

把上面的各部分放回一起： 

import torch
from torch.utils.data import TensorDataset, DataLoader, Subset
import pandas as pd
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    features = windows[:, :-1]  # All columns except the last
    targets = windows[:, -1:]   # Just the last column
    return features, targets

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
# Create PyTorch Dataset and DataLoader
dataset = TensorDataset(features, targets)
batch_size = 32
train_loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

# Print some information about the dataset
print(f"Series length: {len(series)}")
print(f"Number of windows: {len(features)}")
print(f"Feature shape: {features.shape}")  # Should be (num_windows, window_size-1)
print(f"Target shape: {targets.shape}")    # Should be (num_windows, 1)

# Show a few examples
print("\nFirst few windows:")
for i in range(3):
    print(f"\nWindow {i+1}:")
    print(f"Features (previous {window_size-1} days): {[f'{x:.2f}' for x in features[i].numpy()]}")
    print(f"Target (next day): {targets[i].item():.2f}")

在自己的电脑上运行

下载 zip 文件并解压到一个 文件夹。zip 里有这个系列到目前为止的程序、time_series.csv 数据文件，以及 pyproject.toml。这篇笔记用的是 time_05.py。在 Visual Studio Code 中打开文件夹，然后在终端输入这三行： 

uv python pin 3.12.10
uv sync
uv run time_05.py

第一行记录这个文件夹用哪个 Python 版本，第二行安装 pyproject.toml 列出的每一个 包。第三行打印和版本 4 相同的四个计数和三个例子。

这三行只需要一次。下次想再运行程序，只输入 uv run time_05.py。

如果你还没有设置 uv，先看 如何安装 Visual Studio Code？，然后看 uv 笔记的 Windows 或 Mac。
