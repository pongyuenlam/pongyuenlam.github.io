如何用 AI 实时为你涂上口红？

林邦源 · AI 笔记 · 2026年11月1日 · 阅读时间约 7 分钟

English 繁體中文 简体中文

本文把前两篇合而为一。从 〈如何从摄像头获取实时画面？〉借来摄像头循环， 从 〈如何用 AI 为你涂口红？〉借来口红。 成果是 35 行代码，让一张动态的脸带着樱桃红的嘴唇出现在屏幕上。

唯一的新概念是：嘴唇要在每一帧中重新寻找。找出、上色、显示；然后下一帧到来， 同样三个步骤再重复一次。因为每次上色只需几分之一秒，你的脸看起来就像一直涂着口红。

为什么这个程序比照片版本长

口红那篇是 14 行，这篇是 35 行。口红逻辑本身没有变：同样的 12 个嘴唇关键点、 同样的樱桃红、同样的填色。变长的是实时处理（而非处理文件）的代价。

  • 需要循环。照片只需打开一次。摄像头会不断送来一帧又一帧画面， 所以程序需要一个循环、一个显示每帧的方法、一个停止的方法，以及一个释放摄像头的方法。
  • 速度至关重要。处理一张照片可以花整整一秒；一帧画面不行， 否则下一帧已经迟到，视频就会卡顿。这就是为什么要在缩小四分之一的副本上找脸， 再把关键点放大回原尺寸。
  • 没有文件可以直接画。照片那篇使用 ImageDraw， 一行就能用半透明颜色填满形状。实时画面在内存中是一格格的数字， OpenCV 没有对等的一行填色指令，所以要先建立掩码（mask），再把颜色混进去。
  • 两种颜色顺序。OpenCV 的颜色是蓝色在前；AI 库要的是红色在前。

所以多出来的行数，都是为了跟上了一张移动中的脸。

程序如何运行

1. 加载三个库

import cv2
import face_recognition
import numpy as np

cv2 是 OpenCV：负责读取摄像头、调整每帧大小、转换颜色顺序， 并把画面显示出来。face_recognition 找出人脸及其关键点—— 也就是标示嘴唇的点。np 是 NumPy（Numerical Python）， 它能用一行对整个像素网格做算术——这里非它不可，否则逐个像素混合颜色、每秒 35 次， 会慢得无法接受。

2. 选择颜色和三个设置

color_lip = (40, 20, 190)
strength = 120 / 255
small = 0.25

color_lip 是樱桃红，来自口红那篇。在那里，这个红色按红、绿、蓝顺序写成 (190, 20, 40)。OpenCV 存储颜色的顺序相反——蓝、绿、红——所以同一种颜色 在这里写成 (40, 20, 190)。

strength 是口红的显色强度：120 除以 255，约 0.47。每个嘴唇像素变成 47% 樱桃红加 53% 原本颜色，所以你原本的嘴唇仍然能透出来。

small 是速度设置。找人脸是这个程序最慢的部分，所以在缩小到宽高各四分之一的 副本上进行。一帧 1920 × 1080 的画面会以 480 × 270 来搜索，像素少了 16 倍。 没有这个技巧，每帧都要花太长时间处理，视频就会卡顿而不流畅。

3. 打开摄像头并读取一帧

cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    if not ret:
        break

cv2.VideoCapture(0) 连接电脑上第一个摄像头。cap.read() 返回两样东西： ret（return）表示有没有成功取得帧，img（image）是帧本身。 如果没有帧送达，ret 就是 False，于是 not ret 为 True。这种情况在摄像头被拔掉或被其他程序占用时会发生。 break 就停止循环，而不是对着空帧继续运算。

4. 在缩小副本中找脸

small_img = cv2.resize(img, (0, 0), fx=small, fy=small)
rgb_small_img = cv2.cvtColor(small_img, cv2.COLOR_BGR2RGB)
face_landmarks_list = face_recognition.face_landmarks(rgb_small_img)

cv2.resize 制作缩小四分之一的副本；fx 和 fy 分别是宽度和高度的缩放倍数。

cv2.cvtColor 把颜色顺序从蓝绿红翻转成红绿蓝。face_recognition 是按红色在前的顺序训练的，所以它预期这个顺序；直接喂给它 OpenCV 的顺序，脸仍然找得到， 但它赖以判断的颜色是错的。cvtColor 是 convert color（转换颜色）的缩写。

face_landmarks 返回一个列表，每找到一张脸就有一个条目，每个条目包含 top_lip、bottom_lip、眉毛、眼睛等的关键点。

5. 在嘴唇位置画上白色掩码

mask = np.zeros(img.shape[0:2], dtype=np.uint8)
for face_landmarks in face_landmarks_list:
    for lip in ['top_lip', 'bottom_lip']:
        points = (np.array(face_landmarks[lip]) / small).astype(np.int32)
        cv2.fillPoly(mask, [points], 255)

掩码（mask）是一张与帧同尺寸的黑白图：白色标示口红要涂的位置， 黑色标示不涂的位置。np.zeros 一开始把它全部填黑， img.shape[0:2] 取出帧的高和宽作为它的尺寸。

两层循环处理每一张脸，以及每张脸的两片嘴唇。关键点是在缩小副本上找到的， 所以要除以 small，把它们映射回完整帧：100 的点变回 400。 astype(np.int32) 把它们保留为整数像素，因为 OpenCV 无法填满 角点落在像素之间的形状。

cv2.fillPoly 然后把每片嘴唇的轮廓填上 255，即最亮的值。由于上唇和下唇的 关键点同时沿着口腔的外缘和内缘走，白色区域只盖住嘴唇而不会盖住牙齿。

6. 柔化边缘

mask = cv2.GaussianBlur(mask, (7, 7), 0)

没有这一行，掩码会在嘴唇边缘从白色直接跳到黑色，口红看起来就像用剪刀剪出来的。 模糊化把每个像素与它 7 × 7 范围内的邻近像素混合，让边缘淡出。 效果读起来像化妆，而不是一块填色形状。

7. 把颜色混进帧

alpha = (mask / 255 * strength)[:, :, None]
img = (img * (1 - alpha) + np.array(color_lip) * alpha).astype(np.uint8)

alpha 是什么。alpha 就是掩码换算成 0 到 1 之间的数字。 除以 255 把纯白（255）变成 1、纯黑（0）变成 0；再乘以 strength 把白色降到 0.47。所以在嘴唇上 alpha 是 0.47，远离嘴唇是 0，模糊出来的灰色边缘 落在两者之间。 

img.shape                      # (1080, 1920, 3)   rows, columns, colour values
alpha.shape                    # (1080, 1920)      rows, columns
alpha[:, :, None].shape        # (1080, 1920, 1)   rows, columns, 1

从帧说起。取一帧宽 1920 像素、高 1080 像素的画面——这是一般摄像头 全高清（full HD）的标准尺寸。NumPy 把它存储为 (1080, 1920, 3)：1080 行、 每行 1920 个像素、每个像素 3 个数字——分别是蓝、绿、红。

再看 alpha。它的形状是 (1080, 1920)：1080 行、1920 列， 每个像素只有一个数字，没有颜色分量。

None 加了什么。方括号里有三个部分，由两个逗号分隔： 第一个 : 取所有行，第二个 : 取所有列，None 则加上恰好容纳 1 个数字的第三层。形状变成 (1080, 1920, 1)。

为什么这样就够。NumPy 对形状不符有一条固定规则：哪一边是 1， 就把那个值重复到与另一边匹配。所以 1 会被拉长成 3，每个像素的单一数字被使用三次—— 蓝、绿、红各一次。

最后一行。它把同一条公式一次性套用到帧的每个像素： 新像素 = 旧像素 × (1 − alpha) + 樱桃红 × alpha。在嘴唇上， alpha 是 0.47，所以每个像素变成 53% 原本的嘴唇加 47% 樱桃红——你嘴唇天然的明暗 仍然透出来，这正是效果读起来像化妆而非油漆的原因。远离嘴唇的地方 alpha 是 0， 原像素原封不动地通过。

8. 显示帧，按 q 或 Q 停止

cv2.imshow("Frame", img)
key = cv2.waitKey(1)
if key in (ord('q'), ord('Q')):
    break
cap.release()
cv2.destroyAllWindows()

cv2.imshow 把完成的帧显示在窗口中。cv2.waitKey(1) 等待一毫秒看有没有按键，然后返回所按按键的代码，没有按键就返回 -1。 如果代码是 q 或 Q，循环结束并释放摄像头，其他程序就能使用它， 摄像头指示灯也会熄灭。

按 q 之前，先点击视频窗口内部；按键信号会送往目前选中的窗口， 而你在 Visual Studio Code 按运行后，选中的通常是终端。双键退出的方法也行： 在终端同时按 Ctrl 和 C。

完整程序

把上面的部分拼回来。这就是完整的文件，一共 35 行： 

import cv2
import face_recognition
import numpy as np
# Cherry red from face04_lip.py: (red, green, blue, see-through)
# OpenCV uses blue-green-red order, so the color is written backwards
color_lip = (40, 20, 190)
strength = 120 / 255          # how strong the lipstick is: 0 = none, 1 = solid
small = 0.25                  # look for the face in a picture 1/4 the size, so the video is fast
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    if not ret:
        break
    # face_recognition uses red-green-blue order, OpenCV uses blue-green-red
    small_img = cv2.resize(img, (0, 0), fx=small, fy=small)
    rgb_small_img = cv2.cvtColor(small_img, cv2.COLOR_BGR2RGB)
    face_landmarks_list = face_recognition.face_landmarks(rgb_small_img)
    # Mask: white where the lips are, black everywhere else
    mask = np.zeros(img.shape[0:2], dtype=np.uint8)
    for face_landmarks in face_landmarks_list:
        for lip in ['top_lip', 'bottom_lip']:
            # The landmarks were found on the small picture, so make them 4 times bigger
            points = (np.array(face_landmarks[lip]) / small).astype(np.int32)
            cv2.fillPoly(mask, [points], 255)
    # Soften the lip edges
    mask = cv2.GaussianBlur(mask, (7, 7), 0)
    # Mix the lip color into the picture where the mask is white
    alpha = (mask / 255 * strength)[:, :, None]
    img = (img * (1 - alpha) + np.array(color_lip) * alpha).astype(np.uint8)
    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

在自己的电脑上运行

下载 zip 文件并解压到 一个文件夹。这个 zip 包含本系列的六个程序；本文使用 face06.py。 这个程序不需要在文件夹里放照片。在 Visual Studio Code 中打开文件夹，然后在终端 输入以下三行： 

uv python pin 3.12.10
uv sync
uv run face06.py

如果你还没有设置 uv，请先阅读 〈如何安装 Visual Studio Code？〉， 然后是 Windows 或 Mac 的 uv 笔记。

两个实际提醒。第一，电脑越快视频越流畅；在较旧的笔记本电脑上，找脸的频率较低， 口红可能会比你的嘴部动作慢半拍。第二，程序会为它找到的每一张脸涂上 红唇——包括坐在你后面的人。在你为课堂或会议录像之前，这一点值得知道。
