Python 程序如何用 DeepSeek API？

林邦源 · AI 笔记 · 2026年11月3日 · 阅读时间约 5 分钟

English 繁體中文 简体中文

与 AI 模型对话，不一定要通过浏览器。程序可以通过互联网向 DeepSeek 发出消息，然后收到一段文字回复，随即可打印、保存，或交给更大程序的下一步处理。 程序就是这样获取 AI 答案，而无需人工从聊天窗口复制粘贴。

本文的程序向 DeepSeek 提出 “What is the traditional Chinese for Hong Kong?”这个问题，并打印回复，全程只用 21 行。

先获取密钥

DeepSeek 需要知道谁在提问，所以程序要出示一个 API 密钥：一串像密码 一样的保密字符。API 是 Application Programming Interface（应用 程序接口）的缩写，即程序之间通过互联网沟通的方式。要获取密钥，请到 https://platform.deepseek.com/ 注册；少量余额已足够试用，密钥可在 API keys 页面创建。

密钥绝不能直接写进程序里，否则任何读到代码的人都能拿走它。密钥应放在同一文件夹内 一个名为 .env 的小文件中，里面只有一行： 

DEEPSEEK_API_KEY=paste-your-key-here

下载示例程序后，请自行创建这个文件；zip 内并不包括它，因为密钥属于个人。

逐段拆解程序

import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

这里引入了三个库。os 是 operating system（操作系统） 的缩写；在这里用来读取环境变量，即存放在代码以外的设置。load_dotenv 读取 .env 文件，把每一行复制到那些环境变量之中。 OpenAI 是 openai 软件包的连接器。它以另一家 AI 公司命名，但 DeepSeek 特意采用相同的消息格式，所以同一个连接器两者都适用：你只需 更改它连接的地址。 

client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",
)

这里创建连接器。os.environ.get("DEEPSEEK_API_KEY") 读取 load_dotenv() 刚才从 .env 加载的密钥，而 base_url 是 DeepSeek 服务的互联网地址。从此连接器发出的每个请求 都会发送到该地址并带着密钥，DeepSeek 便知道请求来自哪个账户。 

response = client.chat.completions.create(
    model="deepseek-flash",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is the traditional Chinese for Hong Kong?"},
    ],
    stream=False,
)

这里发送问题并等待回复。model="deepseek-flash" 选定由哪个 DeepSeek 模型作答；DeepSeek 的文档会列出最新的模型名称，它们会随时间改变。 messages 列表是迄今为止的对话：system 消息设定模型的 行为方式，user 消息则是实际的问题。stream=False 要求一次性获取整段回复，而不是逐字看着它到来。 

print(response.choices[0].message.content)

回复藏在响应包的几层之下。choices 是候选回复的列表——几乎总是只有 一个——所以 [0] 取出第一个，而 message.content 就是 它的文字。打印出来的正是这段文字。

完整程序

import os
from dotenv import load_dotenv
from openai import OpenAI

load_dotenv()

client = OpenAI(
    api_key=os.environ.get("DEEPSEEK_API_KEY"),
    base_url="https://api.deepseek.com",
)

response = client.chat.completions.create(
    model="deepseek-flash",
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "What is the traditional Chinese for Hong Kong?"},
    ],
    stream=False,
)

print(response.choices[0].message.content)

在自己的电脑上运行

下载 zip 文件并 解压到一个文件夹。这个 zip 包含程序和一个 pyproject.toml 项目文件。 请如上所示，加入你自己的 .env 密钥文件。然后在 Visual Studio Code 中 打开文件夹，在终端逐行输入以下三行： 

uv python pin 3.12.10
uv sync
uv run deepseek_chat.py

第一行记录这个文件夹使用哪个 Python 版本。第二行设置项目，并安装程序需要的两个软件包 openai 和 python-dotenv。第三行运行程序。几秒之后， 回复便会出现： 

The traditional Chinese for “Hong Kong” is **香港** — the same characters are used in both traditional and simplified Chinese.

- Cantonese: **Hoeng1 Gong2**
- Mandarin: **Xiānggǎng**

你运行时的措辞很可能不同，因为模型每次都会即时写出新的回复。

如果你还没有设置 uv，请先从 如何安装 Visual Studio Code？开始，然后看 uv 笔记： Windows 或 Mac。

局限

  • 它需要密钥和互联网。.env 里没有有效的密钥，或者 没有连接，程序都会因错误而终止。
  • 回复要花少许费用。DeepSeek 按处理的文字量收费。像这样的一条 问题只需一分钱的几分之一，但程序若提问数千条问题，累积起来也可观。
  • 回复不保证正确。模型写的是看似合理的文字，而非核实过的事实， 所以重要的答案仍需人工过目。给模型提供参考资料会有帮助；见下方的 RAG 笔记。
  • 模型名称会改变。deepseek-flash 是写作时的通用 名称；旧名称可能失效，有疑问时请查阅文档。
