如何用 Python 和 Flask 构建本地网站（版本 2）？

林邦源 · AI 笔记 · 2026年11月25日 · 阅读时间约 5 分钟

English 繁體中文简体中文

要快速让网站回应访客，可以添加文本框和按钮。输入名字，点击 Say Hello， 页面便会显示 Hello Howard 这样的问候语。

一个小型 Python 程序接收名字并返回问候语。页面和程序分别位于 templates/index.html 和 app.py。

开始前需要什么

  • Visual Studio Code，并可使用终端。如果尚未安装，请先看 如何安装 Visual Studio Code？
  • uv，用来安装 Flask 的工具： Windows 或 Mac。
  • 浏览器。你需要自行打开网址。

步骤 1：获取项目文件夹

下载 zip 文件并解压到一个文件夹。 内有 app.py、templates/index.html 和 pyproject.toml。 用 Visual Studio Code 打开该文件夹。

在终端记录这个文件夹使用的 Python 版本。这行只需执行一次：

uv python pin 3.12.10

然后安装 Flask，同样只需一次：

uv sync

步骤 2：查看 Python 程序

以下是 app.py 的全部程序：

from flask import Flask, render_template, request, jsonify
app = Flask(__name__)
@app.route("/")
def index():
    return render_template("index.html")
@app.route("/greet", methods=["POST"])
def greet():
    data = request.get_json()
    user_name = data.get("user_name", "")
    return jsonify({"greeting": f"Hello {user_name}"})

第一条路由把页面传给浏览器。第二条路由接收名字，把它接在 Hello 后面，再返回问候语。 每个 @app.route 行都把网址连接到下面的函数。

步骤 3：查看页面

这是 templates/index.html：

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Hello User</title>
</head>
<body>
    <h1>Hello User</h1>
    <input type="text" id="userName" placeholder="Your name">
    <button onclick="greetUser()">Say Hello</button>
    <p id="greeting"></p>
    <script>
        function greetUser() {
            const userName = document.getElementById("userName").value;
            fetch("/greet", {
                method: "POST",
                headers: {"Content-Type": "application/json"},
                body: JSON.stringify({user_name: userName})
            })
            .then(response => response.json())
            .then(data => {
                document.getElementById("greeting").textContent = data.greeting;
            });
        }
    </script>
</body>
</html>

文本框保存名字，按钮执行 greetUser()。脚本把名字传到 /greet， 接收答案，再放进按钮下方的段落。

步骤 4：运行程序

在终端输入：

uv run flask run

Flask 会自动寻找 app.py，通常每次都使用 5000 端口。 终端会显示页面网址： 

 * Debug mode: off
WARNING: This is a development server. Do not use it in a production deployment. Use a production WSGI server instead.
 * Running on http://127.0.0.1:5000
Press CTRL+C to quit

把 http://127.0.0.1:5000 复制并粘贴到浏览器的地址栏，或直接输入地址栏。输入名字并点击 Say Hello。 问候语会显示在按钮下方。

要停止服务器，请点击终端，然后同时按 Ctrl 和 C 两个键。 下次只需在终端输入 uv run flask run。

限制

  • 用户输入的名字不会保存。程序只用它生成一次问候语，然后便忘记。
  • 空白文本框会生成不完整的问候语。程序不会检查是否已输入名字。
  • 这是开发用服务器。Flask 的警告信息明确指出不要把它用于生产环境； 它用于在你自己的电脑上构建和试用应用程序。
