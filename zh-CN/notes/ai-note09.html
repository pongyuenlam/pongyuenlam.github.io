如何从摄像头获取实时画面？

林邦源 · AI 笔记 · 2026年11月1日 · 阅读时间约 4 分钟

English 繁體中文 简体中文

电脑上的摄像头，是任何需要“观察真实世界并作出反应”的程序的起点。口红的例子正展示了 这一点：视频是许多静止帧一个接一个送来。在每一帧中找出人脸，涂上口红， 显示这一帧，再继续下一帧。每一帧都这样做，结果就是一张带着口红的动态人脸。

下面的程序是基础：10 行代码，打开你的摄像头，在窗口中显示实时画面，直到你按下 q 或 Q。它不含任何 AI，只负责从摄像头获取帧并显示出来—— 刻意如此，好让摄像头部分在加入 AI 之前先弄清楚。

你的眼睛看到什么，程序看到什么

你的眼睛看到流畅的动态影像。程序看到的是一连串独立的帧，每一帧迅速取代前一帧， 快得让你看不出变化。

程序如何运行

1. 打开摄像头

import cv2
cap = cv2.VideoCapture(0)

cv2 是 OpenCV（Open Source Computer Vision，开源计算机视觉）， 本系列用来打开照片和视频的库。第一行把它加载。

第二行连接摄像头，并把这个连接保存在 cap（capture，捕获）里。0 指电脑上的第一个摄像头，通常是内置摄像头。在 Mac 上，第一次运行时电脑会请求授权； 在 Windows 上，如果没有画面出现，请检查“设置”中是否允许了摄像头访问。

2. 每次读取一帧

while True:
    ret, img = cap.read()
    cv2.imshow("Frame", img)

第一行启动一个不会自行停止的循环，因为 True 永远为真。它下面缩进的 每一行都会一遍又一遍地执行，每帧一次。

cap.read() 取出一帧。ret（return）表示有没有成功读到帧， img（image）就是帧本身：一个像素值的网格。这个 img 就是任何摄像头程序要处理的东西——与之前笔记中的照片文件完全一样。

cv2.imshow 把帧显示在标题为 "Frame" 的窗口中。每一帧新画面 取代前一帧，所以窗口看起来就像实时视频。

3. 按 q 或 Q 时停止

key = cv2.waitKey(1)
if key in (ord('q'), ord('Q')):
    break

cv2.waitKey(1) 等待一毫秒看有没有按键，然后继续。key 是一个代码，告诉你按了哪个键，没有按键就返回 -1。这个短暂的等待 也让窗口有时间画出帧——视频能显示出来，正是因为它。

下一行检查 q 或 Q。ord() 把字母变成数字—— ord('q') 是 113——这样字母就能与 key 中的数字比较。 两个都测试，大写锁定（Caps Lock）就没有影响。

break 离开循环，继续执行最后两行。运行程序后，Visual Studio Code 的 终端仍是目前选中的窗口，所以你按的 q 或 Q 会送往 Visual Studio Code，而不是显示视频的程序。把鼠标指针移到视频窗口上，单击选中它， 然后按 q 或 Q 结束程序。

还有一个更快的停止方法：在 Visual Studio Code 终端中，同时按 Ctrl 和 C 两个键。

4. 关闭摄像头

cap.release()
cv2.destroyAllWindows()

cap.release() 断开与摄像头的连接，其他程序就能再次使用它，摄像头指示灯 也会熄灭。cv2.destroyAllWindows() 关闭窗口。

完整程序

把上面的部分拼回来。这就是完整的文件，一共 10 行： 

import cv2
cap = cv2.VideoCapture(0)
while True:
    ret, img = cap.read()
    cv2.imshow("Frame", img)
    key = cv2.waitKey(1)
    if key in (ord('q'), ord('Q')):
        break
cap.release()
cv2.destroyAllWindows()

保存其中一帧

许多工作只需要一帧画面，而不是一条视频流：取一帧，然后分析它。你不需要为此 另写一个程序。在循环内，img 已经是一帧画面，所以多加一行就能把它 保存为文件： 

cv2.imwrite("camera_frame.jpg", img)

把那行加在 cap.read() 之后，程序就会为每一帧写一个新文件。如果只想 保留一帧，把它加在 break 那行上面，这样文件会在你按 q 时保存：你那一刻在屏幕上看到的，就是你得到的。

一旦帧成为文件，之前笔记中的一切就都能套用——包括 〈AI 如何找出你脸上的关键点？〉中的 face_recognition.load_image_file。

在自己的电脑上运行

下载 zip 文件并解压到 一个文件夹。这个 zip 包含本系列的六个程序；本文使用 face05.py。 这个程序不需要在文件夹里放照片。在 Visual Studio Code 中打开文件夹，然后在终端 输入以下三行： 

uv python pin 3.12.10
uv sync
uv run face05.py

第一行记录这个文件夹使用的 Python 版本，第二行安装 pyproject.toml 列出的所有软件包（包括 OpenCV）。第三行打开摄像头窗口。在该窗口中按 q 即可关闭。

如果你还没有设置 uv，请先阅读 〈如何安装 Visual Studio Code？〉， 然后是 Windows 或 Mac 的 uv 笔记。
