如何复用你已经训练好的模型（预测，版本 13）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 3 分钟阅读

这是预测系列的最后一篇。版本 12 训练了两百个模型，把冠军的权重存进一个叫 best_model_12.pt 的文件里。版本 13 完全不做训练：它重建同一个网络， 载入那些保存下来的权重，几秒钟内报出同样的四个分数。

实际保存的是什么

版本 12 模型部分的最后一行是 torch.save(best_trial["model"].state_dict(), "best_model_12.pt")。 state_dict 是一个数字的字典：每一层的权重和偏置，以它们所属的层来命名。 它不含程序，也不含设置；用这个冠军的话，文件只有大约 11 KB — 小到可以用电子邮件寄出。

所以这个文件没法自己重建。版本 13 必须提供形状 — 有几层、多宽，以及窗口多长。 它按这个形状搭一个空网络，然后由 load_state_dict 把保存的数字拷进去。 如果形状不匹配，PyTorch 会直接报错停下，而不是给出一个错误的预测。

配置从哪里来

在版本 13 靠近顶部的地方，这些设置不是手打进去的。它们是从版本 12 写出的表格里读出来的： 

RESULTS_FILE = "search_results_12.xlsx"
MODEL_FILE   = "best_model_12.pt"
BATCH_SIZE   = 32

results  = pd.read_excel(RESULTS_FILE)
best_row = results.sort_values("val_loss").iloc[0]

BEST_CFG = {
    "window_size": int(best_row["window_size"]),
    "hidden_size": int(best_row["hidden_size"]),
    "num_layers":  int(best_row["num_layers"]),
}

read_excel 载入那 200 行的表格。按 val_loss 从低到高排序， 再取 .iloc[0]，就挑出了获胜的那一行 — 这正是版本 12 里搜索本身用的 规则 — 决定形状的三个设置按列名复制出来。int() 把它们变成普通整数， 因为层的尺寸必须是普通整数。

六个设置里只需要三个。回合、学习率和优化器属于一次训练，而这个程序不训练。 因为表格是读出来的而不是打进去的，如果版本 12 重跑一次、换了另一个组合获胜， 这个程序会自己跟着新的冠军走。

程序怎么运作

1. 用同样的窗口大小重建数据

window_size = BEST_CFG["window_size"]
windows     = series_tensor.unfold(0, window_size, 1)
features    = windows[:, :-1]
targets     = windows[:, -1:]
full_dataset = TensorDataset(features, targets)

total   = len(full_dataset)
val_end = int(total * 0.85)
test_loader = DataLoader(Subset(full_dataset, range(val_end, total)),
                         batch_size=BATCH_SIZE, shuffle=False)

窗口和测试集的切分都完全按 搜索应该有多宽（版本 12）里解释的方式搭建， 只差一点：只搭测试集的 loader，因为这里不训练任何东西。

2. 重建架构并载入权重

def build_model(input_size, hidden_size, num_layers):
    layers, in_dim = [], input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers)

model = build_model(window_size - 1, BEST_CFG["hidden_size"], BEST_CFG["num_layers"])
model.load_state_dict(torch.load(MODEL_FILE, map_location=device))
model.to(device)
model.eval()

网络和 搜索应该有多宽（版本 12）里一模一样地搭建， 所以它的形状和保存的文件对得上。关键在于这一行 model.load_state_dict(torch.load(MODEL_FILE, map_location=device))： torch.load 读取文件，load_state_dict 把每一个保存的数字 拷进对应的层。map_location 把这些数字放到任何一个可用的设备上， model.to(device) 把网络搬到同一个地方。model.eval() 把它切到测试模式。

3. 让测试日通过已保存的模型跑一遍

preds, actuals = [], []
with torch.no_grad():
    for xb, yb in test_loader:
        preds.extend(model(xb.to(device)).cpu().numpy())
        actuals.extend(yb.numpy())

torch.no_grad() 告诉 PyTorch，这里没有任何东西在学习。程序只是在做预测， 不是在改进模型，所以这个设置省时间，也省内存。预测值和真实值保持同样的顺序， 因为 loader 不打乱它们。

model.eval() 把网络放进测试模式。有些种类的层在训练时和测试时行为不同， 这个设置选择测试时的行为。这个网络只有简单的层，所以在这里没有区别， 但以后如果加了别的层，它能让程序仍然正确。

因为模型已经训练好，你也可以把它用在别的数据上。把新的销售数值按同样的格式放进一个 CSV 文件，保持同样的窗口大小，再运行一次程序。它会载入保存的权重， 为那些新的日子而不是那 215 个测试日生成预测。

4. 计算四个指标

mae  = torch.mean(torch.abs(p - a)).item()
mse  = torch.mean((p - a) ** 2).item()
rmse = torch.sqrt(torch.tensor(mse)).item()
r2   = (1 - torch.sum((a - p) ** 2) / torch.sum((a - torch.mean(a)) ** 2)).item()

MAE 平均每次偏差的大小，MSE 先把它们平方，RMSE 再开平方，让数字回到销售额的美元单位。 R² 把模型跟“永远预测测试日平均值”相比，正如 如何用模型从未见过的数据来评估它（版本 8）里解释的那样。

你应该看到什么

一次真实运行的完整输出，未经改动： 

Loaded: best_model_12.pt
Config: {'window_size': 30, 'hidden_size': 32, 'num_layers': 2}

Test Set Metrics:
  MAE:  4.4603
  MSE:  31.7479
  RMSE: 5.6345
  R²:   0.3710
Saved: best_model_predictions.png

这四个数字和版本 12 为它的冠军打印出来的完全一致，精确到小数点后第四位。 没有训练任何东西，没有打乱任何东西，评分过程里也没有随机种子参与。 同样的权重在同样的 215 天上给出同样的答案，这正是保存模型的用处。

整个系列一眼看完

十三个程序，一个问题：给定最近的过去，下一天的销售额会是多少？ 版本 1 到 3 看了看数据，把它切成窗口。版本 4 到 6 把这些窗口变成特征和目标， 并按日期顺序切分，这样模型总是在它学过的日子之后的日子里被评分。版本 7 训练了一个网络。 版本 8 诚实地在它从未见过的日子里给它打分。版本 9 到 12 搜索设置 — 训练多久、迈多大一步、用哪个优化器、多宽、多深、回看多远 — 最后走到两百次试验。版本 13 留住了结果，并展示怎样把它重新拾起来。

这个模型能做到的很有限：它跟随序列的水平和缓慢上行的漂移，在一瞬间把 29 个过去的数值 变成一个数字。它跟不上每日的起伏；R² 大约 0.37，意味着测试日里大约三分之二的变化 仍然没有被解释。网络只看到最近的销售额数值，所以它不知道星期几、月份，也不知道假期。

更好的下一步不是更大的搜索，而是更好的输入，或另一种模型，比如一种能记住更长模式的模型。 但先有一个障碍：time_series.csv 里的时间列是从 1 到 1,460 的步数编号， 不是日期，所以在给每一行配上真实日期之前，星期几和月份都算不出来。

完整程序

上面那些片段，重新拼回一起。这是完整的文件： 

import os
os.environ["KMP_DUPLICATE_LIB_OK"] = "TRUE"

import torch
import torch.nn as nn
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
from torch.utils.data import TensorDataset, DataLoader, Subset

# ── Best config, selected by validation loss in search_results_12.xlsx ───────
RESULTS_FILE = "search_results_12.xlsx"
MODEL_FILE   = "best_model_12.pt"
BATCH_SIZE   = 32

results  = pd.read_excel(RESULTS_FILE)
best_row = results.sort_values("val_loss").iloc[0]

BEST_CFG = {
    "window_size": int(best_row["window_size"]),
    "hidden_size": int(best_row["hidden_size"]),
    "num_layers":  int(best_row["num_layers"]),
}

# ── Load data ─────────────────────────────────────────────────────────────────
df = pd.read_csv("time_series.csv")
series = df["series"].values
series_tensor = torch.tensor(series, dtype=torch.float32)

window_size = BEST_CFG["window_size"]
windows     = series_tensor.unfold(0, window_size, 1)
features    = windows[:, :-1]
targets     = windows[:, -1:]
full_dataset = TensorDataset(features, targets)

total   = len(full_dataset)
val_end = int(total * 0.85)
test_loader = DataLoader(Subset(full_dataset, range(val_end, total)),
                         batch_size=BATCH_SIZE, shuffle=False)

device = torch.device("cuda" if torch.cuda.is_available() else "cpu")

# ── Rebuild model architecture & load weights ─────────────────────────────────
def build_model(input_size, hidden_size, num_layers):
    layers, in_dim = [], input_size
    for _ in range(num_layers):
        layers += [nn.Linear(in_dim, hidden_size), nn.ReLU()]
        in_dim = hidden_size
    layers.append(nn.Linear(in_dim, 1))
    return nn.Sequential(*layers)

model = build_model(window_size - 1, BEST_CFG["hidden_size"], BEST_CFG["num_layers"])
model.load_state_dict(torch.load(MODEL_FILE, map_location=device))
model.to(device)
model.eval()
print(f"Loaded: {MODEL_FILE}")
print(f"Config: {BEST_CFG}\n")

# ── Evaluate ──────────────────────────────────────────────────────────────────
preds, actuals = [], []
with torch.no_grad():
    for xb, yb in test_loader:
        preds.extend(model(xb.to(device)).cpu().numpy())
        actuals.extend(yb.numpy())

p = torch.tensor(np.array(preds))
a = torch.tensor(np.array(actuals))

mae  = torch.mean(torch.abs(p - a)).item()
mse  = torch.mean((p - a) ** 2).item()
rmse = torch.sqrt(torch.tensor(mse)).item()
r2   = (1 - torch.sum((a - p) ** 2) / torch.sum((a - torch.mean(a)) ** 2)).item()

print(f"Test Set Metrics:")
print(f"  MAE:  {mae:.4f}")
print(f"  MSE:  {mse:.4f}")
print(f"  RMSE: {rmse:.4f}")
print(f"  R²:   {r2:.4f}")

# ── Plots ─────────────────────────────────────────────────────────────────────
# 1. Predictions vs actual
plt.figure(figsize=(12, 5))
plt.plot(actuals, label="Actual",    color="lightgrey", linewidth=1.5)
plt.plot(preds,   label="Predicted", color="red",       linewidth=1.5)
plt.title(f"Best Model — Predictions vs Actual (Test Set)\nR²={r2:.4f}  RMSE={rmse:.4f}", fontsize=11)
plt.xlabel("Time"); plt.ylabel("Value")
plt.legend(); plt.grid(True)
plt.tight_layout()
plt.savefig("best_model_predictions.png", dpi=150)
plt.show()
print("Saved: best_model_predictions.png")

在自己的电脑上运行

下载 zip 文件，解压到 一个文件夹。zip 里有这个系列的程序、time_series.csv 数据文件和 pyproject.toml。这篇笔记用的是 time_13.py。

版本 13 有一个之前任何一篇笔记都没有的要求：它需要 best_model_12.pt， 而这个文件只有在同一个文件夹里跑过一次 time_12.py 之后才会存在。 版本 12 要跑两百次试验，需要好一阵子才结束。版本 13 只要几秒钟，因为它那些活一点也不干。

在 Visual Studio Code 里打开文件夹，然后在终端里打这三行： 

uv python pin 3.12.10
uv sync
uv run time_13.py

第一行记录这个文件夹使用哪个 Python 版本，第二行安装 pyproject.toml 里列出的 每一个包。第三行载入保存的权重，打印四个分数并画一张图，把它存成 best_model_predictions.png；看过之后关掉窗口。

这三行只需要一次。下次想再运行程序，只打 uv run time_13.py。

如果你还没有设置 uv，请先从 如何安装 Visual Studio Code？开始，然后看 uv 笔记： Windows 或 Mac。
