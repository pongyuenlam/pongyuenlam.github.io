如何用腾讯 WorkBuddy 获取网站链接？

林邦源 · AI 笔记 · 2026年11月26日 · 阅读时间约 3 分钟

English 繁體中文 简体中文

电脑上的 HTML 文件没有可以发给别人的网址。要得到网址，文件必须被托管： 一台连接互联网的电脑保存这个页面，并向访客显示。

腾讯 WorkBuddy 的国际版可以在对话中完成这件事：附加一个 HTML 文件，请 WorkBuddy 托管， 它便回复一条链接。

本文的例子是 如何用语音识别让网页听懂说话（版本 2）？中的聆听页面。 你可以打开已托管的示例 看看结果。

开始前需要什么

  • 一个 HTML 文件。它应能在浏览器中打开并运行。示例文件名为 index.html。
  • 腾讯 WorkBuddy 国际版。在 www.workbuddy.ai 打开，如网站要求就先登录。
  • 互联网连接。WorkBuddy 读取文件并把页面上线。

步骤 1：准备 HTML 文件

使用你自己的文件，或从聆听页面的笔记下载 index.html。把文件放在容易找到的位置，例如桌面或“下载”文件夹。

这个例子是单一自足文件：页面和脚本都在 index.html 内，没有其他文件要上传。

步骤 2：在 WorkBuddy 附加文件

在 WorkBuddy 国际版开始新对话。用附件控件加入 index.html，就像附加文档或 图片一样。

步骤 3：请 WorkBuddy 托管

附上文件并发送这句：

read the attached html file, and let me know whether you can help host it online?

WorkBuddy 会读取文件并准备在线副本。如果回复没有链接，就请它托管页面并提供网址。

步骤 4：复制并测试链接

WorkBuddy 会回复一个网址。以示例文件而言，网址是： 

https://wbapp-p9pnbs1i3wmpuod8agncme.apps.workbuddy.host/?sharecode=ND6FKZWMKB

在新的浏览器标签页打开整个网址。页面现在来自 WorkBuddy 的托管服务，而不是你电脑上的文件。 把链接发给任何人之前，先测试它的按钮和其他功能。

复制整个网址，包括 sharecode= 之后的部分。完整网址就是可分享的链接。 访客无需你发送 HTML 文件。

限制

  • 网址由 WorkBuddy 控制。它不是你的域名，托管服务也可能改变。截至本文发布 日期，WorkBuddy 未说明链接的有效期限。最新信息请看 腾讯的官方文档。 保留原始 HTML 文件，以便链接失效时再次托管。
  • 把分享页面视为公开。上传前先移除文件中的密码、个人资料和其他私密信息。
  • 这个例子只有一个 HTML 文件。若网站有独立的图片、样式文件或脚本，就需要一并 提供。Python 网站又不同，因为它需要运行 Python 的服务器。
  • 托管不改变页面的需要。聆听示例仍然需要 Chrome 或 Edge、麦克风权限， 以及用于语音识别的互联网连接。
