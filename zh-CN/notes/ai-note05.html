如何安装 Visual Studio Code？

林邦源 · AI 笔记 · 2026年11月1日 · 阅读时间约 4 分钟

English 繁體中文 简体中文

Visual Studio Code——简称 VS Code——是微软推出的免费集成开发环境（Integrated Development Environment，IDE）。简单来说，它是一个把文件集中管理、让你编辑文件、 并在文字旁边显示 AI 帮助的程序。它就是我在较早前的笔记 〈无代码、低代码、氛围编程与编程〉中 介绍过的编辑器。你只需安装一次，在 Windows 或 Mac 上都只需要几分钟。

观看演示视频

在 Google Drive 观看 （无需账户）。

下载安装程序

前往 code.visualstudio.com/download， 选择适合你电脑的按钮。这个页面由微软发布，下载完全免费。

在 Windows 上安装

在下载页面选择 Windows 按钮，运行下载的文件。接受许可条款， 然后一直按 Next，直到出现 Install 并点击它。 默认选项已经足够。

在 Mac 上安装

在下载页面选择 Mac 按钮——如果你的 Mac 较新，选择名为 “Apple silicon”的芯片版本；如果不确定，选择“Intel”。

双击下载的文件解压，然后把 Visual Studio Code 拖进 Applications（应用程序）文件夹。之后从 Launchpad 或聚焦搜索 打开它，就像打开 Word 或 Excel 一样。

验证安装

打开 Visual Studio Code。你应该会看到一个列出最近文件夹的 Welcome（欢迎）标签页。这就是所需的全部设置，暂时无需再配置任何东西。
