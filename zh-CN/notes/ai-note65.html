如何把每个窗口分成特征与目标值（预测，版本 4）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 5 分钟阅读

这是预测系列的第 4 个版本，也是训练开始之前的最后一个版本。版本 4 把每个窗口切成两部分： 特征，模型被允许查看的那些日子；以及目标值，它必须猜的 那一天。

特征与目标值

取一个 30 天的窗口。前 29 天是模型会看到的东西；第 30 天是它必须预测的。这把每个窗口变成 一个训练例子。这两部分的名字值得记住，因为之后每个版本都会用到：

  • 特征 — 29 个已知的日子。输入。
  • 目标值 — 第 30 天。模型被打分时所对照的答案。

因为每个窗口里最后的销售额数值被用作目标值，所以窗口 30 会给出 29 个特征，而不是 30 个。 这就是 29 在这个程序里到处出现的原因。

程序怎样运作

1. 导入 torch、它的数据工具和 pandas

import torch
from torch.utils.data import TensorDataset, DataLoader
import pandas as pd

TensorDataset 把特征和目标值配成对。DataLoader 把这些对分批 送给模型。pandas 读 CSV 文件。

2. 在一个函数里切割并拆分

def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    row_n = windows.shape[0]
    col_n = windows.shape[1]
    features = windows[0:row_n, 0:col_n-1]  # All columns except the last
    targets = windows[0:row_n, col_n-1:col_n]   # Just the last column
    return features, targets

第一行是版本 3 的切割，没有改动。windows.shape 然后报告结果的大小： row_n 是有多少个窗口，col_n 是每个窗口有多长。

接下来两行做拆分。windows[0:row_n, 0:col_n-1] 的意思是每一行、从第 0 列 到最后一列之前（不含最后一列），也就是 29 个已知的日子。 windows[0:row_n, col_n-1:col_n] 的意思是每一行、只要最后一列， 也就是答案。每一行的注释用更少的字说了同一件事，最后一行返回特征和目标值。

3. 载入真正的销售文件

df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30

前两行引入 1,460 个每日销售额数字。第三行把它们从一个普通数组转换成 PyTorch 的 张量，也就是 PyTorch 用来做计算的那种格式，而 dtype=torch.float32 让每个数字是小数而不是整数 — 这是必需的，因为 销售额有分。

4. 建立例子的数据集

features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
dataset = TensorDataset(features, targets)
batch_size = 32
train_loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)

第一行调用函数 create_sliding_windows_with_target，给我们两个列表， features 和 targets。第一个列表装着 29 天的输入，第二个装着 对应的答案。TensorDataset 把每个输入和它自己的答案放在一起。 DataLoader 然后把这些例子每 32 个一组送给模型，而不是一次送上全部 1,431 个。 设 shuffle=True 让模型每次看到例子时顺序都不一样，于是它从销售额数值中学习， 而不是记住它们的日期顺序。

5. 打印造出来的东西

print(f"Series length: {len(series)}")
print(f"Number of windows: {len(features)}")
print(f"Feature shape: {features.shape}")
print(f"Target shape: {targets.shape}")

这四行是一个值得照抄的习惯：训练任何东西之前，先打印形状。如果这里的数字错了，下面每一个 结果都是错的，而现在发现这件事的代价是一次运行，不是一个下午。

6. 看一眼三个例子

for i in range(3):
    print(f"\nWindow {i+1}:")
    print(f"Features (previous {window_size-1} days): {[f'{x:.2f}' for x in features[i].numpy()]}")
    print(f"Target (next day): {targets[i].item():.2f}")

循环跑三次，前三个例子各一次。里面，第一个 print 给例子贴上标签，第二个打印 四舍五入到两位小数的 29 个特征，第三个打印那一个目标值。花括号里的 :.2f 意思是显示两位小数。

你应该会看到什么

Series length: 1460
Number of windows: 1431
Feature shape: torch.Size([1431, 29])
Target shape: torch.Size([1431, 1])

First few windows:

Window 1:
Features (previous 29 days): ['29.40', '33.41', '37.86', ... '27.24', '28.71']
Target (next day): 27.08

这个序列有 1,460 天，每个窗口覆盖其中 30 天。第一个窗口包含 第 [1, 2, 3, ..., 30] 天，第二个包含第 [2, 3, 4, ..., 31] 天， 依此类推，每个窗口都比前一个晚一天开始。

你可以从一个窗口的结束日算出它的起始日： 起始日 = 结束日 − 30 + 1。第二个窗口结束在第 31 天，所以它从 31 − 30 + 1 = 2 天开始。最后一个窗口结束在第 1,460 天，所以它从 1,460 − 30 + 1 = 1,431 天开始。窗口因此从第 1 天、第 2 天开始，一直到 1,431，总共 1,431 个窗口。

每个窗口变成一个训练例子。它的前 29 个值是输入，最后一个是目标值。这就是特征形状是 [1431, 29]、目标形状是 [1431, 1] 的原因：有 1,431 个例子， 每个有 29 个输入和 1 个答案。

完整程序

把上面的各部分放回一起。这就是完整的文件，一共 27 行： 

import torch
from torch.utils.data import TensorDataset, DataLoader
import pandas as pd
def create_sliding_windows_with_target(data, window_size, shift=1):
    windows = data.unfold(0, window_size, shift)
    row_n = windows.shape[0]
    col_n = windows.shape[1]
    features = windows[0:row_n, 0:col_n-1]  # All columns except the last
    targets = windows[0:row_n, col_n-1:col_n]   # Just the last column
    return features, targets
df = pd.read_csv('time_series.csv')
series = df['series'].values
series_tensor = torch.tensor(series, dtype=torch.float32)
window_size = 30
features, targets = create_sliding_windows_with_target(series_tensor, window_size=window_size, shift=1)
dataset = TensorDataset(features, targets)
batch_size = 32
train_loader = DataLoader(dataset, batch_size=batch_size, shuffle=True)
print(f"Series length: {len(series)}")
print(f"Number of windows: {len(features)}")
print(f"Feature shape: {features.shape}")  # Should be (num_windows, window_size-1)
print(f"Target shape: {targets.shape}")    # Should be (num_windows, 1)
print("\nFirst few windows:")
for i in range(3):
    print(f"\nWindow {i+1}:")
    print(f"Features (previous {window_size-1} days): {[f'{x:.2f}' for x in features[i].numpy()]}")
    print(f"Target (next day): {targets[i].item():.2f}")

在自己的电脑上运行

下载 zip 文件，解压到 一个文件夹。zip 里有这个系列到目前为止的程序、time_series.csv 数据文件， 以及 pyproject.toml。这篇笔记用的是 time_04.py。在 Visual Studio Code 中打开文件夹，然后在终端输入这三行： 

uv python pin 3.12.10
uv sync
uv run time_04.py

第一行记录这个文件夹用哪个 Python 版本，第二行安装 pyproject.toml 列出的 每一个包。第三行在终端打印四个计数和三个示例窗口。

这三行只需要一次。下次想再运行程序，只输入 uv run time_04.py。

如果你还没有设置 uv，先看 如何安装 Visual Studio Code？，然后看 uv 笔记的 Windows 或 Mac。

接下来是什么

数据集有了，但还没有任何东西从它学过。版本 5 把这两行切片整理成更短的形式，版本 6 把例子 分成训练部分和验证部分，这样就能在模型没见过的日子上衡量进展。
