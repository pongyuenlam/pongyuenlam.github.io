如何显示文件夹里的每一张人脸照片（人脸识别，版本 1）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 4 分钟阅读

这是九篇系列的第一篇。这个系列一步一步地搭出一个能认出摄像头前是谁的程序。 版本 1 里完全没有 AI。它打开一个装满照片的文件夹，把照片一张一张显示出来， 并打印出照片里那个人的名字。这样安排是有意的：电脑要认出人脸，先得能找得到文件、 打得开照片。

名字从哪里来？

人脸识别程序必须知道谁是谁。你可以另外打一份名单，但那等于多一件需要跟照片同步的事。 这个系列改用文件名。文件夹里如果有 Howard.JPG、Mary.jpg 和 Paul.jpg，程序就已经知道三个名字，需要的时候直接从文件名读出来就行。

这也是程序最后三行只打印 Howard 的原因——前面不带 images/ 这个 文件夹，后面不带 .JPG 这个扩展名。这里打印出来的东西，就是后面几个版本贴在 人脸旁边的标签。

程序怎么运作

1. 载入三个库

import cv2
import os
import glob

cv2 是 OpenCV，负责打开和显示图片。 os 负责电脑的文件和文件夹，并且知道你的电脑在文件夹之间用的是 / 还是 \。glob 负责按规则找文件——程序不用事先知道照片叫什么名字， 就能把它们找出来。

2. 列出文件夹里的每一个文件

images_folder = "images"
images_path = glob.glob(os.path.join(images_folder, "*.*"))

第一行记下文件夹的名字。第二行用 os.path.join 组合出 images/*.* 这个规则——任何名字，一个点，任何扩展名。用 os.path.join 而不是自己打斜线，是为了在 Mac 和 Windows 上都正确。 然后 glob.glob 会返回所有符合条件的路径，例如 ["images/Howard.JPG", "images/Mary.jpg", "images/Paul.jpg"]。

*.* 很方便，但也不挑食：在 Mac 上它连 .DS_Store 这类杂物 都会抓进来。遇到这种情况，程序只是读不到那一个文件然后继续，你也可以把这个杂物文件删掉。

3. 数一数有几张照片

print("{} images in folder".format(len(images_path)))

len() 就是 length（长度），用来数清单里有几个路径。{} 是占位符，由 .format() 填进去，所以画面会先显示 3 images in folder。如果这个数字是 0，说明文件夹名字写错了，或者照片放在 别的地方——这时候先把它修好，再往下读。

4. 每张照片显示一秒

for img_path in images_path:
    img = cv2.imread(img_path)
    cv2.imshow("image", img)
    cv2.waitKey(1000)

for 那一行把路径一个一个拿出来，下面缩进的部分每张照片执行一次。 cv2.imread 把文件读进 img，那是一格一格的像素值， 后面的版本就是在这个格子里找出人脸。cv2.imshow 把它显示在标题为 "image" 的窗口里，cv2.waitKey(1000) 让它停留 1000 毫秒， 也就是一秒，然后下一张照片才替换上来。

一秒够你看清照片，也短到能一张张看完整个文件夹。把数字调大，幻灯片就慢下来。

5. 打印文件名里的名字

    basename = os.path.basename(img_path)
    (filename, ext) = os.path.splitext(basename)
    print(filename)

os.path.basename 去掉文件夹，images/Howard.JPG 变成 Howard.JPG。os.path.splitext 把名字和扩展名拆成两段， Howard 和 .JPG，分别存进 filename 和 ext。最后一行在他的照片还显示着的时候，打印出 Howard。

完整程序

把上面的片段拼回去，就是完整的文件，一共 13 行： 

import cv2
import os
import glob
images_folder = "images"
images_path = glob.glob(os.path.join(images_folder, "*.*"))
print("{} images in folder".format(len(images_path)))
for img_path in images_path:
    img = cv2.imread(img_path)
    cv2.imshow("image", img)
    cv2.waitKey(1000)
    basename = os.path.basename(img_path)
    (filename, ext) = os.path.splitext(basename)
    print(filename)

在自己的电脑上运行

下载压缩包，解压到一个 文件夹。压缩包里是这个系列全部九个程序、装着三张照片的 images 文件夹， 以及 pyproject.toml。这一篇用的是 face01.py。用 Visual Studio Code 打开这个文件夹，然后在终端输入下面三行： 

uv python pin 3.12.10
uv sync
uv run face01.py

第一行记下这个文件夹使用的 Python 版本，第二行按 pyproject.toml 安装所有 包，第三行显示第一张照片。想换成自己的照片，就把 images 里的文件替换掉， 并用那个人的名字当文件名，例如 Anna.jpg。

这三行只需要做一次。下次想再运行这个程序，只需输入 uv run face01.py。

如果你还没装好 uv，请先读如何安装 Visual Studio Code？， 再看 uv 那一篇：Windows 或 Mac。
