如何看出照片里的人是谁（人脸识别，版本 3）？

林邦源博士 · AI 笔记 · 2026 年 11 月 13 日 · 约 5 分钟阅读

版本 2 为它认识的每个人存了一组 128 个数字。版本 3 终于用上它们。它打开一张新照片， 量度里面的每一张脸，把这些测量值跟存下来的比较，然后打印对得上的那个人的名字。 这是第一个能回答问题的版本，而不只是为问题做准备。

整个比较建立在版本 2 的一个事实上：同一个人的两张照片会产生两个靠得很近的清单， 两个不同的人会产生离得远一点的清单。下面所有内容，都是在量度这种接近程度， 并决定多近才算够近。

程序怎么运作

1. 多一个库

import face_recognition
import cv2
import os
import glob
import numpy as np

numpy 是 NumPy，Numerical Python 的简称。它一次处理整份 数字清单，而这里要算的正是一整串距离。as np 只是一个绰号，所以代码可以写 np.round，不用写 numpy.round。

前四行做的是版本 2 的同一件事：找出文件夹里的照片，把每一张已知的脸变成数字。唯一的 差别是，这个版本不打印运行中的数目，而是直接去建那两个清单。

2. 一张要检查的新照片

img = cv2.imread("image-source.JPG")
rgb_img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)

image-source.JPG 是你要认的那张照片：一张班级照、一张合照、别人传给你的图。 它放在程序旁边，不在 images 里面，因为它还不是程序认识的人。第二行用跟 版本 2 一样的方式修正颜色顺序。

一个实际问题：代码里的文件名必须跟真实的文件完全一致，包括大小写。Mac 的截屏常常是 大写 .JPG。Windows 和默认设置的 Mac 不管这个差别，Linux 管，所以值得检查一下你打的名字。

3. 量度之前先找出人脸

face_locations = face_recognition.face_locations(rgb_img)
face_encodings = face_recognition.face_encodings(rgb_img, face_locations)

face_locations 是一个清单，找到几张脸就有几项，每一项是框住那张脸的一个框。 一张合照里可能有五个。

第二行把这些框交回给 face_encodings。库自己也能再找一遍脸，但告诉它脸在哪里， 省掉这份工作，也保证测量值和框指的是同一批脸。

注意这次没有 [0]。版本 2 只留第一张脸，因为每张已知的照片里只有一个人。 这里照片里每一张脸都要量，因为问题是谁在照片里，而不是照片里第一个人是谁。

4. 一张脸一张脸地比较

for face_encoding in face_encodings:
    matches = face_recognition.compare_faces(known_face_encodings, face_encoding)

compare_faces 拿新的一张脸和整份已知脸的清单，为每个已知的人返回一个 True 或 False，顺序跟 known_face_names 一样。 已知三个人时，结果看起来像 [True, False, False]：这张脸对得上第一个人， 对不上另外两个。

那个 True 背后有一个阈值。库用距离比较两张脸，距离小于等于 0.6 就算同一个人。 这个系列的第 9 个版本会改这个数字；现在 0.6 是默认值。

5. 每张已知的脸有多远？

    face_distances = face_recognition.face_distance(known_face_encodings, face_encoding)
    print(np.round(face_distances, 2))
    best_match_index = np.argmin(face_distances)

face_distance 返回每个已知的人的实际数字，而不是是或否：类似 [0.28, 0.63, 0.64]。越小表示越像。同一个人拍两次，通常低于 0.4； 两个不同的人通常高于 0.6。

np.round(..., 2) 只是把显示整理到两位小数。然后 np.argmin 找出最小数字的位置——也就是最接近的那张已知的脸。位置从 0 开始，所以 0 表示 known_face_names 里的第一个名字。

6. 两个都要：最近，而且够近

    name = "Unknown"
    if matches[best_match_index]:
        name = known_face_names[best_match_index]
        face_names.append(name)

最近不等于对得上。一张陌生人的照片里，已知清单里总会有一个人是最近的，距离也许是 0.7。 matches[best_match_index] 这一行问的是：这个最近的人有没有通过 0.6 的测试。 只有通过了，名字才被接受。

append 在 if 里面，所以没有对上的脸就直接不进清单。这就是为什么 开头设成 "Unknown" 的那个变量，永远不出现在输出里：陌生人什么都不加， 而不是加上 Unknown 这个词。

完整程序

把上面的片段拼回去，为了篇幅把版本 2 里打印运行数目的那一行去掉： 

import face_recognition
import cv2
import os
import glob
import numpy as np

images_folder = "images"
images_path = glob.glob(os.path.join(images_folder, "*.*"))

known_face_encodings = []
known_face_names = []
for img_path in images_path:
    img = cv2.imread(img_path)
    rgb_img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
    basename = os.path.basename(img_path)
    (filename, ext) = os.path.splitext(basename)
    img_encoding = face_recognition.face_encodings(rgb_img)[0]
    known_face_encodings.append(img_encoding)
    known_face_names.append(filename)

img = cv2.imread("image-source.JPG")
rgb_img = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
face_locations = face_recognition.face_locations(rgb_img)
face_encodings = face_recognition.face_encodings(rgb_img, face_locations)

face_names = []
for face_encoding in face_encodings:
    matches = face_recognition.compare_faces(known_face_encodings, face_encoding)
    name = "Unknown"
    face_distances = face_recognition.face_distance(known_face_encodings, face_encoding)
    best_match_index = np.argmin(face_distances)
    if matches[best_match_index]:
        name = known_face_names[best_match_index]
        face_names.append(name)

print("The matched name's image file is", face_names)

输出是什么意思

如果 image-source.JPG 是 Howard 的照片，最后一行会打印： 

The matched name's image file is ['Howard']

如果你把两行 print 加回去，运行中间会显示推算过程： 

[0.28 0.63 0.64]
0

Howard 最近，距离 0.28，远在 0.6 的范围之内，所以留下的就是他的名字。一个陌生人会给出 类似 [0.71 0.74 0.69] 的距离，最近的是 0.69，if 不成立， 打印出来的清单就是空的：[]。

空清单是正确答案，不是 bug。它的意思是照片里没有一个是程序认识的人。

在自己的电脑上运行

用跟版本 1 一样的下载： 下载压缩包，解压， 用 Visual Studio Code 打开这个文件夹。这一篇用的是 face03.py。 第一次在这个文件夹里运行时，三行都跑： 

uv python pin 3.12.10
uv sync
uv run face03.py

这三行只需要做一次。下次想再运行这个程序，只需输入 uv run face03.py。

把想检查的照片放在 face03.py 旁边，命名为 image-source.JPG。 压缩包里已经有一张，所以解压后程序马上就能跑。换成你自己的照片，才能测一个真实的问题。 一张清晰、正面对着摄像头的脸给出最好的答案；一张转过去或者光线很差的脸，即使那个人 在文件夹里，也可能返回没有对上。

下一步

版本 1 到 3 都只处理已经存在的文件。版本 4 会打开摄像头，显示实时视频， 那是让识别可以在你移动时发生的必要一步。
