AI Programs

Python code exploring AI concepts step by step, from first principles to working models.

AI-Programs-NLP

Python · MIT License

A progression of scripts on cosine similarity, sentence embeddings, and semantic search: starting from basic cosine similarity calculations, through sentence embeddings with all-MiniLM-L6-v2, multilingual embeddings with BAAI/bge-m3 (including Chinese), and ending in a question-answering demo with a Gradio interface.

AI-Programs-regression

Python

A progression of scripts building up gradient descent from first principles: plotting and residual analysis, OLS regression with statsmodels, animated gradient descent, vectorized multi-parameter updates with NumPy, and finally regression as a one-neuron PyTorch model trained with autograd and SGD.
